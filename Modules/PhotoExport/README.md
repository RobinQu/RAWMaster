# RAWMaster Photo Export

The Rust library owns portable validation, the 200-input rule, filename templates, canvas geometry, raster composition, SDR encoding and exclusive publication. A host supplies verified and developed pixels, capture labels and any rasterized text or graphics.

`cargo test --locked --manifest-path Modules/PhotoExport/Cargo.toml` builds the bundled TurboJPEG encoder with CMake. The Swift package runs the same locked release build and places the runtime in its resource bundle. SwiftPM build plugins have no network access, so run `scripts/fetch-rust-dependencies.sh` once after checkout or a lockfile change; the plugin then builds with `cargo --offline --locked`. The stable call surface is `include/rawmaster_photo_export.h`.

Rust clients can call `Preset::parse`, `ordered_selection`, `geometry`, and `write_photo` directly. The raster contract is top-down, interleaved, straight-alpha RGBA16 in sRGB. The Mac can supply an opaque RGBX8 bitmap for JPEG. The embedded v4 RGB profile was generated by Little CMS from its sRGB profile factory. RGB sampling, glyph generation, and EXIF extraction remain upstream of this interface. File publication is exclusive and stages on the output volume.

The application keeps the established RAW development and Core Text paths for rendering recipes and glyphs. It uses the same Rust geometry for the preview and final raster, Rust codecs for delivery, and ImageIO for a typed metadata allowlist. Server callers can use the Rust raster compositor and supply platform-independent watermark overlays.
