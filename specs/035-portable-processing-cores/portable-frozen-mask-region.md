# 原片径向蒙版的局部重绘

这项实验从编辑器主画布的 2400×1600 定稿进入。它沿用单个具名硬边径向蒙版的八个色调控件。当前资格为 Apple M4 Max、两种已验证的原始尺寸、EXIF 方向 1、FlashRaw 0.3.1 及原显影和 FIT 计划。运行时需同时开启 `RAWMASTER_QA_PORTABLE_MASK_HALF_FIT=1` 与 `RAWMASTER_QA_PORTABLE_MASK_REGION_HALF_FIT=1`。[原有全幅路径与资格](portable-frozen-mask-half.md) · [原生入口](../../Sources/RAWMasterImaging/PreviewNativeSource.swift)

## 像素来源

第一次请求使用真实 Core Image 蒙版算子。从该算子的原坐标裁出保守外框，写入私有 R32Float 纹理。外框按 32 列和 256 行向外取整，并裁回相机原片。框外覆盖是正零。Rust 冷态仍检查整张光学图及全部半幅输出，每个原始像素先产生 Float32，再以原宽度、原坐标和硬件线性采样取得半幅。原生显示成功、当前文件与请求凭据再次核验后，宿主才登记框外已经核验的半幅字节。[Swift 所有权与存活期](../../Sources/RAWMasterImaging/PreviewPortableMaskRegion.swift) · [Metal 计算](../../Modules/ImageEdit/src/gpu/metal_surface/native_half_mask_region.wgsl)

同一物理原图对象、同一资料库快照及相同蒙版几何只变更控件时，宿主将已验证外部字节复制到新的私有输出，再调用 Rust 逐像素重绘框内。公开 C 接口的 `patch_only=1` 只证明矩形内的计算。对故意放置在框外的 NaN，局部调用可以成功，NaN 保留原状。宿主可交付的框外字节来自持有的冷态结果，其他来源的输出不能安装为复用数据。改变中心、更换快照或撤销来源会使旧数据失效。每个已提交的命令均等待完成。[C 接口和凭据范围](../../Modules/ImageEdit/include/rawmaster_image_metal.h) · [撤销和几何改变回归](../../Tests/RAWMasterImagingTests/PreviewPortableMaskRegionTests.swift)

| 实际光学输出 | 归档外框与原生计算量 | 原色阶中的分数覆盖像素 | 私有覆盖／已验证外部／独占半幅分配 |
| --- | --- | ---: | --- |
| 9504×6336 | 6688×4096，27,394,048／60,217,344 像素 | 366 | 110,100,480／131,301,376／241,680,384 B |
| 8640×5760 | 6080×3840，23,347,200／49,766,400 像素 | 363 | 93,388,800／105,676,800／199,065,600 B |

两种来源各对八个控件的两档取值做全图比对。32 份原始 Float32 诊断均匹配原显影，32 份非诊断 C 调用的整张 Float32 半幅及归档 sRGB8 也逐位相同。另有 12 帧按相同蒙版名连续切换 A、B、A 三次几何，均重新得到与独立原显影相同的半幅和显示。错误注入覆盖错误绑定、未写入覆盖、越界、尾带不对齐、已提交命令后撤销及同程序重试。测试保留输入 SHA-256 和逐项计数。[逐片证据](evidence/portable-mask-region.json) · [源码和原始回执](evidence/portable-mask-region-sources.tar.gz)

512 MiB 预算包括同时存活的覆盖、外部字节、独占输出和 Rust 的 48 MiB 工作缓冲。独立 Metal 缓冲使用实际 VM 页分配。首个候选采用 heap 估算时，对主片外部缓冲少收 8,192 B，分配核验拒绝该渲染。修订版在同一总预算内按完整 VM 页预留并复核实际分配。全进程最多保留一份可让出的蒙版数据。[预留与释放](../../Sources/RAWMasterImaging/PreviewCanonicalHalfFIT.swift)

## 编辑服务实测

同一封存 Release 按全幅、局部、局部、全幅顺序独立启动进程，每轮使用两张原片、37 个控件及两档参数，分别请求交互和定稿。1,184 帧的输出摘要及近似标记跨轮一致。每张原片的局部臂有两次需要重新生成完整半幅，另外 30 次直接使用已核验的外部像素。基线为 Batch 30 已集成的全幅具名蒙版路径。下表每个统计量采用每张照片、每个实验臂的 32 个目标定稿，并包含显示读回。[应用内逐轮数据和校验](evidence/portable-mask-region.json)

| 原片 | 全幅 P50 | 局部 P50 | 全幅 P95 | 局部 P95 | 蒙版与半幅阶段 P50，全幅／局部 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 9504×6336 | 61.27 ms | 37.66 ms | 89.32 ms | 68.91 ms | 42.62／21.38 ms |
| 8640×5760 | 54.72 ms | 33.28 ms | 76.46 ms | 77.56 ms | 37.15／17.10 ms |

首次定稿仍需计算整个半幅。每张照片两次冷请求的中位耗时，主片从 135.29 ms 到 137.01 ms，次片从 75.52 ms 到 78.07 ms。随后 30 次复用的定稿中位分别为 37.44 和 33.11 ms。37 控件进程峰值在两种来源均提高，该进程还同时运行独立的色轮与降噪试验。此接入保持默认关闭。封存运行库另行对拍 32 张完整 Float32 半幅和归档显示，均逐位相同。更换为 Batch 30 和 19b 的运行库后，两库各自输出四张局部色调和四张色轮定稿，与原归档一致。[运行库版本、完整物理半幅和旧库复演](evidence/portable-mask-region.json)
