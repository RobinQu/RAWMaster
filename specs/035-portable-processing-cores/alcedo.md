# AlcedoStudio 的编辑图如何提交到 GPU

本次核对 `zidage/AlcedoStudio` 的 `61d59bc98afad3be7b0d855bebdb86d7b9225e62`，与 032、033 使用同一提交。最值得借鉴的是把编辑配方、可复用的执行计划、单帧 GPU 资源分开。这个版本的场景主图只允许一条从 Develop 到显示变换 DRT 的通路。RAWMaster 需要额外实现两支 RGB 处理后合成的配方。本次在本机编译并运行了上游图校验器，GPU 路径的结论来自同一提交的实现与测试源码。上游 NOTICE 将该提交列为 GPL-3.0-only，本次 PoC 自行实现处理逻辑。[固定提交](https://github.com/zidage/AlcedoStudio/commit/61d59bc98afad3be7b0d855bebdb86d7b9225e62) · [上游 NOTICE](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/NOTICE#L4-L12) · [探针源文件](evidence/alcedo-graph.cpp)

## 从编辑参数到一帧图像

1. **冻结配方。** 预览和已提交快照持有只读文档、元素与谱系标识。导出在入队时取已提交快照，执行时绑定原图、全分辨率以及该项指定的输出色彩。因此同一导出项始终取入队那一刻的编辑版本。[快照构造](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/edit/graph/pipeline_graph_snapshot.cpp#L20-L51) · [导出入队](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/app/export_service.cpp#L154-L179) · [全尺寸任务](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/app/export_service.cpp#L262-L293)
2. **校验图，再展开执行阶段。** 通用校验逐端口检查类型、必需输入和多重连接，通过入度遍历检测环。产品额外校验场景主链，拒绝 RGB 扇出。编译器仅接受 Develop、ColorGrade、DRT 三种文档节点，沿主链连线顺序编译可见 Grade。一个 Grade 可以产生多个 `MaskEvaluate`，其覆盖合并为 `MaskUnion` 再输入 Grade。因此蒙版有多个前驱，主图的分支能力仍受限。[端口、入度及环](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/edit/graph/pipeline_graph.cpp#L395-L453) · [主链约束](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/edit/graph/pipeline_graph.cpp#L546-L592) · [允许的节点](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/edit/runtime/graph_compiler.cpp#L217-L240) · [蒙版汇合](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/edit/runtime/graph_compiler.cpp#L294-L317) · [按边编译](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/edit/runtime/graph_compiler.cpp#L503-L535)
3. **静态编译、逐帧绑定。** 静态键包含拓扑、输入布局、后端能力版本、编译算法版本。视口和本帧几何后绑定。交互角色复用解包输入和编译计划，批量角色取预解码输入或自行解包，每次编译。相邻可融合点运算组成有序参数命令，邻域算子有自己的阶段，旁路的 Grade 可以只传递原图绑定。在 Metal，主机复用计算管线状态并绑定源、目标、参数和 LUT，点运算内核在一次像素读取后遍历命令，必要时把蒙版混合并入本次写回。[两类渲染角色](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/include/edit/runtime/detail/renderer.inl.hpp#L147-L179) · [静态键](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/edit/runtime/graph_compiler.cpp#L474-L488) · [阶段分组](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/edit/runtime/graph_compiler.cpp#L103-L137) · [编码点运算](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/edit/runtime/metal/metal_primary_grade_pass.mm#L79-L130) · [内核的一读一写](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/edit/runtime/metal/shader/primary_grade.metal#L289-L323)
4. **按输出目的交付。** 计划执行器根据本帧需要绑定已有结果或编码 GPU pass。蒙版可命中覆盖缓存，Grade 使用工作纹理，显示变换产出最终图。预览通过 frame sink 提交纹理及同一帧的几何，调用者要求主机像素时才走显式下载。展示或下载失败会丢弃未发布写入。产品分派到编译可用的 CUDA、Metal 或 OpenCL 执行器，选择 CPU 得到 `None`，在产品渲染入口触发错误。无 GPU 的服务端需要独立提供 CPU 实现。[逐级执行](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/include/edit/runtime/plan_executor.hpp#L214-L284) · [呈现、下载、失败](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/include/edit/runtime/detail/renderer.inl.hpp#L338-L381) · [选择后端](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/edit/pipeline/pipeline_accelerator.cpp#L63-L111) · [产品渲染分派](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/edit/pipeline/pipeline_executor.cpp#L117-L144)
