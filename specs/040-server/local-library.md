# 040 · Server 资料库接入

2026-11-27 · Server 在 [042 本地资料库与制作任务](../042-local-library-workbench/spec.md) 的库包和单活动会话上增加连接、同步与所有权。[Server 交互](ux.md#首次打开与资料库菜单) · [接入原型](../../docs/ui/prototype/index.html?serverReview=1#welcome)

## Server 绑定

**`libraryID`** 随目录保存，代表逻辑库。**`replicaID`** 代表当前安装授权的包实例，与设备侧 bookmark、卷和文件身份一起登记。**`deviceID`** 由 Server 登记，授权和认证保存在设备侧。Server 写入校验 `(libraryID, deviceID, replicaID, ownershipEpoch, recoveryGeneration)`。拷贝取得的库 ID、旧目录的设备字段或同一 Mac 的设备令牌均须经绑定检查。

## 已同步库的移动与拷贝

| 动作 | Server 处理 |
| --- | --- |
| 已核对为同一包的移动或改名 | 保留 `libraryID`。经验证的包实例更新位置后继续原绑定 |
| 跨卷明确接续原库 | 核对本机包、Server 修订与未同步操作，显式重绑定同一逻辑库。Server 更新 fencing，目标失败时保留原绑定 |
| 作为独立资料库打开拷贝，或恢复到新的独立库 | 新身份清除原 Server 写授权、同步水位和待发操作。灾备接续走 Server 恢复或所有权转移 |
| 在另一台 Mac 首次打开已绑定库包 | 提供独立资料库或显式接续。取得新写授权前只使用已可访问的本地数据和允许的远端只读能力 |

## 切换与退出

在 042 的关闭屏障前暂停旧库发件箱、取回和同步订阅。未提交的操作与传输进度随旧库保存。Server 已接收的作业继续执行，下次打开所属库时重新核对。事件与结果只能更新所属库。[041 双端协同](../041-server-image-editing/queues.md#4-双端协同)

## 与 Server 建立本地副本

两条路径都先核对地址、证书和设备登记，随后选择本地包位置、核对空间，再确认操作。连接过程可返回或取消。

| 路径 | 成功条件 | 异常与恢复 |
| --- | --- | --- |
| 新建 Server 资料库 | 生成稳定的建库命令 ID。以同一库 ID 建立本地包和 Server 初始快照，校验修订、身份和所有权后打开本地库。 | 超时按原命令 ID 查收据。若 Server 已建好，保留远端库，从原步骤续接。本地未验收的暂存不得成为最近库。 |
| 同步 Server 上已有资料库 | 选可访问的库。显示所有权。下载已验证快照到暂存，补齐至选定修订的操作及不可重建资源，校验完成后激活。可用的机内 JPEG／代理逐步到达，原件按需取回或按用户选择固定。 | 断线／磁盘不足保留可核验检查点。快照或必要资源缺失不打开空库。若他机持写权，可按授权只读打开或显式转移，取得新 epoch 并对账后才开放写入。 |

本地可用、远端副本可用、原件已取回、索引完成分别显示。Server 连接或初次同步失败时可以返回已有库，也可以从开始页另建本地库。后续绑定本地库前需显式确认目标逻辑库。旧持有者离线期间产生的操作保存在原包，重连发现 epoch 过期时可查阅或另存独立库，经显式处理后才允许再次同步。
