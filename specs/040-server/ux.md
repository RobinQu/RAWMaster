# 040 · Server 交互与状态

2026-11-26 · 客户端入口、状态词汇、默认动作与走查要求。产品要求见[规格](spec.md)，数据与协议见[数据模型](data-model.md)与[协议](protocol.md)。本轮只完成交互定义，不改原生界面；现有[Server 规划预演](../../docs/ui/prototype/index.html#tools/server)仍用模拟状态覆盖归档、同步、作业三条主路径。原生开工前按 [AGENTS](../../AGENTS.md) 先更新同一工作台并完成浏览器走查。

## 1. 入口与归属

| 入口 | 作用范围 | 放什么 | 不放什么 |
| --- | --- | --- | --- |
| 设置 → Server | 设备与服务器 | 地址、证书指纹、登记、设备名、资料库绑定、归档策略、备份目标、诊断 | 单张照片决定、编辑参数 |
| 资料库工具 → Server | 当前资料库 | 归档覆盖率、独立备份、冷热缓存、冲突、作业、恢复 | 全局服务器安装配置 |
| 标题栏／状态区 | 当前资料库 | 在线／离线、待上传、待同步、冲突、运行作业的简短状态 | 详细日志 |
| 照片／组／项目上下文菜单 | 明确选择范围 | 查看归档状态、固定离线、取回原件、释放本地副本 | 服务器地址、令牌 |
| 导入完成摘要 | 当前会话 | 本次纳入／排除／仅序列／失败、可归档数量与字节、开始归档 | 自动把排除项标成可归档 |
| 任务／作业中心 | 当前库或全部库 | 上传、备份、取回、同步、远程作业的进度、取消、重试、结果 | 改变已提交输入 |

**不新增第 4 个工作流。** 标题栏仍为「资料库／编辑／导出」。Server 是资料库的设置与工具页，不替代选片、编辑或交付。

## 2. 状态词汇

所有状态必须能回答“这是目录、原片、备份、同步还是作业”。同一控件不得用“已同步”概括多个维度。

### 2.1 连接

| 状态 | 显示 | 可用动作 | 禁止暗示 |
| --- | --- | --- | --- |
| 未配置 | 设置入口、说明本地功能不受影响 | 连接服务器 | 已备份 |
| 连接中 | 地址、阶段、取消 | 取消、重试 | 在线 |
| 在线 | 服务器名、版本、最近联系 | 归档、同步、取回、作业 | 独立备份已完成 |
| 离线 | 最近成功时间、待同步数、本地可用范围 | 重试、继续本地工作 | 已搜索全库 |
| 需重新认证 | 原因、设备名 | 重新登记、撤销本机 | 继续上传 |
| 版本不兼容 | 客户端／服务端版本、只读范围 | 检查更新、退出 | 写入成功 |
| 降级 | 缺失能力、受限动作 | 使用已声明能力 | 完整功能 |

### 2.2 归档与备份

| 状态 | 含义 | 与相邻状态的区别 |
| --- | --- | --- |
| 未取得资格 | 最终排除、未核验失败或封存前未完成 | 不是“待上传” |
| 仅保留历史 | 只有来源、内容身份和处置 | 不是可恢复原件 |
| 待传输 | 已有归档引用，尚无完整服务器对象 | 不是“服务器已有” |
| 传输中 | 已收到部分块 | 不是“校验中” |
| 校验中 | 长度已到，正在核验哈希与可读性 | 不是“已完成” |
| 服务器原件可用 | 主存对象已校验，至少一个有效归档引用 | 不是“独立备份已覆盖” |
| 独立备份已覆盖 | 该对象在某代独立备份中已校验 | 需要主存与备份都可用 |
| 待找回 | 有归档资格但当前无可校验来源 | 需要用户提供来源或恢复 |
| 缺失／损坏 | 曾登记但对象不可读或哈希不符 | 需要修复或从备份恢复 |

**主存与备份分开显示。** 一行可以同时出现“服务器原件可用 · 独立备份未覆盖”，不能合并成一个绿色勾。备份代次详情列出目录快照、对象数、字节数、缺项、校验时间和目标。

### 2.3 本地可用

| 状态 | 显示 | 可用动作 |
| --- | --- | --- |
| 仅目录 | 缩略图或占位、需联网标记 | 取回代理／原件 |
| 代理可看 | 代理来源、尺寸、生成版本 | 取回原件、固定 |
| 原件已缓存 | 本地路径、校验时间、缓存级别 | 释放、固定 |
| 取回中 | 进度、已下载字节、取消 | 取消、暂停 |
| 已固定 | 固定范围与级别、占用 | 取消固定 |
| 可释放 | 满足全部释放条件 | 释放本地副本 |
| 释放受阻 | 具体原因：未备份、已固定、未同步、唯一副本、引用盘 | 查看原因、去处理 |
| 已释放 | 仅目录／代理仍可用 | 再次取回 |

### 2.4 同步与作业

同步：已同步、待同步、同步中、有冲突、暂停、失败。冲突必须显示实体、字段、双方值、设备来源、基准修订和建议动作；“保留本机”“采用服务器”“保留双方为分支”“稍后处理”四类动作按字段可用性出现。

作业：草稿、缺输入、排队、运行、等待、已暂存、已登记、失败、已取消、待核对。作业详情固定显示提交时的输入版本、执行位置、引擎／模型、需要补传内容和结果状态。

## 3. 页面与对话框

### 3.1 连接服务器

- 字段：地址、可选显示名、证书指纹（只读）、登记码、设备名。
- “测试连接”只验证地址、TLS、版本和登记码，不发送资料库内容。
- 指纹首次出现必须由用户确认；变化时默认阻止并给出“为什么变化”的说明。
- 成功后进入“选择资料库”：列出本地库、最后打开时间、大小和绑定状态；默认不勾选任何库。
- 取消／失败回到设置原位置，保留地址和已填设备名，清空登记码。

### 3.2 Server 仪表板

顶部四组摘要，不做总分：

1. **连接**：服务器、版本、在线状态、最近同步。
2. **归档**：有资格文件数／字节、服务器原件可用、待传输、待找回、缺失。
3. **备份**：最近独立备份代次、覆盖对象数、校验时间、未覆盖数。
4. **待处理**：冲突、待同步操作、运行作业、释放受阻。

下方分区：归档队列、独立备份、冷热与固定、同步冲突、远程作业、设备与存储。空状态明确“本库还没有归档资格”或“服务器尚未启用”，不显示零值绿勾。

### 3.3 归档计划

- 先显示范围：当前库／项目／会话；逐文件列表可按纳入、仅序列、排除、失败、待找回筛选。
- 摘要：纳入文件数、唯一内容数、总字节、已存在对象数、需上传字节、排除文件数。
- 逐项显示文件、拍摄、角色、来源、内容哈希前 12 位、字节、资格依据。
- 排除项只显示“仅保留历史”，不提供“加入归档”快捷按钮；恢复纳入必须走显式恢复流程并核验来源。
- 开始后关闭窗口不取消；再次进入显示同一计划、已完成项和剩余项。
- 失败项按文件重试，不重传整个计划；内容哈希不符时保留失败原因。
- 取消只停止未完成传输，不撤销已登记的有效引用。

### 3.4 独立备份

- 显示目标、故障域说明、最近代次、目录快照时间、对象数与字节、校验时间。
- “创建备份”先预览范围、缺项、所需空间；不把同池目录或同机快照标成独立。
- 备份进行中显示阶段：快照、复制、逐对象校验、完成收据；可取消未完成代次。
- 完成但校验失败时，代次标“不可用于恢复”，列出失败对象，不用部分成功冒充覆盖。
- “校验”只读检查；“修复”只补缺项；“恢复”进入恢复向导。

### 3.5 冷热与固定

- 照片检查器显示可用级别、代理来源、缓存位置、大小、最后校验、固定范围。
- 组／项目右键提供“固定离线可用…”，先显示将包含的照片、原片数、字节、已缓存和需下载。
- 释放本地副本前显示检查表：未固定、服务器可回取、独立备份已覆盖、无未同步编辑。任一项不满足，按钮禁用并给出原因与处理入口。
- 取回中断后保留已下载块；重试从断点继续。服务器离线时允许取消，不显示虚假完成。
- 代理与机内 JPEG 在检查器中分行显示，不能只写“JPEG”。

### 3.6 同步冲突

- 资料库工具和标题栏显示冲突数；冲突不阻塞本地浏览，但阻塞相关实体的“已同步”标记。
- 冲突列表按实体分组，显示字段、双方值、设备、时间、基准修订。
- 详情并排显示本机、服务器和共同基线；组冲突显示成员顺序、参与和缺帧；配方冲突显示版本和来源。
- 解决动作产生新的操作 ID 和修订；重复点击不重复应用。
- 关闭对话框不解决冲突；Escape 返回列表；没有“全部按最新覆盖”的批量危险动作。

### 3.7 远程作业

- 从组或照片的“制作”进入；执行位置默认“本机”，服务器可用且能力齐全时才提供“服务器”。
- 提交前显示冻结输入、顺序、替代 JPEG、缺帧、需补传文件、执行端能力、引擎／模型版本、预计输出类型。
- 缺输入时提供“补传并继续”或“改本地执行”，不能静默跳过。
- 运行中可关闭；任务中心按作业 ID 查询、取消、重试。断线后显示“待核对”，不自动重复提交。
- 结果先显示“已暂存／待预览”，用户查看后才“采用”或“登记为作品”；旧结果标“过期”，不替换当前版本。

### 3.8 恢复

- 选择备份代次后显示目录版本、对象数、字节、缺项、所需空间和恢复目标。
- 先恢复目录和关系，再逐对象校验；进度按阶段显示，不把复制字节当作完成。
- 部分成功可续跑；完成页列出已恢复、缺失、需重连、需重新登记的内容。
- 恢复到新设备时生成新设备身份；旧令牌不随备份恢复。
- 未完成或校验失败时不能显示“完整恢复”。

## 4. 交互规则

1. **先说明范围，再执行。** 归档、备份、固定、取回、释放和恢复都先显示作用于哪些照片、版本、文件和字节。
2. **可关闭，可回来。** 上传、备份、取回、同步和远程作业不要求窗口常开；再次进入按同一 ID 继续。
3. **失败保留原因。** 网络、磁盘、权限、哈希、版本和缺项分别说明；重试只重做失败项。
4. **取消不制造半成品。** 未完成上传、备份代次、取回文件和作业暂存可清理；已登记的有效引用不因取消被撤销。
5. **破坏性动作要确认。** 释放、撤销设备、删除归档引用、回收对象和覆盖冲突必须明确确认；默认不物理删除源文件。
6. **键盘与焦点。** 所有对话框支持 Tab／Shift+Tab、Escape 取消、Return 执行默认安全动作；冲突和恢复向导保留来源可读名称。
7. **窄窗与外观。** 390pt 宽时摘要改为单列，表格允许横向滚动但关键状态不被截断；浅色／深色下状态色与文字共同表达，不只靠颜色。
8. **可访问名称。** 状态徽标、进度、冲突双方、作业执行位置和备份目标都有完整读屏文本，不用“同步中”单独承担上下文。

## 5. 原型与走查

现有预演入口：[资料库工具 → Server](../../docs/ui/prototype/index.html#tools/server)。当前页面只提供三条模拟路径：归档与恢复、离线同步、远程作业。

原生实现前必须在该工作台补齐以下可操作场景，并写入覆盖表：

1. 未配置 → 指纹确认 → 登记码失败／成功 → 选择资料库 → 只同步目录。
2. 五文件样本归档计划 → 排除项灰显 → 中断续传 → 服务器原件可用但独立备份未覆盖 → 完成备份。
3. 冷片代理 → 取回中断 → 继续 → 哈希通过；固定项目 → 释放检查表 → 释放受阻与解除。
4. 双设备冲突：不同字段合并、同一评分冲突、组顺序分支、配方分支。
5. 远程作业：缺输入、排队、断线待核对、取消、重试、结果暂存与采用。
6. 异机恢复：代次预览、部分成功、缺项、重新登记设备。
7. 窄窗、浅／深色、键盘、Escape、焦点返回和读屏名称。

走查记录写入本目录的 `validation.md`；未完成浏览器与原生复验前，本规格只能标“交互已定义”，不能标“已实现”。
