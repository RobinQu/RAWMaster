# 040 · Server 交互与状态

2026-11-27 · 客户端入口、状态、Direct／Relay、元数据备份恢复、证书与所有权。产品要求见[规格](spec.md)，协议见[协议](protocol.md)，存储见[存储](storage.md)，安全见[安全](security.md)。本轮只定义交互，不改原生界面；现有[Server 规划预演](../../docs/ui/prototype/index.html#tools/server)仍用模拟状态。原生开工前按 [AGENTS](../../AGENTS.md) 更新同一工作台并走查。

## 1. 入口与归属

| 入口 | 作用范围 | 放什么 | 不放什么 |
| --- | --- | --- | --- |
| 设置 → Server | 设备与服务器 | 地址、证书指纹、私有 CA、登记、设备名、库绑定、S3 profile、备份目标、诊断 | 单张照片决定、编辑参数 |
| 资料库工具 → Server | 当前库 | 归档、Direct／Relay、对象状态、冷热、过期、所有权、元数据备份摘要 | 全局服务器安装 |
| 标题栏／状态区 | 当前库 | 在线／离线、证书变化、待上传、Relay、待备份、待恢复 | 详细日志 |
| 照片／组／项目上下文 | 明确选择 | 归档状态、固定离线、取回原件、释放本地副本 | 服务器地址、令牌 |
| 导入完成摘要 | 当前会话 | 纳入／排除／仅序列／失败、可归档数量与字节、开始归档 | 自动把排除项标成可归档 |
| 作业中心 | 当前库 | 上传、取回、备份、恢复、远程作业进度 | 改变已提交输入 |

**不新增第 4 个工作流。** 标题栏仍为「资料库／编辑／导出」。Server 是资料库的设置与工具页。

## 2. 状态词汇

### 2.1 连接与身份

| 状态 | 显示 | 可用动作 | 禁止暗示 |
| --- | --- | --- | --- |
| 未配置 | 设置入口、本地功能不受影响 | 连接服务器 | 已备份 |
| 连接中 | 地址、阶段、取消 | 取消、重试 | 在线 |
| 在线 | 服务器名、版本、最近联系、证书指纹 | 归档、取回、备份 | 底层存储可靠 |
| 离线 | 最近成功时间、待同步数、本地范围 | 重试、继续本地 | 已搜索全库 |
| 证书变化 | 旧／新指纹、原因 | 确认、取消、导出 | 继续写入 |
| 需重新认证 | 设备名、原因 | 重新登记、撤销本机 | 继续上传 |
| 版本不兼容 | 客户端／服务端版本、只读范围 | 检查更新、退出 | 写入成功 |

### 2.2 所有权

| 状态 | 显示 | 动作 |
| --- | --- | --- |
| 本机所有 | owner、epoch、最后写入 | 正常写入 |
| 他人所有 | 当前 owner、最后在线 | 只读、申请转移 |
| 转移中 | 双方、epoch、确认 | 确认／取消 |
| epoch 过期 | 旧客户端、fencing 原因 | 重新拉取、申请转移 |
| 恢复中 | 恢复代次、只读 | 等待、查看报告 |

第二客户端打开时显示“该库正在被另一台设备使用”，默认只读；不能静默抢写。

### 2.3 归档与对象

| 状态 | 含义 | 与相邻状态的区别 |
| --- | --- | --- |
| 未取得资格 | 最终排除、失败或未核验 | 不是“待上传” |
| 仅保留历史 | 只有来源、内容身份和处置 | 不是可恢复原件 |
| 待上传 | 有归档引用，无完整对象 | 不是“对象可用” |
| Direct | 客户端直传 S3 | 不是 Relay |
| Relay | Server 代理缺失 part | 不是失败 |
| 校验中 | 长度已到，核对 SHA-256 | 不是完成 |
| 对象可用 | S3 对象校验通过 | 不是“冷备已覆盖” |
| 引用已登记 | PostgreSQL 归档引用完成 | 需要对象可用 |
| 待找回 | 有资格但当前无对象 | 需要来源或冷备 |
| 缺失／损坏 | 曾登记但 S3 不可读／哈希不符 | 需要修复 |

**对象可用与外部冷备分开。** 外部冷备由 TrueNAS 负责；RAWMaster 可以显示“外部冷备未知／已确认”，不能把 S3 对象可用说成已有独立备份。

### 2.4 本地可用与过期

| 状态 | 显示 | 动作 |
| --- | --- | --- |
| 仅目录 | 缩略图／占位、需联网 | 取回代理／原件 |
| 代理可看 | 代理来源、尺寸、生成版本 | 取回原件、固定 |
| 原件已缓存 | 路径、校验时间、缓存级别 | 释放、固定 |
| 取回中 | 进度、已下载字节、Direct／Relay | 取消、暂停 |
| 已固定 | 固定范围、占用 | 取消固定 |
| 可释放 | 满足全部条件 | 释放本地副本 |
| 释放受阻 | 未固定、对象缺失、冷备未知、未同步、唯一副本 | 去处理 |
| 已释放 | 仅目录／代理仍可用 | 再次取回 |

过期状态：垃圾桶、草稿、版本、墓碑、暂存、备份代次各自显示到期时间；到期前可恢复或延长。

### 2.5 元数据备份与恢复

| 状态 | 显示 | 动作 |
| --- | --- | --- |
| 未备份 | 最近成功时间、覆盖率 | 创建备份 |
| 备份中 | 快照、dump、对象清单、上传阶段 | 取消（未完成代次） |
| 已验证 | 代次、schema、对象数、校验时间 | 恢复、删除 |
| 验证失败 | 失败项、保留代次 | 重试、查看日志 |
| 恢复中 | 隔离库、对象 HEAD、缺项 | 取消、查看报告 |
| 待核对 | 缺失对象、客户端补交、epoch | 处理、切换 |
| 完整 | 恢复回执、对象核对、客户端重连 | 关闭、导出报告 |

## 3. 页面与对话框

### 3.1 连接服务器

- 地址、可选显示名、证书链／SPKI 指纹、登记码、设备名。
- 私有 CA：导入／固定 CA；单证书：固定 SPKI。
- “测试连接”只验证 TLS、版本、登记码；不发送库内容。
- 指纹变化默认阻止写入，显示旧／新指纹和原因。
- 成功后选择库；默认不勾选。

### 3.2 Server 仪表板

四组摘要，不做总分：

1. **连接**：服务器、版本、证书、在线、最近同步。
2. **归档**：有资格文件、对象可用、待上传、待找回、缺失。
3. **元数据**：最近验证备份、代次、对象数、待恢复。
4. **待处理**：Direct／Relay 失败、证书到期、所有权、释放受阻。

下方：归档队列、对象存储、冷热与固定、过期、元数据备份、恢复、所有权。

### 3.3 归档计划

- 范围：库／项目／会话；筛选纳入、仅序列、排除、失败、待找回。
- 摘要：纳入文件、唯一内容、总字节、已存在对象、需上传、排除。
- 逐项：文件、拍摄、角色、来源、SHA-256 前 12 位、字节、资格依据。
- 排除项只显示“仅保留历史”，不提供快捷加入归档；恢复纳入走显式流程。
- 开始后关闭窗口不取消；再次进入同一计划。
- 失败按文件重试；取消只停未完成传输，不撤销已登记引用。

### 3.4 Direct／Relay 状态

- 每文件显示当前模式：Direct、Relay、Mixed。
- Direct 失败时显示原因和自动切换；用户不需要手动选。
- Relay 只显示“服务器中转”，不暴露 S3 凭据。
- 传输中断保留 part 进度；重试从缺失 part 继续。
- 收据可在详情查看模式、part 数、校验时间。

### 3.5 元数据备份

- 列表：代次、时间、schema、应用版本、对象数、校验状态、保留标签。
- “创建备份”先显示范围（全 Server）、预计大小、S3 目标、临时磁盘。
- 阶段：快照、pg_dump、对象清单、上传、隔离验证、完成。
- 未验证代次标“不可用于恢复”；失败保留。
- “验证”只读；恢复进入向导。
- 全量备份是默认；按库恢复后续，不在 V1 暴露。

### 3.6 恢复向导

- 选择已验证代次；显示库、对象、快照、缺失项、所需空间。
- 目标 PostgreSQL、S3 endpoint／bucket、证书／secret bundle。
- 步骤：校验文件 → 隔离恢复 → 迁移 → doctor → 对象 HEAD → 重置瞬态 → 只读启动 → 客户端重连 → 切换。
- 部分成功可续跑；完成页列出已恢复、缺失、需重连、需重新登记。
- 未完成／失败不能显示“完整恢复”。

### 3.7 冷热与固定

- 检查器显示可用级别、代理来源、缓存位置、大小、最后校验、固定范围。
- 固定组／项目先显示照片、原片数、字节、已缓存、需下载。
- 释放检查表：未固定、对象可用、外部冷备、未同步、非唯一副本。
- 取回中断保留进度；服务器离线允许取消，不显示虚假完成。
- 代理与机内 JPEG 分行，不能只写“JPEG”。

### 3.8 所有权转移

- 第二客户端显示当前 owner、最后在线、只读原因。
- 申请转移：服务器通知 owner（若在线）；owner 确认后递增 epoch。
- 旧客户端立即被 fencing；新客户端拉取最新修订。
- 恢复／换机走同一流程；不共享旧令牌。
- 转移失败保留原因，不静默变成可写。

### 3.9 证书与令牌

- 显示服务器证书链、SPKI、有效期、CA、最近轮换。
- 证书变化：旧／新指纹、原因、确认／取消；未确认不能写。
- 设备列表：名称、最后在线、令牌 key ID、撤销、轮换。
- secret bundle 状态：已加密、key ID、最近恢复；不显示私钥。
- 证书过期前提醒；过期后阻止写入。

## 4. 交互规则

1. **先说明范围，再执行。** 归档、备份、恢复、固定、取回、释放都显示照片、版本、文件、字节。
2. **可关闭，可回来。** 上传、备份、恢复、取回不要求窗口常开；按同一 ID 继续。
3. **失败保留原因。** 网络、TLS、S3、Postgres、checksum、证书、配额分别说明；重试只重做失败项。
4. **取消不制造半成品。** 未完成上传、备份代次、恢复、取回可清理；已登记引用不因取消撤销。
5. **破坏性动作要确认。** 释放、撤销设备、删除引用、回收对象、转移所有权、恢复切换必须确认。
6. **键盘与焦点。** Tab／Shift+Tab、Escape 取消、Return 安全默认；恢复向导保留来源可读名称。
7. **窄窗与外观。** 390pt 单列；表格横向滚动但关键状态不被截断；浅／深色用文字＋颜色。
8. **可访问名称。** 状态、进度、Direct／Relay、证书、备份代次、所有权有完整读屏文本。

## 5. 原型与走查

现有预演：[资料库工具 → Server](../../docs/ui/prototype/index.html#tools/server)。原生实现前补齐：

1. 未配置 → 私有 CA／单证书 → 指纹确认 → 登记失败／成功 → 选择库。
2. 五文件归档 → Direct → 断网 Relay → 续传 → 对象可用 → 引用登记。
3. 元数据备份 → 验证 → 恢复向导 → 空 PostgreSQL → 对象缺失 → 客户端重连。
4. 证书变化／过期 → 阻止写入 → 确认／轮换；令牌撤销／轮换。
5. 单客户端所有权 → 第二客户端只读 → 转移 → 旧客户端 fencing。
6. 冷片代理 → 取回中断 → 继续 → 固定 → 释放检查表。
7. 窄窗、浅／深色、键盘、Escape、焦点返回、读屏。
