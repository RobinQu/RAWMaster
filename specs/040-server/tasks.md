# 040 · Server 任务与发布门

2026-11-26 · 规划任务，均未开始。任务按可独立演示的增量拆分；完成一项不等于发布门通过，证据写入本目录或对应专项的验证记录。产品要求见[规格](spec.md)，技术方案见[plan.md](plan.md)。

## 0. 交付原则

- **先契约后代码。** S0 冻结身份、归档资格、操作信封、备份代次和错误码；后续实现不得私自改变语义。
- **先正确后规模。** 五文件样本、断点、恢复和冲突矩阵通过后，才做吞吐与容量。
- **每个任务都有真实输入。** 使用隔离资料库、真实 RAW／JPEG 样本和真实网络故障；不用合成状态代替对象校验。
- **不跨阶段声明。** S1 不能标 Server 1.0；S2 不能标冷热与同步完成；S4 不能标远程计算全面可用。

## S0 · 契约与夹具

- [ ] **SRV01 · 冻结身份与操作信封。** 确认 `libraryID`、`deviceID`、`commandID`、`baseRevision`、`payloadVersion`、服务器修订和收据的字段、唯一约束与错误码。准备固定 JSON 夹具和未知版本样本。[数据模型](data-model.md) · [协议](protocol.md)
- [ ] **SRV02 · 冻结归档资格。** 把 033 的五文件样本转成服务端可复核的封存快照、排除项、仅序列项、恢复纳入和失败项夹具；确认服务端不依赖来源目录扫描。[归档资格](../033-library-lifecycle/spec.md#每个导入原件的归档资格)
- [ ] **SRV03 · 冻结备份代次与恢复清单。** 固定目录快照、对象清单、资源、成片、缺项和校验收据格式；明确哪些内容可重建、哪些不进备份。[备份实体](data-model.md#24-备份与恢复)
- [ ] **SRV04 · 冻结作业与能力描述。** 固定输入顺序、内容版本、配方、引擎／模型、所需能力、输出类型、取消／重试和结果登记语义。[作业实体](data-model.md#25-作业与执行端)
- [ ] **SRV05 · 评审 UI 状态与入口。** 把[交互规格](ux.md)落到现有摄影工作台；补齐连接、归档、备份、冷热、冲突、作业、恢复场景。浏览器走查记录写入 `validation.md`，不修改原生生产界面。[覆盖表](../../docs/ui/coverage.md)

## S1 · 连接与服务器目录

- [ ] **SRV10 · 服务端进程骨架。** Rust 单二进制；配置、日志、健康、优雅退出、数据目录初始化；默认仅监听局域网。[技术方案](plan.md#4-部署)
- [ ] **SRV11 · TLS 与服务器身份。** 自签或受管证书；`GET /server` 返回版本、指纹和能力；客户端固定指纹并处理变化。[协议](protocol.md#31-服务器与登记)
- [ ] **SRV12 · 设备登记与撤销。** 一次性登记码、按设备令牌、摘要存储、撤销、过期和速率限制；令牌只进钥匙串。[安全要求](spec.md#68-运维安全与兼容)
- [ ] **SRV13 · 资料库绑定与多库。** 按 `libraryID` 幂等绑定；同 ID 不同来源拒绝；列出库、状态和水位。[协议](protocol.md#32-资料库绑定)
- [ ] **SRV14 · 每库目录与操作日志。** 打开 SQLite 目录、应用现有命令、生成收据、维护操作水位；未知 schema 拒绝写入。[现有命令](../../Modules/LibraryCatalog/src/authority.rs)
- [ ] **SRV15 · 客户端连接设置。** 设置 → Server：地址、指纹、登记码、设备名、库选择、测试连接、错误与重试；未确认指纹前不发送内容。[交互](ux.md#31-连接服务器)
- [ ] **SRV16 · 健康与基础诊断。** 在线／离线／版本不兼容／需重新认证状态；最近同步、存储摘要和日志关联 ID。[状态词汇](ux.md#2-状态词汇)

**S1 出口。** 新服务器可被一台 Mac 连接并绑定资料库；错误指纹、过期登记码、撤销设备和更高写版本被拒绝；服务器离线不影响本地打开、导入和已有编辑；客户端不会暗示已归档或已备份。

## S2 · 归档、备份与恢复

- [ ] **SRV20 · 归档计划。** `POST /archive/plans` 逐文件复核资格、内容身份、字节和缺项；排除项只返回历史；重复计划幂等。[协议](protocol.md#34-归档与内容传输)
- [ ] **SRV21 · 断点上传与暂存。** 分块、区间、重复块幂等、到期清理、`complete` 校验；未完成对象不可见。[传输要求](spec.md#63-传输校验与主存)
- [ ] **SRV22 · 对象发布与去重。** 长度＋SHA-256 校验后原子发布；相同内容只存一份；多引用分别保留；失败可重试。[内容身份](data-model.md#1-身份与权威边界)
- [ ] **SRV23 · 归档引用与状态。** 登记 `archiveRef`；主存、待找回、缺失、损坏分别显示；恢复纳入追加事件。[归档状态](ux.md#22-归档与备份)
- [ ] **SRV24 · 归档队列与客户端关闭／续跑。** 上传可关闭窗口、重启后续跑；按文件重试；取消不清除已登记引用。[交互](ux.md#33-归档计划)
- [ ] **SRV25 · 同代目录快照。** 使用现有目录内核生成可打开的 SQLite 快照；记录 schema、水位、清单摘要和完整性检查。
- [ ] **SRV26 · 独立备份。** 预览范围、复制对象、逐对象校验、代次收据；同池目录／同机快照不得标独立；失败代次不可恢复。[备份要求](spec.md#64-独立备份与恢复)
- [ ] **SRV27 · 恢复向导与服务端恢复。** 代次预览、目录优先、对象校验、部分成功续跑、缺项报告；新设备重新登记；不覆盖活动库。[协议](protocol.md#35-备份与恢复)
- [ ] **SRV28 · 五文件端到端。** 归档、备份、异机恢复、排除项零引用、恢复纳入只增一项；断点、重复、哈希不符、磁盘满和权限错误。[验收场景](spec.md#9-验收场景)

**S2 出口（Server 1.0 首个可发布增量）。** 五文件样本归档与备份清单精确；断点续传不重复；独立备份恢复到新机逐对象哈希一致；排除项不进入归档；主存与独立备份状态分开；恢复报告列出缺项。

## S3 · 冷热、离线与同步

- [ ] **SRV30 · 代理生成。** 服务端或受控本地生成 JPEG 代理与缩略图；代理键含源内容、尺寸、色彩和生成版本；可删除重建；与机内 JPEG 分标。[代理要求](spec.md#65-冷热数据代理与离线固定)
- [ ] **SRV31 · 冷热状态与取回。** 仅目录、代理、原件缓存、需联网、取回中、固定、可释放；Range 下载、断点、哈希核对。[协议](protocol.md#34-归档与内容传输)
- [ ] **SRV32 · 固定离线。** 照片／组／项目范围；先显示照片、字节、已缓存和需下载；固定状态属于设备，不被回收。[交互](ux.md#35-冷热与固定)
- [ ] **SRV33 · 受控释放。** 检查未固定、服务器可回取、独立备份已覆盖、无未同步编辑；任何一项不满足显示原因；不释放唯一副本／引用盘。[释放规则](spec.md#65-冷热数据代理与离线固定)
- [ ] **SRV34 · 同步 outbox 与收据。** 持久队列、批量、重试、按 `commandID` 去重、同 ID 不同载荷拒绝；不重复上传回声。[协议](protocol.md#33-操作同步)
- [ ] **SRV35 · 变更拉取与快照。** 游标增量、分页引导、快照后追平、新设备引导；不传输活动数据库。[同步实体](data-model.md#22-操作与同步)
- [ ] **SRV36 · 冲突矩阵与解决。** 同字段、不同字段、标签、集合、组、配方、删除、迟到结果；冲突可见、可选择、产生新修订。[冲突矩阵](data-model.md#3-同步冲突矩阵)
- [ ] **SRV37 · 双设备故障矩阵。** 离线修改不同字段、同一评分、组顺序、配方、删除／恢复、重复／乱序／超时；无静默丢失。[验收场景](spec.md#9-验收场景)
- [ ] **SRV38 · 冷热与同步端到端。** 冷片代理切完整 RAW；断网修改后重连；释放门槛；代理与机内 JPEG 分标。[验收场景](spec.md#9-验收场景)

**S3 出口（Server 1.0）。** 冷片可代理浏览并取回完整原件；双设备离线修改后字段合并／冲突可选；释放条件不可绕过；服务器离线不降级本地已有能力；跨库查询明确覆盖范围。

## S4 · 远程作业（Server 1.1）

- [ ] **SRV40 · 能力登记与匹配。** worker 注册 CPU／GPU／内存、引擎、模型、许可和版本；缺能力时列出缺项并禁用提交。[作业要求](spec.md#67-远程计算)
- [ ] **SRV41 · 作业提交与输入解析。** 冻结输入、顺序、替代 JPEG、缺帧和内容版本；需补传文件逐项列出；同 `jobID` 重试幂等。[协议](protocol.md#36-作业)
- [ ] **SRV42 · 队列、租约、取消与重试。** 排队、进度、租约、崩溃回收、取消清理；断线按 `jobID` 查询；未发布暂存可清理。[作业实体](data-model.md#25-作业与执行端)
- [ ] **SRV43 · 输出暂存与单次登记。** 校验长度、摘要、可读性；`jobID` 唯一约束登记派生作品／版本和来源；重复回调只一次。[输出规则](spec.md#67-远程计算)
- [ ] **SRV44 · 过期结果与采用。** 输入变化后旧结果标过期，不覆盖当前版本；采用由用户明确操作。[版本规则](spec.md#67-远程计算)
- [ ] **SRV45 · 远程作业端到端。** 断网、修改组、重试原请求、服务器重启、取消、失败和迟到回调；只产生一个绑定原输入的结果。[验收场景](spec.md#9-验收场景)

**S4 出口。** 断线重试只登记一份结果；缺引擎／模型／输入时明确禁用；取消／失败不产生作品；旧结果不自动采用；Mac 专用链路不被冒充为跨端一致。

## S5 · 容量、运维与发布

- [ ] **SRV50 · 容量测量。** 现有库＋受控放大样本：文件数、拍摄数、关系数、版本数、查询时延、归档吞吐、恢复时长、内存和存储；100 TB／200 万文件单独立项。[容量边界](spec.md#10-成功标准)
- [ ] **SRV51 · 周期校验与修复。** 主存和备份的缺失／损坏报告；只补缺项；修复收据可审计。[备份校验](spec.md#64-独立备份与恢复)
- [ ] **SRV52 · 保留与回收。** 保留代次、删除意图、回收期限、引用计数；默认不删唯一副本；可撤销。[保留规则](data-model.md#7-保留回收与删除)
- [ ] **SRV53 · 升级与回退。** 升级前备份、未知版本拒绝写入、只读路径、回退条件；客户端／服务端版本握手。[兼容要求](spec.md#68-运维安全与兼容)
- [ ] **SRV54 · 监控与审计。** 健康、容量、归档／备份覆盖率、队列、冲突、作业、最近错误；日志不含令牌／凭据。[可观察性](spec.md#68-运维安全与兼容)
- [ ] **SRV55 · 灾备演练。** 从独立备份恢复到隔离机器；核对目录、对象、决定、组顺序、编辑依赖和成片；记录缺项与耗时。[恢复要求](spec.md#64-独立备份与恢复)
- [ ] **SRV56 · 安全复核。** 错误指纹、过期码、撤销设备、错误令牌、重放、路径逃逸、公开暴露、日志泄漏。[安全约束](protocol.md#6-安全约束)
- [ ] **SRV57 · 发布评审。** 把规格、数据、协议、任务、验证和已知限制放在同一评审包；未通过项明确保留，不用“规划完成”替代验收。

**S5 出口。** 容量与恢复演练有可复现报告；升级和回退路径可用；安全复核无未处置 P0；Server 1.0／1.1 的发布范围与限制对用户可见。
