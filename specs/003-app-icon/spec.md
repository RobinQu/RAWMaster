# 003 · 自适应应用图标

用户已选择第二轮 C 系列作为最终方向：C2 为 light，C1 为 dark；自动切换。

- macOS 支持图标外观时，由系统选择原生浅色 / 深色图标，覆盖应用运行与退出状态。
- 自动模式随系统明暗切换；用户固定图标样式、清透或染色模式时遵循系统选择。
- 保留两片青蓝紫原色层、C2 钴蓝交叠与 C1 亮色交叠。
- 去掉概念稿外部留白和预制圆角外框，由系统统一裁切。
- 不将应用工作台的固定深色主题作为图标外观依据。
- 旧系统提供静态浅色 ICNS 后备；旧系统自动切换不在本次范围。

验收：构建资源同时含 Aqua / DarkAqua 图标栈，各自只显示对应图案；两版图像内容不同；保留 16–1024 像素后备尺寸；系统渲染预览无概念稿外框或杂点。

2026-10-24 视觉简化：浅深两版保留叠层、配色和交叠关系，移除素材中的顶部强光、发亮描边和厚重玻璃材质；背景接近纯色，只保留平缓的颜色过渡。使用 LightMinimal / DarkMinimal 源图，旧版本保留。系统外框的轻微反光继续遵循原生渲染。
