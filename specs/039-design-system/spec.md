# 039 · 界面规范

本规范约束 RAWMaster 的可见界面：尺寸、间距、字级、颜色、控件状态、版式与原生/自绘边界。目标是让资料库、编辑、导出和设置在后续迭代里保持同一套设计语言，而不是每个面板各起炉灶。

参考对象是 macOS Photos 的整体界面语言（检查器的等距滑块、扁平菜单、平面勾选、分组展开），但它只作为外观与交互参考：RAWMaster 保留自己的工具分类、草稿语义和 RAW 算法，不复制 Photos 的专有能力，也不把模拟值当输出。

## 适用范围

| 范围 | 规则 |
| --- | --- |
| 照片编辑工作区（检查器、左栏、画布工具条、Prompt） | 使用本规范的自绘控件与令牌 |
| 资料库、拍摄组、导入、导出、设置 | 容器与导航使用系统控件；密度更高的列表可复用本规范的行高与字级 |
| 菜单、工具栏、弹窗、表格、系统设置表单 | 保持 macOS 原生，不重绘系统材质与焦点环 |
| API 与数据 | 界面规范不改变配方、版本、导出与撤销语义 |

## 三层模型

1. **令牌（Tokens）**：`Sources/RAWMaster/DesignLanguage.swift` 的 `AppDesign`。只有这里可以出现尺寸、间距、圆角、字号和墨色数值。
2. **原语（Primitives）**：照片检查器的共享控件 `PhotosSliderRow`、`PhotosFlatButtonStyle`、`PhotosFlatCheckboxStyle`、`PhotosFlatTabs`、`PhotosFlatMenu`、`DevelopmentNumberField`，以及 039 新增的 `AppIconButton`、`AppSectionHeader`、`AppHint`、`AppReadout`（`Sources/RAWMaster/DesignControls.swift`）。新代码只用 `App*` 名称，旧名是过渡别名。
3. **界面（Surfaces）**：由原语组合出的面板。界面文件里不得再出现行高、字号、圆角或临时透明度的字面量。

新增控件前先检查原语清单；能组合就不新增类型。

## 原则

- **照片是判读中心。** 控件只用中性墨色与单一强调色，不用渐变、投影或彩色底占据画面。颜色只表达状态，不表达装饰。
- **密集但可读。** 参数标题、轨道与精确数值共用一行；说明完整换行，不压缩行距，不用缩写替代可读标签。
- **位置表达作用域。** 顶栏切换工作流，右栏图标切换面板，浮动条只作用于当前照片；控件不承担导航职责。
- **原生优先。** 系统已有语义的控件不重绘；自绘只在系统控件达不到密度、键盘或渲染要求时使用。
- **状态可恢复。** 悬停只是补充反馈；键盘可达、焦点可见、禁用保留数值和原因，取消与撤销回到操作前。

| --- | --- | --- |

| `Radius.control` | 5 | 按钮、菜单、滑杆轨道、行选中 |
| `Radius.container` | 7 | 浮动工具条、卡片、弹层容器 |
| `Radius.composer` | 9 | Prompt 输入区 |

### 墨色与填充

- 主墨色：亮色白度 0.15、暗色 0.91；次级为 72%，三级为 50%。
- 填充：常态 7%、悬停 12%、按下 17%、禁用 4%；禁用不透明度 0.45。
- 行选中：强调色 13%。强调、保留、警告、评分色沿用 `AppPalette`。
- 滑杆轨道：底 7%（禁用 3.5%）、已填充 12%（禁用 6%）、指针 34%（禁用 17%）；刻度主线 58%、次线 33%。
- 分隔线使用系统 `separatorColor`；非法输入使用系统红。

### 动效

- 展开与折叠：0.16s ease-out；悬停：0.09s。
- 尊重“减少动态效果”；该设置开启时不播放展开与悬停动画。
- 动效只用于展开、选中和出现，不用于数值跳动或照片本身。

## 控件目录

### 参数行（滑杆）

- **使用时机**：连续标量调整。离散选项用分段或菜单。
- **解剖**：26pt 轨道 + 6pt 刻度带；标题在轨道左侧内缩 8pt；精确数值框 66pt（宽面板可 70/78pt），右缩 7pt；只有读数时显示等宽数字。
- **刻度**：21 格，每 5 格为主刻度；只在悬停、拖动或聚焦时绘制，行位置不变。
- **交互**：水平拖动；方向键按步长；双击复位（可选 Shift 单独自动）；Option 拖动可触发溢出提示（按控件定义）。
- **状态**：禁用时轨道、指针、刻度一起降级，数值保留；不显示刻度的空占位。
- **代码**：`PhotosSliderRow` → `PhotosNativeSlider`。新代码用 `AppSliderRow`。

### 数字输入

- **使用时机**：所有可精确输入的数值。禁止再用 `TextField().textFieldStyle(.roundedBorder)` 表达同一语义。
- **解剖**：高 21；右对齐；等宽数字；集成在参数行时无边框，独立时使用系统圆角边框。
- **校验**：只接受有限数值、区间内、无千位分隔；非法值保留编辑内容、红框和帮助文字，不写入。
- **键盘**：回车提交并结束编辑；Escape 恢复进入编辑前的值；输入法组合期不提交。
- **代码**：`DevelopmentNumberField` / `DevelopmentNumberInput`；新代码用 `AppNumberField`。

### 勾选

- **使用时机**：布尔开关。编辑面一律平面 14pt 方框；设置与弹窗使用系统 checkbox；不使用 switch 表达编辑参数。
- **状态**：选中用强调色描边与 12% 填充；悬停不上色，只保留可点光标；焦点环包住 20pt 区域。
- **代码**：`PhotosFlatCheckboxStyle`；新代码用 `AppFlatCheckboxStyle`。

### 分段标签

- **使用时机**：2–5 个互斥视图切换，例如直方图/波形/矢量。
- **解剖**：24pt 高、11pt、选中半粗并带 2pt 强调色下划线；间距 4。
- **边界**：超过 5 项改用菜单；系统容器内的阶段切换可用 `.segmented`，但同一屏不要混用两种形态。
- **代码**：`PhotosFlatTabs`；新代码用 `AppTabs`。

### 菜单

- **使用时机**：选项较多或需要显示当前值。
- **解剖**：26pt 高、圆角 5、12pt medium、左缩 8、右侧箭头；悬停 12%、按下 17%、禁用 4%。
- **边界**：工具栏、弹窗和设置使用系统 `Menu` / `Picker`；编辑面使用扁平菜单。
- **代码**：`PhotosFlatMenu`；新代码用 `AppMenu`。

### 按钮

- **文字按钮**：26pt 高、11pt medium、横向内边距 7、圆角 5；常态 7%、悬停 12%、按下 17%、禁用 0.45 不透明度。
- **图标按钮**：26×26 命中区，图标 12–13pt；必须提供辅助功能标签与工具提示；不得用 24/27/28/32 等临时尺寸。
- **主操作**：一个区域内只允许一个强调按钮；编辑面用强调色文字或 `AppPalette.accent`，系统表单用 `.borderedProminent`。
- **代码**：`PhotosFlatButtonStyle`、`AppIconButton`。

### 分组头

- **解剖**：32pt 高；左侧 10pt 展开箭头 + 13pt 半粗标题；右侧可带自动、启停与复位。
- **状态**：整行悬停 4% 底色；复位只在组被修改后可点；停用后保留全部数值。
- **边界**：密排列表使用 22pt 折叠头，不与 32pt 主分组混在同一层级。
- **代码**：`AppSectionHeader`；照片检查器的完整变体见 `PhotosAdjustmentSection`，迁移时收敛。

### 说明与读数

- 说明 10pt、次级墨色、完整换行，禁止逐行截断；读数 12pt 等宽数字、72% 墨色。
- 说明与上一组的间距 12，不紧贴控件边缘。

### 系统控件

以下场景保持原生：应用菜单与快捷键、工具栏、`NavigationSplitView` 侧栏、设置 `Form(.grouped)`、弹窗与确认框、文件面板、表格、系统颜色面板。不要在这些容器上手绘背景或替换系统焦点环。

## 版式

- **检查器**：左右内边距 12；分组内行距 4；分组间 12；面板分节 16。标题、轨道与数值同一行；窄窗先压缩数值宽度，再允许标题省略，说明换行。
- **左栏**：分区标题 34pt 行高、12pt；条目 25pt 行高、11pt；图标列与文字列对齐。
- **资料库**：网格、胶片带、比较与评分保持现有密度；标签与按钮沿用同一字号表，不用 13pt 以上的自绘按钮。
- **导出**：面板内边距 14，容器圆角 7；预设、目标、预览顺序不变。
- **设置**：系统 `Form` + `.grouped`；只统一 `controlSize`、分节标题与说明字号，不替换系统控件。
- **弹窗**：明确标题、正文、取消与确认；破坏性操作使用红色；宽度不超过 510（另有明确内容需求时除外）。

## 交互与状态

| 状态 | 规则 |
| --- | --- |
| 悬停 | 只作补充；不得承载唯一信息；无悬停能力的输入设备也能完成操作 |
| 焦点 | Tab 顺序跟随视觉顺序；方向键在分段与滑块内移动；焦点环 1.5pt 强调色 |
| 按下 | 底色 17%；拖动期间只在开始与结束各触发一次手势与一次撤销 |
| 禁用 | 不透明度 0.45；保留数值；工具提示说明原因 |
| 非法输入 | 红框 + 范围说明；不写配方；Escape 恢复 |
| 撤销 | 一次连续拖动只产生一次撤销；数字输入提交算一次 |
| 减少动态效果 | 关闭展开/悬停动画；不改变布局结果 |

## macOS 版本策略

- 最低版本保持 macOS 15。所有 26 及以上 API 用 `if #available(macOS 26, *)` 分支。
- 运行在 macOS 26 及以上时，系统控件自动采用 Liquid Glass。不要给工具栏、侧栏、弹窗叠加自定义材质；浮动条优先使用系统材质。
- macOS 26 起 `Slider` 原生支持刻度、`neutralValue` 与 `enabledBounds`。评估用原生滑杆替换自绘轨道的条件：先满足刻度显隐、双击复位、一次手势一次撤销和辅助功能标识，再切换。
- 新增 `.glass`、`.glassProminent` 或 `glassEffect` 前，先在原型的浅色/深色与降低透明度下走查，并确认不会与照片内容竞争。

## 原型与走查

- 入口：[摄影工作台 → 资料库工具 → 界面规范](../../docs/ui/prototype/index.html#tools/design)。
- 画廊覆盖：参数行（常态/悬停/聚焦/禁用）、数字校验、勾选、按钮与图标按钮、分段、菜单、分组折叠、令牌表、检查器版式与评审清单。
- 浏览器回归：`python3 scripts/check-ui-prototype.py`；设计页纳入[功能覆盖表](../../docs/ui/coverage.md)。
- 原生证据：`DesignGallery` 由 `DesignSystemTests` 渲染浅色/深色 PNG，命令见 [验证记录](validation.md)。

## 治理

新增或修改控件按以下顺序：

1. 在现有原语中找可复用项；找不到才新增，并在本规范登记解剖与状态。
2. 先更新原型 `#tools/design` 的画廊标本，走查浅色、深色、390pt 窄窗、键盘与减少动态效果。
3. 令牌只在 `AppDesign` 增加；界面文件不得出现新的尺寸、字号、圆角或墨色字面量。
4. 原生实现与画廊使用同一组输入和动作；在特性验证记录里链接原型与原生证据。
5. 补测试：令牌数值、控件高度、画廊渲染；涉及输入语义时补键盘与输入法用例。

评审清单：行高只允许 26/22/32/24；字号只允许 13/12/11/10/9；颜色来自 `AppDesign.Ink` 或 `AppPalette`；悬停不是唯一反馈；禁用保留值；数字输入有范围、回车、Escape 与输入法处理；浅色、深色、窄窗各走查一次。

## 现状与迁移清单

2026-11-26 已完成的收敛：

- 滑杆、按钮、勾选、分段、菜单、数字框改由 `AppDesign` 取尺寸、字级与颜色；检查器的 26+6 行高和刻度带保持不变。
- 新增 `AppIconButton`、`AppSectionHeader`、`AppHint`、`AppReadout` 与原生 `DesignGallery`。
- 原型新增可操作的界面规范画廊。

尚未收敛、按批次迁移：

| 范围 | 现状 | 目标 | 优先级 |
| --- | --- | --- | --- |
| 旧初修面板参数行 | `DevelopmentParameterRow` 用 SwiftUI `Slider` + 独立标签行 | 改用 `PhotosSliderRow` | 高 |
| 导出数字输入 | `TextField.roundedBorder`，无范围校验 | `DevelopmentNumberField` | 高 |
| 蒙版 / AI 蒙版面板 | 行高 28、`.caption`、自有按钮网格 | 26/22 行高 + `AppIconButton` + `AppHint` | 中 |
| 预设浏览器 | 11pt 密排行 23/25 | 22pt 密排行 + 统一悬停 | 中 |
| 工作流胶囊与侧栏 | 12pt/28pt 胶囊、独立行样式 | 保留胶囊导航，字号与行高对齐令牌 | 中 |
| 图标按钮 | 24/26/27/28/32 五种尺寸 | 26pt `AppIconButton` | 中 |
| 设置页 | 系统表单，控件尺寸不统一 | 只统一 `controlSize` 与分节 | 低 |
| 勾选/分段第三种形态 | 系统 checkbox/segmented 与自绘混用 | 按容器边界保留系统形态，编辑面只用自绘 | 低 |

旧类型别名（`PhotosFlatButtonStyle` 等）在本规范生效期内保留；下一个大版本移除。

## 验收

- 令牌与规范表一致，测试 `DesignSystemTests` 通过。
- 检查器行高、刻度带、数字框宽度在浅色、深色和窄窗下不重叠。
- 画廊可操作，状态与键盘路径完整，覆盖表可进入。
- 新增界面代码不出现本规范之外的尺寸、字号、圆角与墨色字面量。
- 迁移清单内的旧面板在替换前不得再扩展第二套同类控件。
