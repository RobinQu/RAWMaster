# 界面与操作设计草案

状态：用户已批准 A → B。保留现有工作台、快捷键与照片优先的布局。本文描述目标体验，实际验证见 validation.md；连拍建议因缺独立留出样本按 SC05 延后正式入口。

## 1. 设置 → 外观

菜单“RAWMaster → 设置…”或 ⌘, 打开独立设置窗口。

```text
外观
  [ 浅色预览 · C2 ]  [ 深色预览 · C1 ]  [ 跟随系统 ]
  当前：跟随系统 · 深色

  自动保存，切换立即生效。
  运行中 Dock 可随应用主题变化；Finder 等位置遵循 macOS 图标设置。
```

建议默认选“跟随系统”。选项始终显示用户选择的档位，而不是把 system 偷换成当前解析出的 dark。系统切换时仅“当前”状态变化；手动档不变化。不新增时刻、独立图标或独立画布设置。

| 元素 | 浅色 | 深色 | 保持一致 |
|---|---|---|---|
| 工作台/画布 | 无色偏浅灰 | 无色偏深灰 | 图片像素、缩放与位置 |
| 面板/表单 | 浅底深字 | 深底浅字 | 布局、键盘焦点、字段值 |
| 选择 | 可辨识边界与浅色强调底 | 可辨识边界与深色强调底 | 当前资产和多选范围 |
| 保留/排除/星级 | 适配浅底的状态色 | 适配深底的状态色 | 图形、文字和含义 |
| 图片叠层 | 自带可读性背景 | 自带可读性背景 | 预览/RAW 来源标记，不遮挡主体 |

切换不关闭弹窗、不重置输入、不跳转照片；普通窗口、导入、交付、组编辑、空状态及错误状态均列入双主题验收。

## 2. 找回原片

缺片卡片保留原缩略图与决定，信息栏显示“原片不可用”和原位置。“查找原片…”只处理当前资产；会话菜单“重新定位来源…”处理整个会话。复制模式分别标明“原始来源”与“受管副本”。

```text
选择目录 → 核验中（可取消）→ 核验报告 → 应用已匹配位置
                                   ↘ 取消：不修改当前路径
```

报告顶部显示范围与数量；表格列出原文件、候选路径、匹配状态及原因。默认仅勾选唯一且内容核验一致的匹配；歧义项必须选定位置，内容不同项不可勾选。提交按钮显示“应用 146 项匹配”，而不是笼统的“修复全部”。部分成功后列出剩余 6 项，不宣称整批恢复。

核验期间继续浏览已缓存照片；RAW 查看/交付只对已实际可用内容开放。退出后保留扫描会话，重新进入时先复核证据，不自动提交旧结果。目录和内容不符的文件继续保持原有身份及决定，提示另行接入新素材。

## 3. 识别拍摄组

从工具栏菜单打开“识别拍摄组…”：先确认当前项目/会话或显式选择的范围、照片数量和扫描是否完整，再点“生成分组建议”。不因为工作台默认选中一张图就误把整批操作缩成一张，也不把范围默认为全库。

完成后提供非强制通知“发现 12 个待确认候选”；不自动移动正在看的照片。用户主动打开“待确认分组”后进入临时审阅范围，关闭时恢复之前的工作范围、焦点、缩放与视口。

```text
待确认分组                 当前候选 · 8 张
  时间与画面接近 · 8 张      [有序缩略图 / 原有比较入口]
  时间邻近 · 4 张            依据：拍摄间隔、画面相似；时间精度说明
  证据不足 · 3 张            用途：[普通连拍 ▾]  名称：[...]
                            [拆分] [与候选合并] [忽略] [确认分组]
```

“时间邻近”与“确认连拍”分开表达；不展示未经校准的“98% 正确”标签。候选中的 P/X/U 仍只做照片决定。确认组是单独按钮，可先纠正成员/类型；有既有组重叠先预览影响，不能把确认候选等同覆盖旧组。

首轮按单候选确认，不加入无人审阅的一键全收。失败项显示原因与重试，不成为排除建议。支持取消正在计算的任务，已生成/确认部分保留。

## 4. 正式组、保护与恢复

已确认组默认显示锁定标记；“锁定”表示自动分析不能改写，不妨碍用户自己调整。组菜单可改名、改用途、拆分、合并及调整成员顺序；保留已有比较与独立照片决定入口。

涉及组内参与状态变化时显示影响列表。普通照片排除不弹出“将移出序列”的错误提示；只有用户实际移出输入时提示。“不再独立精选”与“仍参与延时/HDR”等可同时成立。

当前运行的 ⌘Z 按真实操作顺序工作。重启后从“最近组操作”复核最近一次可恢复的组命令，按钮说明恢复范围；存在后来冲突变更时先报告原因，不直接覆盖。该入口不宣称已支持所有历史照片决定的跨次撤销。

## 5. 各交付段的演示

A1：同一组照片在三档间切换 → 系统外观改变 → 重启 → 偏好/照片状态保持。

A2：测试副本换根 → 查找目录 → 核验部分成功 → 应用匹配 → 原 RAW 细节与交付恢复，旧决定仍在。

B1：手动组改类型/拆分/合并 → 检查参与冲突 → 撤销 → 重启后的最近组操作恢复。

B2：明确范围生成候选 → 继续原工作台选片 → 主动审阅并纠正 → 确认并锁定 → 重算不覆盖。
