# 042 · 本地资料库与制作任务

2026-11-28 · **当前 macOS 客户端版本。** 摄影师可在受支持的本地卷创建和打开资料库，从相机卡导入、在本机编辑和处理，并在「制作任务」继续未完成的工作。建库、切库、任务调度与恢复可在断网的新安装上验收。本机 Flux 在模型就绪后可离线运行。[实施计划](plan.md) · [任务盘点](task-inventory.md) · [验证](validation.md)

## 1. 当前版本的交付范围

| 功能 | 本版本可独立使用的结果 |
| --- | --- |
| 选址建库与打开 | 新建资料库包时指定名称与位置。用 Finder 双击、应用菜单或最近打开进入同一包 |
| 多资料库 | 一次打开一个库。可创建、移动、拷贝多个库包，每库保存自己的选片和编辑上下文 |
| 兼容已有目录 | 识别升级前的默认库、自选旧目录、无清单的已建库包和备份。提供可验证的迁移与恢复入口 |
| 本地任务 | 在同一入口查看导入、032 交付、分组、场景批次、本机生成、备份和索引等任务。按任务可用操作取消、继续、重试或核对结果 |
| 设备任务 | 模型和运行时下载的状态独立于当前库。切库后继续，退出后凭设备侧清单续做 |

Server 建库与同步、远程作业和远端取回由后续版本接入本版本公开的会话与任务入口。[040 Server](../040-server/spec.md) · [041 Server 图像作业](../041-server-image-editing/spec.md)

## 2. 首次打开与资料库菜单

| 场景 | 用户操作与结果 |
| --- | --- |
| 新安装，找不到已使用的目录 | [开始页](../../docs/ui/prototype/index.html#welcome)显示「新建资料库…」「打开已有资料库…」。新建时填写名称并在系统选取器中选定保存目录，初始提示位置为 ~/Pictures。所选目录不可写时可换目录，完成前无活动库，取消回到开始页 |
| Finder 双击、打开方式或「资料库 → 打开资料库包…」 | 使用同一打开流程。冷启动按传入包打开。运行中若同一包已打开，激活当前窗口。打开另一包时显示当前库、目标库及目标路径，由用户确认是否切换。Finder 一次传入多个包时让用户选一个 |
| 普通启动 | 先恢复上次成功打开的包和该库的项目、筛选、选片及焦点。上次地址不存在或身份变化，显示库名及最后位置，提供重新定位、打开其他库和返回开始页。旧路径上的其他文件保持原状 |
| 升级后首次启动 | 上次明确选择的位置优先。没有选择且存在可验证的 Application Support 旧目录时继续打开它，提供「迁移到资料库包…」。无可用旧目录则显示开始页 |
| 两个库同名 | 菜单「最近打开」列出库名及位置。两个包分别识别，只有成功激活才更新最近项 |

应用的「资料库」菜单提供新建、打开、最近打开和「资料库与备份」。标题栏左侧显示当前库名称。右键或用键盘打开名称下的路径菜单，可查看库包及上级目录。在原生菜单中可定位到 Finder 或拷贝完整库路径。空库可以发起导入。未选片时编辑、导出不可用，任务列表显示空状态。[标题栏与路径原型](../../docs/ui/prototype/index.html#library/project/river) · [走查](validation.md#切库确认与标题栏路径)

Finder 的库包以及标题栏路径菜单的首项采用[资料库文件夹图标](../003-app-icon/spec.md#资料库文件夹图标)。上级目录继续使用各自的系统图标。

## 3. 库包、移动与拷贝

工作库是 Finder 中作为单个文稿显示的 `.rawmasterlibrary` 目录。包内保存 SQLite 目录、必要编辑资源、托管在包里的原片及任务记录。打开已移动的包时，应用按已核验的新包根重新绑定包内路径。包外引用继续保留原卷和内容身份，离线时可浏览已有预览并重新定位原片。最近位置与应用设置保存在偏好设置，共用模型和可再生缓存位于 Application Support。

| 操作 | 身份与任务 |
| --- | --- |
| 关闭后在 Finder 移动或改名 | 可证明为原包时保留 `libraryID`、历史、批次和选片，更新位置。绝对路径绑定的输入和目标仍需核对 |
| 跨卷且移动身份有歧义 | 显示旧、新位置，用户明确选择「接续原资料库」或作为独立库。接续核对库身份、目录与必要资源，确认原位置已退出使用后更新位置 |
| 拷贝后打开 | 同一 ID 出现在另一仍可用的位置时，确认「作为独立本地库打开」，新分配 `libraryID`。照片、作品和版本的库内身份与关系保留。原任务收据可作为历史查阅，副本从空的执行队列开始，重新确认源卷与交付授权 |
| 打开备份代次 | 先核验清单，再恢复到新位置，默认使用新的库身份。用户随后可查看缺失项或接回原件 |
| 崩溃后打开或升级旧库 | 一致地恢复 SQLite 及其伴随文件。迁移先取快照，在新位置重写和核验编辑资源与包内路径，成功后激活目标。源目录保留，可从原位置恢复 |

普通包可在本机可写卷与本地挂载的外置卷打开。网络共享或同步盘可存已关闭的副本，使用前复制到受支持的卷。Finder 操作在关闭库后进行，活动库的复制使用应用的备份／快照。包所在卷离线时保留当前会话或停在恢复页。

## 4. 切库、关闭与退出

1. 先只读预检目标。存在活动库时弹窗确认切换。有可运行的本库任务时，默认选项是「等待任务完成后切换」。也可选「暂停任务并切换」，让可以续做的任务在安全检查点停下。保存、备份等必须完成的操作在弹窗中说明，期间只可等待或取消。暂停、离线、待核对的记录和设备安装下载仍保留各自状态。
2. 等待时当前库继续持有资源，已经提交的任务继续运行，并停止接收新的业务操作。等待进度显示当前任务和「查看制作任务」，可以取消切换回原上下文。任务完成后或选择暂停时，核对未落盘草稿，提供保存、放弃或取消。关闭前保存旧库的浏览范围、筛选、选片、焦点及可恢复编辑状态。
3. 关闭旧库的写连接与 worker 后释放文件锁和 bookmark，再激活目标库。激活失败恢复旧库的会话和任务入口。所有异步完成事件都绑定所属库及打开代次，旧库回调无法写入新库。
4. 重开某库时显示原来未完成的任务与收据，由任务类型决定可自动恢复、需要用户继续或先核对。应用退出时封存进度供下次启动恢复。同一台 Mac 的第二个进程打开同一包时，拒绝竞争写入并说明原因。

主工作台和辅助窗口共用同一活动库。033 的显式只读联合检索使用指定库的索引，写入仍归当前活动库。[切库原型](../../docs/ui/prototype/index.html?batchNativeReview=1#tools/package) · [走查](validation.md#切库确认与标题栏路径) · [033 本地联合检索](../033-library-lifecycle/search.md)

## 5. 制作任务

从资料库、编辑或导出顶栏的波形图标打开「后台信息」，选择「任务」。导出工作台的「任务详情」可回查原件、清单或本次成片交付。列表显示当前库的业务任务，以及标明「设备」的模型／运行时任务。查看详情可以核对归属、输入范围、当前阶段、等待原因和已完成项。关闭详情回到列表，关闭后台窗口后继续原选片、编辑或交付。任务继续从各自的业务入口提交。[工作台原型](../../docs/ui/prototype/index.html#jobs)

| 用户状态 | 处理与反馈 |
| --- | --- |
| 排队／准备／执行 | 显示当前步骤或实际进度。可以换片、关闭面板。任务允许时可取消，取消等待安全停止 |
| 等待 | 提示缺原卷、目标卷、权限、空间、模型或资源。必要时提供接回、授权、重新准备或返回原业务入口 |
| 已暂停／中断 | 保存逐项进度。重新打开原库后，安全重放的内部工作可由调度器重领。会写用户目标文件或需重做模型推理的任务先核对，显示继续动作 |
| 结果待核对 | 用原会话、批次、文件票据或生成尝试核对已经产生的结果。状态未明时禁止直接追加重试 |
| 已取消／失败 | 保留已完成项及收据，解释失败原因。有可继续项时沿用原任务和冻结输入。修改输入、配方或目的地需要重新预检 |
| 已完成 | 指向具体收据、已写文件、候选或任务报告。生成候选、采用版本和写盘是可独立检查的动作 |

首批接入导入、032 成片与原件交付、已安装模型的本机 Flux、038 批次。随后在当前版本内接入已有分组制作、长时间重定位、备份与旧目录迁移、索引及设备安装任务。有持久记录的操作沿用原记录。没有可验证检查点的操作按原业务语义显示可重做或核对。列表空状态、禁用原因、原卷离线、失败、取消、重试和已有领域撤销都在原型及原生验收覆盖。[逐项盘点](task-inventory.md) · [验收场景](validation.md)

拖动滑杆、缩放、网格读页、临时蒙版、查看导出预览等短请求由会话调度。可再生缩略图、预取和缓存维护按优先级让出前台资源，按需重建。

## 6. 发布验收

1. 在无配置、断网的签名客户端上建两个位置不同的库，从 Finder 和菜单逐次打开，切回时恢复选片。模拟丢失最新地址和同路径换盘，保留原数据。
2. 关闭后移动同一包，保留身份和可恢复批次。打开拷贝，验证新身份、作品和版本完整、源包未变以及执行授权已隔离。真实旧库含 WAL、包外原片和必要资源做迁移回读。
3. 导入一批照片并中断续做。提交 032 交付，在保留已完成收据的前提下测试切库、关闭重开、原卷接回、取消和继续。验证两个库的任务和文件写入互不串库。
4. 断网时运行已安装模型的本机 Flux 与 038 批次。验证失败重试、逐项恢复、候选与采用分离、旧 head 冲突和已有撤销。未安装模型时其余本机功能仍可操作。
5. 原生复验空状态、键盘焦点、浅／深外观与可支持的最小窗口宽度。任务忙碌时实测画布和资料库交互，记录前台延迟及结果数量。
