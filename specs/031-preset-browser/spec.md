# 031 · 滤镜与可复用预设

2026-11-22 · macOS 编辑工作区 · 承接 028 的 M2/M3。目录已与 Camera Raw 基础编辑及本地 AI 蒙版集成。版本、性能对照、原尺寸输出和待验项目有独立记录。[集成验收](integration-validation.md) · [功能范围与迁移支持](feature-validation.md)

摄影师能在左栏文字目录找到自适应滤镜、基础滤镜、Spektrafilm 胶片模拟和个人导入预设，在主图试看并采用，再把自己的做法保存给下一张。迁入的 Adobe 条目显示当前照片可用的字段、分析需求和依赖。个人 Lightroom／Camera Raw 预设可通过 XMP 或 ZIP 手工导入。[既有滤镜与性能契约](../028-filter-experience/spec.md) · [目录与 XMP 调研](../../docs/research/lightroom-preset-browser-plan.md)

场景生成卡由右栏管理。保存为个人预设时记录场景目标、保护语义、参考用途及经核验的风格包版本。应用到另一张图重新准备范围并显式生成；本片的像素补丁留在自己的历史中。031 的外观预览与 XMP 迁移沿现有快速路径执行。[生成卡、风格包与采用合同](../030-ai-retouching/generative-editing.md)

## 界面与操作

- 在编辑工作台导入、导出或保存预设，目录读取失败，或用户主动准备语义选区与散景时，操作结果显示在发起照片的主图顶部。写入与分析期间可查看进度；XMP 预检和结果保留逐项明细，表单保留名称等字段校验，删除个人预设仍需确认。从资料库返回该照片，可逐条关闭结果。[实际入口与走查](../025-editing-workspace/editor-rails.md)
- 左上是独立的 RAW 摘要。左下的滤镜、快照、历史共用一块面板。滤镜强度在搜索框上方，搜索框紧邻同一棵文字目录。四根依次是「自适应滤镜」「基础滤镜」「胶片模拟」「用户导入滤镜」，根之间用留白。搜索右侧的星标只显示收藏，保留每个条目的原目录和 ID。
- 自适应预设按人像、天空、主体、风景、模糊背景分组，迁入的自适应颜色和黑白配置文件另在「配置文件」。经过来源确认的 Adobe 条目使用 Lightroom 简中名称。原名和本地名称都可搜索，导入和导出保留原字段。用户预设及自定义组保留作者命名。HDR 草稿支持在原生侧栏浏览该目录，采用兼容滤镜及调节其强度需要 SDR 编辑。[走查与名称来源](../025-editing-workspace/editor-rails.md)
- 滤镜标题右侧提供复位、圆形启停和管理操作。交换沿用原有导入、保存和导出入口。启停与复位作用于当前基础与胶片滤镜，折叠结束临时预览和候选准备并保留设置。检查器使用 4／7／12 点间距，说明完整换行。折叠、星标、菜单均保有独立焦点，取消后返回原照片、检索与所选条目。[标题区与焦点走查](../021-photos-editor/validation.md#无聚焦边框与滤镜标题区)

- 「胶片模拟」提供九款 Spektrafilm 官方模型外观：Portra 400／Portra Endura、Velvia 100、VISION3 250D／2383，以及 Gold 200／Ultra Endura、Portra 800／Supra Endura、Ektar 100／Portra Endura、Provia 100F、Ektachrome 100 和 VISION3 500T／2383。目录注明「官方模型 · SDR 色彩外观」。使用固定模型烘焙的 64³ 色表，不冒充社区作者调好的 P800 Vintage 或 Clean 系列，也不包含颗粒、光晕或 HDR 成像。鼠标悬停或键盘聚焦时在当前照片、当前版本的主图临时试看，移开或 Escape 还原。点击或回车采用后可调强度、撤销、移除胶片、存快照或版本；曝光、裁切与蒙版保留。撤销后只标记配方中实际采用的一款，不把上次浏览项也标为已采用。关闭目录、换片或退出编辑返回原选片上下文。浏览目录时滤镜缩略图请求为 0。[可操作原型](../../docs/ui/prototype/index.html#edit/development) · [九款目录与走查](film-catalog-validation.md) · [原生实现与验收](directory-delivery.md)
- 社区作者 Look 与官方 stock 模型分开。bazdesh 的 P800 Vintage、Clean 和 Velveetia 包含实际显影、耦合剂、印相与扫描调参；当前没有确认允许一般 App 内置分发的独立许可，旧 experimental JSON 也没有固定引擎提交。本次不打包这些作者资产。来源、修正版与限制见[社区候选](film-catalog-validation.md#社区作者候选与许可边界)。HDR 主干、显示与输出的目标设计见 [037](../037-color-film-hdr/spec.md)，不是这九款 SDR 色表的新增能力。
- 名称优先用文件中的本地化名称，组缺失则归入 Imported。按组、排序名及显示名稳定排列，重名保留来源和独立身份。依赖详情能找到隐藏 Look，搜索结果和收藏不将它们提升为独立可套用的风格。
- 鼠标停留或键盘聚焦时，在当前照片临时呈现基础滤镜、胶片、个人预设与导入条目的可用配方。可用的全质量配方通过同一预览入口请求。普通 XMP 含未映射字段时，试看显示已映射且兼容的子集，详情提供实际遗漏字段。逐图蒙版在停留后准备，经过来源与修订校验才可呈现，移开会取消。缺少依赖或可用字段的条目显示原因。离开、Escape、比较、按住原片、裁切、换片或其他编辑立即结束临时展示。点击或回车采用后可撤销。
- 右栏「智能预设」按场景选择任务、在本张确认范围并试看。纪实组照由「同组参考配平」显示参考张与逐张例外。已保存或导入的语义配方可从左栏重用同一套参数和蒙版。风格浏览、收藏、保存和常规应用都可离线完成。[按场景的智能预设](../030-ai-retouching/scene-presets.md) · [左栏、蒙版、智能卡的交互和视觉评审](../030-ai-retouching/ux-design.md)

## 功能契约

| 编号 | 开发与验收共同遵循的行为 |
| --- | --- |
| FR-001 | 目录按稳定 ID 搜索、分组与收藏。新建、改名、移动、替换或复制用户项时保留身份与版本关系。迁入旧滤镜收藏。浏览 1,075 条测试元数据时，目录请求的滤镜缩略图为 0 |
| FR-002 | 预设按字段保存。缺省表示沿用当前值，显式 0 表示设置为 0。只写曝光的 XMP 保留同组其余字段。一次有变更的采用按当前照片修订提交一笔历史。重复命令、无变化、失败或取消均不新增历史 |
| FR-003 | Amount 用应用前的不可变配方计算。对经验证支持连续强度的字段，0 为原基线、100 为完整效果。一次拖动合并为一个手势。用户手改、撤销、换片或切换版本即结束此会话。离散选择、Profile Amount、Delta64 强度及未知 SupportsAmount2 各自按能力展示 |
| FR-004 | 每项分别记录入库状态、源适用条件、已映射字段和渲染依赖，以及本张照片的分析状态。可查看阻塞原因。严格应用须满足全部必需条件。部分应用只在有实际可用字段且用户确认清单后执行，预览、保存及历史采用同一字段集并标明略过项 |
| FR-005 | 普通预设、显影 Profile、内部 Look 和照片 sidecar 分开识别。独立选择 Profile 保留已有滑杆。校验 RAW/JPEG、相机限制、彩色/单色、SDR/HDR 和 Process Version。版本或必要源事实不明，状态为待验证 |
| FR-006 | 用户可手工导入原生文件、XMP 或 ZIP。一次性限定迁移由诊断命令执行。系统源与用户源均按审核过的路径、大小和 SHA 核对，复用现有事务入库，生成可复算的收据。来源、未知字段和依赖关系可在本机查看 |
| FR-007 | 原生 `.rmpreset.json` 支持用户所选的原生状态和有版本的依赖引用，逐项标明跨片可复用性。Adobe 导出提供已验证字段、排除项及原因。按来源权限原样导出与按当前调整新写 XMP 使用不同命令。Adobe 内置项只用于本机授权副本，默认个人预设导出排除它们。严格完整导出遇到固定 LUT、未验证曲线、语义或源绑定修复等缺项时停下 |
| FR-008 | 语义预设保存目标、顺序、增减关系、局部参数。采用时冻结本张的遮罩。重开读冻结结果，跨片重新解析目标。目标不存在保留原图并记录跳过。混合预设中缺失必需部分按 FR-004 处理。模型更新后用户可显式重算并生成新版本 |
| FR-009 | 只在 ready 快照上进行语义悬停预览，冷分析由用户明确准备或应用触发，进度可见且可取消。打开目录、悬停、搜索、收藏的模型调用、云上传和生成任务数均为 0。结果晚到时逐项校验照片、当前修订、展示和请求 |
| FR-010 | 单张场景卡、批量与左栏预设从同一采用入口验证步骤、祖先配方与来源。普通参数可批量，选区逐图确认或重算。传统克隆与生成式改写均受严格纪实约束。候选生成须在精修流程明确发起，照片采用记录支持离线回放。[030 采用与回滚契约](../030-ai-retouching/plan.md) |

## 成功标准

| 编号 | 发布判据 |
| --- | --- |
| SC-01 · 找到并试用 | 提议用 6 名摄影师实操。至少 5 人在 30 秒内找到指定收藏、试看并采用，均能还原原片。键盘全程可用，VoiceOver 区分目录、收藏、预览、采用和不可用原因 |
| SC-02 · 主图与目录 | 在 1,075 行夹具连续搜索、折叠、滚动和交叉悬停，滤镜候选位图请求、误写历史、晚到错片各为 0。支持域内的普通预设暖呈现与同字段手调在同源同机成对测量，p95 不高于手调。Classic Filters 另须达到 028 的窗口 p50 ≤20 ms、p95 ≤33 ms，冷启动另列 |
| SC-03 · 保存与交换 | 全部指定的旧配方、稀疏覆盖、原生往返、缺项、Amount 和撤销用例通过。每个宣布支持的 Adobe 字段都有指定 PV 与实机导出再导入的参数记录。像素还原标签只用于已固定源、基底、输出和误差门槛的组别 |
| SC-04 · 迁移可恢复 | 在冻结样本上逐字节核对 78 个 SHA、72 项可见、12 条内部引用、1 条缺失外部 Look 和 6 条相机基底依赖。重复导入新增重复项为 0。模拟打断后目录只指向已校验文件，源 SHA 全部保持一致 |
| SC-05 · 逐片语义与审计 | 同图重开和导出调用模型 0 次，跨片复制遮罩或补丁 0 次。无目标、多人、旧模型、取消及严格纪实用例均有可检查的结果。摄影师节时、蒙版交互、组照配平和回放按 030 SC-01/02/03/05 验收，右栏选卡按 030 SC-07 验收 |

执行顺序、负责人角色和实际验证状态见[实施方案](plan.md)、[可领取任务](tasks.md)、[验收记录](validation.md)与[三板块研发计划](../../docs/planning/24-mask-preset-retouch-roadmap.md)。规格采用按用户故事组织需求、独立验收与成功标准的结构。[Spec Kit 规格模板](https://raw.githubusercontent.com/github/spec-kit/main/templates/spec-template.md)
