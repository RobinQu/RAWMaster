# 031 原生目录、采用与离线回放验证

下文源码和测试对应独立功能提交 `d0091997`。在任一工作树执行 `git show d0091997:路径` 可读取指定文件。[独立版本与构建收据](feature-validation.md)

2026-11-22 在 macOS 隔离工作树执行。原生功能专项通过 18 项，其中 Core 8 项，编辑会话与编辑器 10 项。测试覆盖个人预设文件导入导出、导入目录事务、实际成片与备份恢复。Adobe 限定清单、XMP 双向映射及 Lightroom 回读的适配结论由[交换验证](validation.md)记录。

## 实测路径

| 项次 | 功能操作 | 实际结果 |
| --- | --- | --- |
| 1 | 将 V2 的 +1 EV 与红色曲线经无关编辑提升为 V3，分别捕获，再换片采用 | 两份稀疏配方一致。带新旧两个曝光阶段时，50% 分别混合。目标禁用组的未选阴影和启用状态得到保留 |
| 2 | 导出个人预设，重新导入，在另一目录实例改名、移动、复制、删除并重开 | 稳定 ID 与版本关系保留，未知文件字段和过期替换被拒绝，已采用照片可继续解码 |
| 3 | 16 个目录实例同时创建个人项 | 最终读取 16 个独立 ID |
| 4 | 在已有旧域曝光与裁切的照片上，以 50% 采用曲线与暖色分级 | 中点从 0.5 变为 0.61，暖色饱和度为 15，原曝光和裁切保留 |
| 5 | 在其他源上选择完整配方，尝试存入无来源的旧 subjectPNG | 提示同源限制，旧像素层无法进入完整预设；仅勾选曝光的文件可跨片使用 |
| 6 | 从 V2 单独保存曝光和高光并在另一 V2 照片上采用 | 在旧渲染阶段混合到 +0.5 EV、高光 −17.5，目标阴影 −16 得到保留 |
| 7 | 交叉导入、校验错误原件、重复 SHA、撤销共享批次 | UUID 冲突和原件 SHA 不符时整批不发布。撤销后仍有其他批次引用的资源可用，历史原件可以读取 |
| 8 | 应用显式零曝光和单通道曲线 | 目标其他光线字段、蓝曲线、红通道输入范围及现有蒙版保持原值 |
| 9 | 对 1,075 行元数据搜索、加载双目录、查询收藏和重名 | 十个经典候选可见。Profile 独立列出，内部 Look 与照片 sidecar 隐藏，重名结果保留不同 ID |
| 10 | 主图临时试看，点击采用，拖动 Amount 经 50%、0%、80% 再到 50%，撤销重做 | 每次结果从采用前配方计算，0 恢复原基线，整次拖动一笔历史。过期修订与未验证的导入 Amount 被拒绝 |
| 11 | 将两层源照片天空意图换片，准备、试看、采用、重开；另测缺失、迟到与取消 | 目录与冷悬停推理 0 次。同一目标准备一次产生两层独立 ID，选区属于新照片。确认只写一笔历史，重新解码和撤销重做均不推理。无目标保留照片并显示跳过 |
| 12 | 保存有来源的完整天空蒙版预设，原生导出到第二个目录，在原图恢复；再损坏资产、更换原图 | 目录索引只含资源哈希。完整文件能携带经解码验证的 Gray8 PNG。显式试看写历史 0 次，采用后存入原片配方。坏资产或错片被拒绝；原始 SHA 一致但 EXIF 方向或源尺寸改变时，预览和采用都拒绝，提交与历史均为 0 |
| 13 | 从实际编辑器采用、等待 live draft 落库，生成 16 位 PNG 候选；删除用户预设，再备份、恢复到空资料库 | live draft 和不可变版本持有采用记录。恢复版本的配方、预设 ID、版本、字段、结果指纹、成片 SHA 均一致 |
| 14 | 在正常编辑控制器中对普通预设悬停，再将同项改为缺少依赖 | 临时主图有结果，候选缩略图及用户分析请求 0 次，原配方和历史不动。阻塞项终止预览并拒绝采用 |
| 15–16 | 两项旧收藏回归，分别读取旧收藏 ID 与损坏、未知、原片 ID | 旧收藏排序稳定，非法条目被忽略 |
| 17–18 | 两项旧滤镜回归，分别验证独立临时 consumer 和交叉悬停迟到帧 | 临时帧不写历史；迟到结果无法覆盖已采用的主图 |

原生 Core 用例位于`Tests/RAWMasterCoreTests/DevelopmentPresetTests.swift`。会话、编辑器和真实保存分别位于[EditingDevelopmentSessionTests](../../Tests/RAWMasterUITests/EditingDevelopmentSessionTests.swift)及[PhotosDevelopmentIntegrationTests](../../Tests/RAWMasterUITests/PhotosDevelopmentIntegrationTests.swift)。
