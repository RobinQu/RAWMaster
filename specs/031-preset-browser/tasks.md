- [ ] **T002 · QA + Imaging**。为 V1–V7 建立自有稀疏 XMP、旧六槽与内嵌主体 PNG 配方、无目标/多人/方向变换 RAW、目录压力夹具。固定样片、版本、环境、对照方法与每项像素容差。先为 V1/V2/V5 提供可运行的小集，其他专项随对应里程碑扩充。可与 T003 并行。
- [x] **T003 · Core**。在 `Sources/RAWMasterCore/DevelopmentAdjustmentCommands.swift` 所在模块定义逐字段差量、Amount 策略、源适用规则及具体采用记录。在 `EditingDevelopmentSession.swift` 接入比较修订、一次提交、手势合并和 Undo。用显式零、同组省略值、过期修订及重试证明原子性。
- [x] **T004 · Core/存储**。建立全局条目、版本、依赖与内容库，历史固定已采用的字段和资源引用，收藏绑定逻辑 ID。验同 SHA 合并、同 UUID 异内容分流、并发替换、删除预设后离线重开。依赖 T003 的身份与引用约定。

## US3 · 可审计迁移与 Adobe 普通子集

- [x] **T009 · Core/格式**。实现有界 XMP/RDF 和 ZIP 读取、原始字节保留、Preset/Profile/Look/sidecar 分类，输出含 PV、ISO、源限制、未消费字段和依赖的报告。依赖 T001。先用至少 20 个有代表性的文件和自制样本，另以元数据/授权本地资源测大目录。
- [x] **T010 · Core/存储**。对两个源根的冻结范围执行一次性工程迁移。核对路径、大小和 SHA，原子发布目录并验证重跑、已撤销批次、原始文件及依赖。V4 实测 78/72 和 12/1/6。[迁移收据](evidence/frozen-exchange/receipt.json)
- [ ] **T011 · Core/格式 + Imaging**。落实字段/PV 支持表和严格/部分应用。第一片以 Exposure2012、可验证的 Basic/点曲线子集贯通，分别对照八色 HSL、旧六槽、单色和范围溢出。依赖 T002 的 V2/V3 样本、T003、T009。将每项支持标到文件/参数/行为/像素等级。
- [ ] **T012 · Core/格式 + QA**。实现新写 XMP 子集与原字节再导出两个入口，在 Lightroom Classic 实机回读。核对每项声明、排除清单、PV、UUID 和省略字段，确认 19 个真实文件都得到准确的依赖解释。依赖 T009、T011。限定迁移对用户开放需另通过 T010。
