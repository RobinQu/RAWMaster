## 从搜索框到模型与结果

1. **元数据过滤。** 搜索框区分普通文本、标签与自然语言。普通文本和标签经 `SearchFolderPage`，输入自然语言时等待正式提交才启动推理。文件名、镜头和相机等先写成查询列，SQL 使用字段掩码和规范化文本进行匹配。DuckDB FTS 的 BM25 另用于 AI 描述、标签和场景组合文档，在相应字段全开且索引可用时参与查询。可借鉴这种分工，为文件名与 EXIF 设独立的精确、范围及文本查询路径，让语义模型缺失时仍可浏览和过滤。[搜索路由](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/ui/alcedo_main/album_backend/search_controller.cpp#L130-L183) · [字段谓词](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/storage/query/library_search_predicates.cpp#L294-L348) · [BM25 作用域](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/storage/query/library_search_predicates.cpp#L363-L405)

2. **生成图像向量。** `SemanticInputImageService` 固定已提交的编辑快照。无编辑时优先读取内嵌相机预览，否则渲染快照。桌面应用批量调用本机 Rust `puerh_mind` 的图像编码服务，按请求关联返回值，再写入 DuckDB。协议 V2 显式携带请求和模型信息。将输入资产或版本、代理的来源、预处理、模型和维度写入任务与结果，将来同一个任务才能在不同执行器间重试。本期可以先在本机实施这一契约。[选择内嵌预览或编辑快照](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/app/semantic_input_image_service.cpp#L193-L232) · [批量调用](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/app/semantic_generation_service.cpp#L498-L545) · [映射结果并写库](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/app/semantic_generation_service.cpp#L874-L946) · [Rust 服务协议](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/rust/puerh_mind/proto/semantic.proto#L83-L139)

3. **存储及模型切换。** 项目记录模型 ID、修订、维度、输入尺寸、引擎、提示配置及资源清单。图像向量分别存入 512 和 768 维定长数组表，主键均为 `(file_id, model_key)`。该主键没有独立的内容或编辑版本字段。若 RAWMaster 支持搜索原貌和成片，需明确默认视图，并把输入版本及其用途纳入向量身份。只有完成整代构建和校验后才切换活动索引，保留人工人物关联和纠错。[模型与向量表](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/include/storage/store/database.hpp#L135-L179) · [模型记录](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/include/storage/store/semantic/semantic_records.hpp#L16-L41)

4. **文本编码与精确排序。** `ProjectService` 在打开工程时接入语义检索提供者。查询向量和中性短语 `a photo` 的向量按模型键与文本缓存。SQL 先限定集合、活动查询模型及已就绪记录，再算余弦相似度。排名分数为查询相似度减去中性短语相似度，平分按文件 ID 升序。这个版本使用精确扫描。其 SigLIP2 样本校准得相似度下限 0.0855，范围内至少有 30 张已评分照片时，另要求相对分数的 z 值至少为 1。改变搜索范围就可能改变一张照片能否入选。RAWMaster 在现有照片上以原始余弦为参照单独对比这项校正，分别报告中英文、全集、小集合和高重复连拍的结果。实测后再考虑近似索引。[项目安装提供者](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/app/project_service.cpp#L621-L626) · [文本向量缓存](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/app/project_service.cpp#L143-L160) · [数据库入口](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/app/sleeve_filter_service.cpp#L239-L252) · [规则与校准来源](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/include/storage/store/semantic/semantic_vector_search.hpp#L19-L43) · [限定候选的 SQL](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/storage/store/semantic/semantic_vector_search.cpp#L105-L145)

5. **模型与平台。** 上游模型清单包含 English MobileCLIP2 S2（512 维）、多语 Jina CLIP v2 INT8（原始 1024 维，截取到 512 后 L2 归一化）、多语 SigLIP2 B/32 256 ONNX（768 维）和单独的原生 macOS Core ML SigLIP2 配置（768 维）。Rust 实现提供 ONNX 和 Core ML 引擎。相同维度不保证权重或预处理相同，切换引擎时须用相同图文对核对距离及排名，判定是否允许共用索引。上游清单注明 Apple AMLR、Jina CC BY-NC 4.0。其对 SigLIP2 标注 Apache-2.0，并说明选用的转换仓库缺许可标签。RAWMaster 选型时应核对实际权重、转换版本和随包材料。[模型修订与许可记录](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/app/model_asset_catalog.cpp#L22-L54) · [MobileCLIP 与 Jina](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/app/model_asset_catalog.cpp#L59-L105) · [SigLIP2 两种配置](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/app/model_asset_catalog.cpp#L122-L170) · [ONNX 引擎](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/rust/puerh_mind/src/service/ort_clip.rs) · [Core ML 引擎](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/rust/puerh_mind/src/service/coreml_clip.rs#L436-L464)

## 需要单独验证的产品能力

- **人物和 GPS。** 在该提交的应用、查询表、维护中的 UI、推理服务及测试中，未发现从人脸检测、对齐、人物向量到身份聚类与人工命名的整条调用链。也未发现 GPS 坐标查询列、空间索引或多边形过滤入口。分割协议中的 People／Person 返回像素掩膜，只能支持编辑选区。RAWMaster 仍需独立评测小侧脸和误合并、跨照片的同一人检索，以及围栏边界、跨 180° 和无 GPS 值的处理。[分割操作](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/rust/puerh_mind/proto/segmentation.proto#L13-L45) · [分割结果](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/rust/puerh_mind/proto/segmentation.proto#L180-L190) · [目录可查询列](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/src/include/storage/store/database.hpp#L29-L53) · [语义服务接口](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/rust/puerh_mind/proto/semantic.proto#L7-L28)
- **回归样例。** 上游测试明确覆盖未就绪向量、范围改变、无关查询、重复分页、旧 HNSW 索引清理和 768 维模型。可将这些输入条件写入 RAWMaster 的小库回归。质量对照使用同一批实际照片和人工标注，记录查询集、模型制品摘要、候选数、Top-K、延迟与索引体积。媒体缺少已标注的人物或地标时单列覆盖缺口。上游断言及阈值均不能代替本项目的测量。[上游检索回归](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/tests/storage/semantic_storage_controller_test.cpp#L265-L559) · [维度及输入校验](https://github.com/zidage/AlcedoStudio/blob/61d59bc98afad3be7b0d855bebdb86d7b9225e62/alcedo_studio/tests/storage/semantic_storage_controller_test.cpp#L607-L728)
