# 资料库检查、筛选与智能检索

2026-11-22 · 阶段二交付检查器、结构化查询和连拍复核。阶段三交付文搜图、人物聚类及地理围栏。可限定单个库、文件夹、项目或集合。使用多库时明确勾选查询的库，结果保留各自的来源与版本，范围与可用索引覆盖分别展示。[资料库阶段](spec.md) · [项目筛选与操作范围](../007-project-review/spec.md)

## 检查一张照片或一组连拍

- 网格与单张检查器显示文件／拍摄身份、文件和代理位置、原件与备份状态、相机、镜头、时间及偏移、焦距、ISO、光圈、快门、曝光补偿、尺寸和色彩空间。RGB 直方图指明采样来自机内 JPEG、缓存代理或哪一版渲染。离线仍可读取已索引的元数据，原始细节可用时才显示原片级的判断依据。
- 提供 IPTC 标题、说明、作者、版权、分层关键词的查看、批量修改和撤销。多选时区分共有值与混合值，写入前说明目标数。文件夹、集合、可保存的筛选和多图总览（Survey）进入资料库浏览。人物视图随人物索引交付。快速显影、发布与评论为后续候选。
- 在具备相应元数据的机型和格式上，以相机记录的 AF 点叠加于照片。保存来源坐标与方向，旋转、裁切和缩放后正确映射。缺失记录时显示“无可用对焦点”。机型及原始文件支持范围需用实拍样本列明。[Adobe 对焦点查看](https://helpx.adobe.com/lightroom-classic/desktop/viewing-photos/view-focus-points-in-photos.html)
- 连拍默认进入对比复核，可查看主体／眼部区域的实际像素。清晰度属性包含机器判断（清晰、疑似失焦、无法判断）、区域、图像来源、置信度、方法版本和独立的人工结论。可确认或纠正失焦，并按机器或人工结果过滤。低纹理、拖影和缺少 AF 记录都有各自的证据状态。允许带失焦标记正常导入、归档和参与序列，最终导入排除由用户另作处置。

## 查询能力

| 查询方式 | 输入与结果 |
| --- | --- |
| 文本、属性与元数据 | 文件名、标题、说明、IPTC 和关键词支持文字查询。旗标、星级、颜色、镜头、机型、ISO、光圈、快门、焦距、日期、地点、格式、编辑／导出状态、可用性、审阅和清晰度可组合筛选。可选元数据列提供分项计数，查询可命名保存为智能集合，规则或成员属性改变时重新求值。[Adobe 资料库过滤](https://helpx.adobe.com/lightroom-classic/desktop/organize-photos-in-lightroom-classic/finding-photos-catalog.html) |
| 文本按画面找图 | 单独提供按画面内容搜索，用文本和图像表征匹配，支持中文描述与未打文字标签的照片。结构化条件先限定有资格的结果，画面匹配按相关度排序。显示索引覆盖和模型版本 |
| 人物 | 库所有者开启后检测脸部并聚类，保留未知人物。用户可命名、合并、拆分、纠正单张误归类，以已确认人物检索。人工标注、机器建议和模型特征分别保存，更换模型时保留已确认关系 |
| 地理围栏 | 对有 GPS 的照片按圆心半径或多边形精确判断，可命名保存。支持组合围栏与人物、评分、画面搜索。边界上的有效坐标计入，无坐标项可单独筛出。地点文字保留为独立的检索字段 |

全文、空间和向量索引只返回所选范围允许的结果，封存排除项在导入历史另行查询。RAW+JPEG 的文件级条件须由同一文件满足，拍摄或作品级的语义命中注明对象和来源。照片数、文件数和结果可操作范围分别可核对。断网或索引尚未完成时，显示本地可查范围及缺少的索引。机器任务延迟返回时按照片和内容版本更新。

## 验收

1. 用 RAW/JPEG 字段相异、含缺值及未纳入成员的固定清单核对文本、组合条件、计数及分页。保存为智能集合，修改评分后复查。普通查询不读原片字节，前三阶段使用[现有照片基线](validation.md)从输入一直测到首屏可见。长期[目录规模验收](spec.md#100-tb-目录验收)另行安排。
2. 用带标注的原始 RAW 和缺 AF 信息的 JPEG 测原图、旋转、裁切、代理及离线状态。分别评估清晰度误报、漏报和未知覆盖，包含夜空、运动拖影和低对比场景。确认失焦后完成导入和重分析，该照片仍可在项目中按人工属性找到。
3. 固定一组已标注但无文字标签的雨伞照片，以及有文字标签却无雨伞的负例，分别测试文字搜索与画面搜索。指定查询和前 K 个结果，报告相关命中率、召回和索引覆盖。人工拆分误聚类的人脸、纠正并重建索引后，按人检索应只返回预期照片。
4. 用围栏内、外、边界和无坐标样本核对精确结果。在湿地围栏内选定人物和四星以上，再用“红色雨伞”排序，返回成员全部满足硬条件。断网和部分索引时复测范围提示。
