## 阶段一 · 目录与导入

- [x] L01 · Rust 只读包与 C ABI 接进实际网格，旧查询并读对账。覆盖空时间、同排序值、短中文、项目范围、RAW/JPEG 文件条件和连续滚动，逐项核对 ID、总数、分页与批量操作目标。
- [x] L02 · 单写入口及 v7 迁移。完成升级前备份、拍摄／文件／内容／副本身份映射、必要帧兼容、离线挂载和含新写入的恢复。用旧目录副本和更新格式夹具测试每个可读／可写版本。
- [x] L03 · 分别记录每次导入出现与归档资格，覆盖增量扫描、迟到的配对、跨卡／多机歧义、人工锁定和单次封存。用[五文件场景](spec.md#每个导入原件的归档资格)对账，重复命令零重复，排除成员不会经备份、组或缓存取得原件归档引用。
- [x] L04 · 接入可搬迁库包、按代备份、独立位置还原与整卷重连。还原目录、编辑与原片覆盖分别核对。中断复制后只补缺项。
- [x] L05 · 用同一真实目录录制打开、改筛选与持续导入期间的实际首屏，记录 P50/P95、RSS、索引体积与退化原因。在增量索引落后、重建、取消及重开时核对纳入资格和人工数据。

## 阶段二 · 日常管理与迁移

- [x] L06 · 文件夹、受管移动／改名、普通集合、集合组、作用域内堆栈、手动顺序、可保存的规则与虚拟副本。在多卷、同名、复合范围、掉线与恢复场景核对关系和文件操作清单。
- [x] L07 · 检查器、EXIF／IPTC、直方图来源、批量混合值、Survey、元数据分项与结构化组合查询。在本机实际拍摄上核对可用字段、计数及原片离线显示。
- [ ] L08 · **功能已交付，实拍失焦正例待补。**  连拍复核实现相机 AF 点坐标映射、局部清晰度、未知及人工改判。用低纹理、运动拖影、夜景和眼部样本标注误报与漏报，检查失焦照片仍可导入、归档及过滤。
- [x] L09 · Lightroom 只读迁入器和可续跑账本。对五份源目录按组织关系、元数据及可获得的历史外观分别对账。重复迁入不重建既有对象或覆盖人工编辑，抽验还原后的 Adobe 原文、依赖和每个虚拟副本的独立关联。

- [x] L10 · 分组编辑状态和冻结输入清单，先完成延时视频受管回库、双向追溯、重新制作和中断重试。移走外部导出副本后仍能通过资料库定位成片。
- [ ] L11 · **三种算子均已交付，运动 HDR 轮廓与近景视差标注待补。**  按星轨 → 多曝光 HDR → 全景交付算子。星轨补经确认的实际夜空序列，HDR 补标注运动与饱和区，全景补无重叠和近景视差。各自完成全尺寸母版回读、失败提示和输入来源验收。
- [x] L12 · 地理围栏及精确检索，补凹多边形、跨经线、极区和无 GPS。更改或清空坐标后重建，按真实范围逐 ID 对账。
