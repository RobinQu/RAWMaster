# 比较工作台、拍摄序列与颜色标签

2026-10-25 用户追加需求，覆盖009的比较布局规则。

- 比较复用单张底部胶片条；取消右栏与候选单选圈，模式/缩放/撤销移到底部工具条。决定、星级、颜色操作明确属于每个文件；有活动筛选时仍保留有效参照并补入候选。
- EXIF以共享字段列和紧凑数据行展示，照片名称、预览和逐张操作固定在纵向滚动区上方。空选标题贴顶、工具条贴底。
- 显式切换项目时保存网格模式，旧项目往返也不恢复比较；保留各项目查询、焦点和选择。正常启动直接恢复当前项目比较仍可用。
- 网格和胶片条用连续分段的矩形边框表示序列，适配换行并支持收起；不重排照片、不重复显示、不引入检索范围外文件。交错成员分段标记“续”，多重归属另有提示。折叠仅影响展示，键盘定位自动展开。
- [资料库单张查看](../../docs/ui/prototype/index.html#library/project/river)的底部胶片条使用统一的缩略图水平线，分组外框与组外照片选中框同高且上、下沿对齐。组内照片仍有独立选中框。组头位于首张左侧，第一行的箭头和组名是同一个折叠按钮，第二行是张数和独立的设置按钮。组头宽度固定，组名按可用宽度单行尾部省略，不限制名称字符数；悬停、辅助功能和组属性提供全名。设置只打开该组属性，取消返回原选片。折叠保留整行高度和原选片，再展开恢复成员；可继续点击缩略图换片或按 G 返回网格。[走查](../025-editing-workspace/prototype-review.md#资料库胶片带边框与组头)
- 2026-11-22 修订。序列按一次拍摄显示一个成员，展开 RAW+JPEG 可分别核对文件的处置和本次制作是否采用。兼容旧文件级参与例外。只匹配一个文件时按实际范围展示，收起仅替换被隐藏的比较成员并保留其他参照。[拍摄身份与归档资格](../033-library-lifecycle/spec.md)
- 每文件可设置一个独立颜色标签（红/橙/黄/绿/蓝/紫/灰）或移除；支持批量、真实筛选、卡片标识与持久撤销，文字标签不受影响。资料库v5→v6备份迁移增加asset_color_labels，旧查询兼容。
- 网格和胶片条共用右键菜单，编辑工作副本/颜色/决定针对被点击文件，不暗改当前选择；原片始终只读。

连拍组默认进入比较，能从同一候选查看可用的相机 AF 点、主体清晰度、证据来源和人工复核，并按清晰度过滤。导入处置、独立精选与合成参与各自记录。[对焦检查与验收](../033-library-lifecycle/search.md)
