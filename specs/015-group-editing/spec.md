# 拍摄组管理与分组制作

2026-11-22 修订。资料库中的“编辑拍摄组”管理名称、用途、顺序和成员。在组上选择“制作”则进入现有“编辑”工作区的分组状态。分组制作属于[资料库第三阶段](../033-library-lifecycle/spec.md)。

## 使用场景

进入拍摄序列后，多选操作提供“从拍摄组中移除”。项目中的普通多选继续支持创建拍摄组。照片右键菜单以被点击的文件为目标，可加入同项目的现有拍摄组，也可从所属拍摄组中移除。

拍摄序列目录卡片、序列标识和组内照片列表提供明确的“编辑拍摄组…”入口。创建和编辑默认同时显示组名称、用途（含自定义用途）和结构保护；属性修改作为一次操作预览、保存、撤销。合并、拆分保持为独立的结构操作。

## 行为约束

- 创建、属性修改、加入和移除均使用既有组操作记录及影响预览。
- 同一照片可以属于多个组，加入或移除只改变所选目标组。
- 新成员依请求顺序追加并参与该序列；原成员的顺序和参与状态保持。
- 组属性表单的一次保存同时应用全部编辑值；不能串行保存多个字段而留下部分成功状态。
- 名称和用途去除首尾空白后必须非空。旧版组命令记录仍能解码与撤销。
- 保留初筛、导入历史只读、忙碌和项目范围约束。单张右键不会把其他多选文件作为目标。
- 从当前已打开的项目组移除全部成员后，保留该组详情及属性编辑入口；不据此扩大空初筛组的公开范围。
- 原片、照片决定、评分以及其他拍摄组关系保持不变。

## 验收

核心验证覆盖原子属性更新、完整表单创建、成员追加顺序/参与、跨项目拒绝、持久化、一次撤销、旧命令兼容与并发冲突。界面验证覆盖组内/组外选择动作、单照片目标、目录与列表入口、完整属性表单和空组编辑，并检查原生界面布局。最后运行完整回归并重新打包应用。

## 从一组照片制作新作品

1. 选中一个组即可开始制作。显示整个组及人工顺序，默认选中所有已纳入且参与的拍摄。已明确停用的成员保留其状态。初筛排除的必要帧显示位置和缺口，可以调整本次输入，或到导入历史明确恢复。库中筛选或当前网格的局部多选不会改变组的默认输入。
2. 每次快门最多贡献一帧。确认的 RAW+JPEG 优先使用符合本次选择的 RAW，显示最终文件及内容版本。离线原件可以取回，缺片、解码失败或改用 JPEG 均须可见。用户可为本次制作排除、重排或选择替代输入，保存草稿与持久修改组结构采用独立操作。
3. 提交时冻结组身份与修订、实际拍摄、文件内容版本、顺序、参数、配方及引擎／模型。完成时按媒体类型登记一张派生照片或一段视频，加入相应项目。可从成片查源组和每个输入版本，也可从组列出其全部作品。之后变更组或处理参数，可另行制作新版本，已完成作品仍可回溯。
4. 本地与 Server 按相同输入清单执行。渲染、结果校验和目录登记分别记录，重试按作业身份对账。回调晚于组修改时，结果仍属于提交时的输入。连拍优先打开[清晰度比较](../033-library-lifecycle/search.md)，明确发起制作时才创建组作业。[远程任务合同](../033-library-lifecycle/server.md)

| 交付顺序 | 作品与独立质量验收 |
| --- | --- |
| 1 · 延时视频 | 已有 MP4 预览和导出。先验收正式视频登记、双向追溯、帧序与时长、发布中断后只登记一次。[延时规格](../010-timelapse-video/spec.md) |
| 2 · 星轨 | 生成新的叠加照片。用含断帧、异常轨迹和前景的长序列核对轨迹连续性、前景处理与实际采用帧 |
| 3 · 多曝光 HDR | 从曝光包围组生成新的高动态范围照片。核对曝光覆盖、对齐、运动区域去鬼影和实际输出动态范围。缺少曝光档时在制作前说明 |
| 4 · 全景 | 生成新的拼接照片。用含重叠、视差和曝光差异的序列核对匹配、投影、接缝、裁切及失败输入定位 |

每类分别以实拍样本检查画质，以已知输入清单检查成员和版本。用跨组共用一帧、制作期间重排、重试一次、移动原件四个场景检查来源关系及作品数。已有路线中的景深合成另行验收。
