# M1 local culling — implementation plan

Status: authorized implementation, 2026-10-21. Source: docs/planning/07-m1-client-experience-review.md.

Implementation: SwiftPM, macOS 15+ build target but runtime acceptance on current machine; Swift 5 language mode on installed Swift 6 compiler. Standard SDK frameworks only at runtime, SQLite via system library. Native app package generated into output/RAWMaster.app. Library RAWMasterCore isolates persistence and operations. Native UI uses SwiftUI and AppKit image view; ImageIO extracts embedded previews and CIRAWFilter renders RAW detail. Rendering is display-only fixed baseline, not an editor. SQLite retains authoritative M1 state; durable versioned operation records prepare business-level sync, without implementing network sync or claiming CRDT history.

## Core contract (workers must implement these public APIs)

All records Codable/Sendable with public initializers. ProjectRecord: id:String, name:String, createdAt:Date. AssetRecord: id:String, sessionID:String, projectID:String, projectName:String, sourcePath:String, currentPath:String, relativePath:String, filename:String, fileSize:Int64, capturedAt:Date?, camera:String?, width:Int?, height:Int?, contentHash:String?, decision:Decision, rating:Int, groupID:String?, sequenceIndex:Int?, isSequenceMember:Bool, availability:AssetAvailability, importState:ImportState, error:String?. Convenience resolvedURL/URL on currentPath. Decision enum .undecided/.keep/.reject, ImportMode .reference/.copy, ImportState .discovered/.copying/.verifying/.ready/.failed, AssetAvailability .available/.missing/.changed. CaptureGroup: id, projectID, name, kind (String), assetIDs:[String]. Membership is many-to-many in storage; AssetRecord.groupID is only a primary/display hint and never authoritative. ImportSession: id, projectID, projectName, sourcePath, destinationPath:String?, mode, status:String, discovered/completed/failed:Int, createdAt:Date. TaskProgress: title, completed,total:Int, message:String, isRunning:Bool. SelectionChange: assetID, old/newDecision, old/newRating for undo. ExportReport: destinationPath, copied/failed:Int, manifestPath, errors:[String].

LibraryStore is a thread-safe final class, @unchecked Sendable, init(databaseURL: URL) throws. Public methods loadProjects() throws -> [ProjectRecord]; loadGroups(projectID:String? = nil) throws -> [CaptureGroup]; loadAssets(sessionID:String? = nil) throws -> [AssetRecord]; loadSessions() throws -> [ImportSession]; updateSelection(ids:[String], decision:Decision?, rating:Int?) throws -> [SelectionChange]; undoSelection(_ changes:[SelectionChange]) throws; createGroup(ids:[String], name:String, kind:String) throws; removeFromGroup(ids:[String], groupID:String) throws; mergeGroups(ids:[String], name:String) throws; reorderGroup(groupID:String, assetIDs:[String]) throws; setSequenceMembership(ids:[String], included:Bool, groupID:String? = nil) throws; refreshAvailability(ids:[String]?) throws. Provide assets persisted in stable discovery order, source paths are never rewritten by app. Re-import same source/session is idempotent; new source provenance survives content matching. Core image metadata uses ImageIO allowed in library if needed.

ImportService: final thread-safe class init(store:LibraryStore); async importDirectory(source:URL, destination:URL?, projectName:String, mode:ImportMode, projectID:String? = nil, progress:@escaping @Sendable(TaskProgress)->Void) throws -> ImportSession; async resume(sessionID:String, progress:...) throws -> ImportSession; cancel(). Source scanning recursively supports ARW/DNG/RAW/CR2/CR3/NEF/RAF/ORF/RW2/JPG/JPEG/HEIC/TIF/TIFF; skip hidden files; source never modified. Incremental asset registration before checksum, bounded batches. Hash streaming SHA256; temp files atomic promotion, capacity errors clear, no overwrite of different content. Recover sessions and failed/incomplete records. Database mutations synchronize across caller threads. Only one import job at a time. Tasks finish progress state even on cancellation/errors.

ExportService init(store:LibraryStore); async exportAssets(ids:[String], destination:URL, manifestIDs:[String]? = nil, progress:@escaping @Sendable(TaskProgress)->Void) throws -> ExportReport; cancel(). Copies chosen original bytes, hash verifies outputs, collision safe paths. UTF8 CSV and versioned JSON manifests cover chosen scope and statuses; no source sidecar write. Resume by detecting matching complete outputs, partial outputs isolated; report missing files and cancel status. Source/target equality and descendant-danger paths guarded. Groups remain unchanged by selection and export.

## Imaging contract

ImagePipeline.shared: preview(for asset:AssetRecord, maxPixel:Int=600) async throws -> NSImage; detail(for asset:AssetRecord) async throws -> NSImage; metadata(for:URL) static utility optional. Implement bounded concurrent decoding and bounded memory caches keyed by URL + modification/size + requested level. Previews use embedded thumbnail API, RAW detail must use actual CIRAWFilter output at full sensor output extent, not upscaled JPEG. Reject unsupported files with clear error. NSImage actor crossing use Swift 5 language mode. Inspector labels actual source. AppKit ZoomableImageView receives image:NSImage?, zoomToActualPixels:Bool, sync transform binding shared between compare panes, image view can pan/zoom and update coordinates; UI or imaging owner must coordinate file ownership before writing this view.

## Validation

Meaningful tests: store atomic history/undo/reopen, reference import byte preservation/relative paths/hidden files, two different same-name files, repeat/resume idempotence, copy/verify with checksums, reject doesn't change sequence membership, export collision/manifest/missing source and source/destination guards. Real RAW probe to validate metadata, embedded preview, genuine RAW render; source hashes before/after sample test. UI reference import real 152 RAW files and small copy/export subset, selecting/rejecting/undoing/grouping/comparing/zooming/reopening. UI fault injection where practical and core tests for failure boundaries. Not every planned stress/performance threshold can be claimed passed without measurement.

## Review revisions and invariants

Spec.md and tasks.md now exist. Stable ProjectRecord ID relates multiple sessions; UI may pass selected projectID on import. Export IDs are copy scope, manifestIDs are all registered assets of selected session/scope (default copy IDs if omitted for API compatibility); manifest records a copyRequested flag and per-item outcomes. JSON top-level includes schemaVersion and scan/session coverage/status. Task cancellation returns truthful cancelled/partial report when possible; never complete-success label on skipped required copies.

Group storage is membership-table many-to-many. UI may display primary group but preserve all. Expose remove, merge and reorder to avoid a dead-end initial model. Cross-project group operations fail explicitly. Sequence membership belongs to group membership; asset.isSequenceMember is display aggregate.

All decision/group/membership/undo writes and append-only operations use one SQLite transaction. Operation schema: stable UUID, deviceID persisted per library, entityID, baseRevision, payloadVersion=1, action, payload JSON, timestamp; asset revision increments. Transaction/failed write cannot leave state without operation. Undo appends compensating operations. Single serialized SQLite connection via recursive lock or serial queue; no async suspensions while holding transaction.

Filesystem target safety is resolved canonical path (including symlink parents), guarded both at setup and before each write. Copy destination cannot equal or be inside source, export cannot overwrite or alias any input source, and must never traverse out via relative paths. Preserve source directory hierarchy inside unique export root; destination collisions use matching-hash reuse or unique suffix, never remove/replace unknown files. Cancellation cleans only owned temp files; complete outputs retained. Source modifications during import detected by stat before/after read/hash, clear changed state, no stale complete verification. Full SHA256 uses streamed chunks. Stat-only can't prove unmodified source, but detects ordinary external changes. Group/decisions integrity does not depend on worker image metadata arriving.

Additional ownership/resource freeze: imaging lane owns ImagePipeline.swift, ZoomableImageView.swift and ImageTransform (scale CGFloat=1 relative to fit, centerX/centerY CGFloat=.5 normalized). View initializer ZoomableImageView(image:NSImage?, actualPixels:Bool, transform:Binding<ImageTransform>). UI consumes it, never edits those files without handoff. 1:1 maps one image pixel to one backing pixel (view points divided by backingScaleFactor). Preview cache budget 128 MiB, RAW detail cache budget 512 MiB, max 2 preview jobs and 1 RAW job, evict by byte cost and never hold full-res images in grid. Root may adjust lower after measurement. Single-frame RAW result may exceed cache budget: display current result without retaining in cache; no repeated duplicate full decode for one key. Swift owner sends compile-ready imaging API to UI owner.

Operation schema also includes resultingRevision. Group API adds renameGroup(id:String,name:String) throws. Re-import same canonical source into same project resumes existing active/completed session; explicit new project creates new provenance. UI shows session scope. Hash-equal content under a new path still creates a source record; byte dedup is not asset/provenance deletion.

Integration amendment: imaging is a shared RAWMasterImaging target in Sources/RAWMasterImaging so diagnostics and UI exercise the identical shipped pipeline; imaging owns both files, exposes public APIs. Core/Foundation persistence remains separate.

Final integration notes: CaptureGroup.includedAssetIDs records per-group sequence participation; ImportSession.scanCompleted optional field distinguishes known coverage from interrupted discovery. ImageTransform.physicalMagnification=1 maps physical source pixels independently for mixed-size comparison; nil keeps fit-relative zoom. Native canvas explicitly clips images to bounds. New source selection uses NSOpenPanel; new imports reset filters and clear out-of-scope selection before publishing progress scope. Final evidence and remaining boundaries: validation.md.
