# M1 本地 RAW 选片客户端

状态：2026-10-21 用户授权实施。需求依据：docs/planning/07-m1-client-experience-review.md；用户提供真实样本目录用于只读验证。

## 用户故事与验收

US1 接入：用户可引用现有目录或复制到工作目录，扫描后逐步看到素材。源文件不被改写；复制中断可恢复；同名不同内容不覆盖。对应 F001.R01–R08。

US2 浏览选片：网格、单张与 2–4 张比较；先显示预览，按需解码 RAW 细节；P/X/U、星级、批量决定、撤销持久保存。原始细节与预览清楚区分；错误不等于坏片。对应 F002.R01/R03/R05–R07。

US3 序列：手动创建连拍、延时、HDR、星空等组。独立入选与序列参与分离，排除独立照片不改变序列成员。对应 F001.R06、F002.R02/R04。

US4 交付：复制精选原片到独立目标并校验，输出 CSV/JSON 选择清单。失败、缺片、冲突可定位；重试不破坏正确输出；源原片不变。对应 F002.R08–R09。

US5 恢复：重启保留来源、会话、决定与组关系；暂停/取消/拔盘/磁盘满不伪装为全部成功。重新接入同一来源不重复创建同一来源资产。

## 边界

当前是单机 MVP，不交付服务器、多设备传输、自动质量评分、自动分组、自动排除、完整显影或 Lightroom 迁移。SQLite 保存本地领域状态和版本化变更记录；Automerge 仅进行有边界的评估，不以为整个图库保存 CRDT 历史为前提。源数据始终只读，复制测试数据仅写测试工作目录。

## 完成证据

提供可运行 .app、构建/测试入口、真实 RAW 预览和传感器分辨率解码证据、核心恢复与导出测试、实际 UI 操作记录。性能目标按实际测量报告，不凭成功编译宣称达到所有规划阈值。
