# 签名版资料库虚拟副本验收

2026-11-27 在 macOS 上打开独立测试资料库，使用项目网格中已接入的 Sony ILCE-6000 实拍原片 `snow.ARW`。从「更多照片操作」创建「黑白习作」，进入编辑后切换 B&W。彩色原片保存「雪景彩色」，副本保存「雪景黑白」。正常退出整个应用并重新启动后，分别打开两张卡，确认各自的调整、快照名称和恢复后的配方。网格内可同时看到彩色与黑白的缩略图。[网格双选](05-native-library.webp) · [黑白编辑](07-native-editor.webp)

在资料库先只选原片，再只选黑白副本，最后同时选中两份。分别进入导出，选「全尺寸 JPEG」，在三个独立目录实际写入文件。双选时导出清单有两行，可按副本名定位。队列回执中的三批交付数量为 1、1、2。[双选导出](06-native-export.webp) · [文件摘要、选片身份与队列回执](signed-desktop.json)

安装到 `/Applications/RAWMaster.app` 后，以严格模式核对包签名与可执行文件摘要。旧实例正常退出，新实例已打开主窗口。

已将验收资料库完整备份，再恢复到「雪景彩色与黑白.rawmasterlibrary」。用安装版打开恢复的资料库，分别核对了彩色与黑白的快照，并重新双选两份修图。可在「打开其他资料库…」选择这个目录继续编辑。[恢复与重开回执](signed-desktop.json)

以相同的 sRGB 转换与 64 × 64 重采样读回 JPEG。对每个像素取三个通道最大值与最小值的差并求平均，范围为 0–255。另对全部 2400 万个像素的 8 位 sRGB 数据计算 SHA-256，单选、双选的同一份修图逐像素一致。源文件 SHA-256 为 `ba70e98cc4b7caf453aaf96f6b9da3f28a460d07aec992a2c6a49a93f90f5af2`。Release 的 CDHash 为 `d5ea853ca371cef9bbefd43de37fc574784c0d7c`。

另以 125 个物理文件和 1 份副本复验分页。资料库依次载入 60、120、126 个呈现，重开后能导出首屏以外先前选中的同源原片和副本。原生窗口输入覆盖 ⌘ 点击、Shift 加方向键和辅助功能加选，亦检查移除后连续撤销及缩略图缓存按呈现更新。[分页与缩略图回归](../../../../Tests/RAWMasterUITests/VirtualCopyGridTests.swift) · [命名快照与归档验收](editor-native.md)

单选另测了两种重开状态。66 张原片的资料库中，焦点与勾选都停在首屏以外的黑白副本，首屏即可打开底栏的「更多照片操作」。126 张原片的资料库中，焦点停在同源原片，勾选的是副本。载入首批 60 项和随后累计 120 项时，两张卡都还在屏外，仍能对勾选的副本重命名。通过辅助功能按下「编辑照片」并将曝光改为 −0.625 EV，SQLite 读回了副本的新曝光，原片配方保持原值。另将唯一勾选的副本放在第一页、焦点放在第三页，载入第二页后导出清单仍只有该副本。[冷启动选区与底栏操作](../../../../Tests/RAWMasterUITests/EditingLayoutInteractionTests.swift) · [分页焦点与导出对象](../../../../Tests/RAWMasterUITests/VirtualCopyGridTests.swift)

同机回归中，Swift UI 套件 580 项通过、36 项跳过，Swift Core 套件 416 项通过、9 项跳过。Rust 资料库套件 100 项通过、5 项标为忽略。实拍用例使用 Release 包随附的 FlashRaw 解码库。
