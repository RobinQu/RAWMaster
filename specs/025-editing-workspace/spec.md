# 025 · 沉浸式编辑、蒙版与导出工作台

## 状态与目的

- 状态：025 约定范围已实现、验收并安装 27.0；本文档是在实现完成后对现有工作流的 Spec Kit 结构化整理，不宣称经历了 spec-first 或 CLI 生成过程。
- 目的：让照片在暗房画布中保持最大可视面积，以直接、可恢复的方式完成初修、局部调整和批量成片导出。
- 参考流程：[Spec Kit 官方仓库](https://github.com/github/spec-kit/tree/main)的 specification → plan → tasks → implementation/convergence 结构。

## 用户场景

侧栏玻璃、滤镜顺序、画布消息与 Graph 的当前验收入口见[编辑侧栏、画布通知与 Graph 浮窗](editor-rails.md)。

本轮 HTML 评审以[暗房布局与走查](prototype-review.md)为准。该记录区分本次设计与 27.0 的原生验收。

1. 从资料库进入单张编辑，照片占据主要区域；工具以悬浮材质覆盖，背景可切换深灰、中灰、浅灰和纯黑。
2. 通过固定类目进入调整面板，或直接在 RGB 直方图的色调区域拖拽；每次编辑立即生效并进入历史，无需手动保存。
3. 使用 Remove／Heal／Clone 修复，或建立线性、径向、亮度范围、AI 主体蒙版，并对每层独立调整和排序。
4. 在资料库或编辑模式保留显式多选，进入非模态导出工作台，设置格式、尺寸、压缩、目录与命名后输出当前成片。

## 胶片带、快照与调整面板

- 资料库单张查看保留底部胶片带。组名、张数和折叠操作位于组内首张左侧；组内外缩略图中心对齐。折叠不改变选片，聚焦组内照片时展开该组。
- 从资料库选片进入[编辑暗房](../../docs/ui/prototype/index.html#edit/development)。编辑不显示胶片带；用画布底部工具条的「上一张」「下一张」或 `←`、`→` 在当前浏览范围内翻片，达到首尾时禁用对应方向。不改变照片的草稿或版本；离线原片仍可从翻片进入找回，取消留在当前照片。返回资料库继续选片。[翻片走查](prototype-review.md#编辑翻片与资料库胶片带)
- 暗房左栏 → 快照。当前照片及编辑版本的快照使用与预设一致的全宽文字行，右端保留管理操作。悬停或键盘聚焦临时查看，离开时恢复当前配方，点击才恢复快照并记入历史。窗口失焦只结束试看。创建、管理、切换照片与返回暗房均可走查。[快照走查](prototype-review.md#胶片带与调整面板)
- 暗房右栏 → 调整图标。首次进入有可展开区块的面板时，打开第一个区块，往返保留该照片的展开偏好。每个可调整的区块有启停控件，关闭时保留调整值且暂停其效果，重新启用继续使用；任务式增强沿用各自已有设置和工作状态。滑块占单独一行，名称与可编辑数值同在上方。[调整走查](prototype-review.md#胶片带与调整面板)

## 技术与产品约束

| ID | 约束 |
| --- | --- |
| C-001 | 原片、项目资料、归档与已有输出不得被编辑或导出覆盖；所有成片经独立暂存与发布前检查。 |
| C-002 | 交互代理可近似，但 settled、保存、导出和配方重放必须保持约定路径；不得用 JPEG 或交互近似替代 canonical 成片。 |
| C-003 | 配方变更必须进入实际模型、命令、历史与持久化；不展示无实现的动作。 |
| C-004 | 新配方字段必须向后兼容；蒙版、AI 数据、局部操作与几何坐标均需验证来源和有界资源。 |
| C-005 | 失焦、切照片、退出、连续手势和晚到结果必须保持当前上下文；旧任务不能覆盖新草稿。 |
| C-006 | 非主体蒙版不得引入整帧第二采样依赖；所有新增完整画面阶段都需重新检查瓦片内存。 |
| C-007 | 原生快速路径只覆盖其已验证参数域；其他情况使用既有代理或 canonical，不扩大有限值／颜色资格声明。 |
| C-008 | 跨应用性能只在相同输入和明确计时边界下比较；API 返回、画布 draw、GPU idle 与物理输入到屏幕不是同一指标。 |
| C-009 | 安装前备份应用、偏好和资料库；开发验收使用隔离 bundle ID 与资料库。 |

## 明确不在本轮范围

- 画框、签名、社交媒体或图床的直接发布配置。
- JPEG 编辑代理、新 LRU／预热设置；现有 FlashRAW 交互路径已过门禁，没有新增收益证据。
- 全相机／全 RAW 格式、HDR／超色域和所有组合配方的普遍等价或性能保证。
- AI 主体的正向摄影质量、边缘质量或人像基准结论。
- 商业公证、Developer ID 发布；当前为本机 ad-hoc 签名安装。
