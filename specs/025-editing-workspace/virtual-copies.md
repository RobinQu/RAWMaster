# 一张照片的多种修法

在资料库项目网格中选中一张已接入的照片，右键或打开底栏「更多」，选择「创建虚拟副本…」。副本可以从当前彩色调整开始，继续做黑白或者 HDR。原片与副本共用源文件，在网格、编辑及成片交付中各自有稳定身份。[可操作的摄影工作台](../../docs/ui/prototype/index.html?sceneNativeReview=1#library/project/river)

## 创建、查找和移除

- 创建表单预填本张原片可用的「副本 N」。按 Return 创建，Esc 取消并回到原卡。项目网格单选时底栏为末行缩略图保留空间，显示「更多照片操作」；多选时继续使用多选操作栏。VoiceOver 可在卡片上使用「加入选片」和「移出选片」切换勾选。名称为 1 到 128 个字符，同源副本名称忽略大小写时仍须唯一。错误在表单内说明，可直接修正。
- 默认拍摄顺序中，新副本接在同源呈现之后并成为当前选择。网格标明源文件名与副本名，单张胶片带、比较、编辑标题及交付清单可以区分同源两份。切换排序按当前排序规则工作；来源文件数、拍摄数及序列帧数按物理文件计算。
- 星级、保留或排除决定、审阅状态、颜色标签与关键词属于物理照片。在任一副本上修改后，原片与其他同源副本会显示相同的文件元数据。多选同源呈现时，批量标签预览只列一次源文件，写入也只执行一次。每份呈现仍独立选中、保存配方与命名快照，并可分别交付成片。
- 对副本右键或从底栏更多可重命名，或者打开「移除虚拟副本…」。确认界面说明会移除本份编辑和快照，原片与既有成品继续保留。取消回到原选择，确认后焦点移到同源原片。可使用 ⌘Z 恢复该副本、名称和快照。
- 同时选中原片与副本，再按住 ⌘ 点原片取消选中。此时只有副本勾选，浏览焦点仍在原片。底栏「编辑照片」、顶部「编辑」和底栏「更多」都作用于这份副本。进入编辑后栏头显示副本名，改动曝光、返回资料库，当前选择仍是该副本。
- 原片离线时保留该呈现的目录信息。全部引用共享源文件可用性；找回一张原片后，其副本也恢复可访问。已有 AI、外部应用或归档成片继续保留各自的来源关系及像素。旧库只在摄影师显式创建时增加网格呈现。[副本与物理来源](../../Sources/RAWMasterCore/LibraryStore+VirtualCopies.swift)

## 调色历史、快照与已有结果

| 摄影师要完成的操作 | 入口与行为 |
| --- | --- |
| 撤销刚才的调整 | 编辑历史在当前呈现里前后走，恢复快照也写入一条可撤销的调整。 |
| 留下可重开的命名状态 | 在编辑左下「快照」点加号。每份呈现独立保存 SDR／B&W 分支与 HDR 分支的快照。切片、切换色彩外观、重开资料库后只显示当前呈现与分支的命名快照。每个分支可存 32 条，达到上限时说明如何释放位置。重命名和删除从对应行的更多菜单进入。重命名接受 1 至 60 个字符，Return 存储、Esc 取消。无效输入、其他窗口已删除该条快照，或当前呈现或色彩分支发生变化时，表单保留输入与错误原因；取消后可重新选择。 |
| 从现有调整开始尝试另一种修法 | 创建虚拟副本时冻结当前调整及其另一套色彩外观。从独立的快照列表和撤销历史开始。随后在原片或另一副本修改曝光、蒙版及色彩外观时，此份编辑不受影响。 |
| 从已采纳的本地显影成片继续调整 | 在项目网格创建副本，选中它并打开编辑即可继续显影。副本保留已保存的配方、预设应用记录及另一套色彩外观。拔下原片后，可查看并从 032 导出原先保存的成片。接回原片后修改曝光，032 使用副本的最新配方。已有 AI 和外部应用返回的成片继续按其归档像素读取。 |
| 找回已保存的候选或外部返回的成片 | 左栏快照更多打开「已有编辑结果…」。查看、采用和明确导出指定结果沿用原有版本身份。 |
| 冻结一轮输出 | 从网格选中原片和副本，打开 032。在成片栏看到两个源文件名相同、呈现名称不同的输入。每项冻结各自的配方或归档来源、版本和输出名。后续改名、继续编辑或移除副本，已提交回执仍指向原输入。 |

成片预设中的 `{name}` 对副本展开为「源基名-副本名」，沿用已有重名策略。切到原件模式，同一物理源只提交一次。只勾副本也可交付该原件。切回成片保留两个呈现的勾选。[032 工作台](../032-export-workspace/prototype.html) · [交付规格](../032-export-workspace/spec.md) · [032 原生实拍与回执](../032-export-workspace/virtual-copy-delivery.md)

## 浏览器验收

2026-11-27 使用仓库水鸟及山坡样片，浅色 1440 × 900、深色 390 × 844 均从正常入口操作。浏览器的照片和交付任务采用本地示例，实际 RAW 和归档文件在原生验收中核对。[专项脚本](../../scripts/check-virtual-copies-prototype.py) · [机器回执与截图校验值](evidence/virtual-copies/prototype-acceptance.json)

| 操作 | 验收结果 |
| --- | --- |
| 用右键创建，再用底栏更多重命名 | 名称校验、取消与焦点恢复均通过。原片保留 +0.55 EV，黑白副本独立修改。选中两项时拍摄和物理文件计数保持，星级与标签在两份呈现中同步。[浅色资料库](evidence/virtual-copies/01-library-copies.webp) |
| 分别保存彩色、HDR 及副本黑白快照，重开后恢复 | 三份快照只在相应呈现和色彩分支出现。恢复、撤销、重命名与删除按对应快照工作。SDR 填满 32 份后的新增尝试保留原列表，同一呈现的 HDR 分支仍可保存。 |
| 两份呈现同时进入 032 | 两个成片输入拥有不同的呈现及版本 ID、相同物理 ID。切至原件交付可见一个原件，之后返回成片仍是两项。另一次只勾副本交付时，清单含源文件原名与清单文件。提交后继续编辑，已提交版本及文件名保持。[浅色成片工作台](evidence/virtual-copies/02-export-copies.webp) |
| 暗色窄窗中移除、撤销及接回来源 | Esc 可退出确认并回到原项。移除时保留原片与已提交回执，⌘Z 还原原副本。离线山坡原片和副本在一次重连后同时可用。两个工作区均可纵向浏览，032 窄窗保留 180px 的成片预览。[窄窗资料库](evidence/virtual-copies/03-compact-library.webp) · [窄窗导出](evidence/virtual-copies/04-compact-export.webp) |

## 原生复验

签名 Release 中的实拍彩色与黑白副本经应用重启、单选导出、双选导出及文件像素读回确认。[发布版验收与截图](evidence/virtual-copies/signed-desktop.md)

在装入两份同源呈现的真实项目里，AppKit 窗口收到普通点击和 ⌘ 点击。单选时出现「更多照片操作」，多选后换成批量栏。再次 ⌘ 点击副本，原片仍保有单选底栏。VoiceOver 的「加入选片」与 Shift 加右方向键均能同时选中两份。SQLite 读回两个呈现 ID 和副本焦点，切到其他范围再回来仍能恢复。重开大型项目时，首屏即可对上次唯一勾选的副本操作，即使该副本在后续页面，或焦点停在另一张照片。[网格鼠标、键盘与辅助功能](../../Tests/RAWMasterUITests/EditingLayoutInteractionTests.swift) · [分页和重开](../../Tests/RAWMasterUITests/VirtualCopyGridTests.swift)

使用 AppKit 和 SwiftUI 验证资料库与导出控件的标签、原生键盘输入、共享勾选及菜单。自定长边拒绝非整数和越界数值，键盘取消保留原尺寸。成片达到 200 份呈现时按呈现收束；切到原件后按 200 个唯一源文件收束，所保留源文件的所有已勾副本继续勾选。[选择与批次界限](../../Tests/RAWMasterUITests/ExportWorkspaceInteractionTests.swift) · [整数输入](../../Tests/RAWMasterUITests/DevelopmentNumberInputTests.swift)

原生编辑与目录测试覆盖重开、切片、恢复快照、撤销及分支存储。032 另用实际源文件核对对应成片的像素、文件名及冻结回执。[编辑与目录证据](evidence/virtual-copies/editor-native.md) · [032 成片文件与持久回执](../032-export-workspace/virtual-copy-delivery.md)

完整 `.rawmasterlibrary` 备份实测覆盖原片、归档显影成片及连续创建的两级副本。包内共写入三个内容对象，分别为原件、归档 PNG 和发布回执。移除测试原件与旧归档后，恢复的三个呈现仍各自保有命名快照，并读取同一份归档，解码像素逐通道匹配。若副本引用另一张照片的归档，或其显影版本记录了与发布回执不符的配方或预设，完整资料库包及编辑归档备份都会拒绝该引用。[完整包恢复和归档归属回归](../../Tests/RAWMasterCoreTests/LibraryVirtualCopyStorageTests.swift) · [原片离线导出和重连后重新显影](../../Tests/RAWMasterUITests/VirtualCopyDeliveryTests.swift)
