从资料库打开照片，在「编辑 → 基础 → 色彩外观」直接选择模式。「预览 SDR 派生」只切换 HDR 草稿的观看分支。点击 SDR 或 B&W 则恢复这张照片的兼容显影配方。在支持 HDR 的原片上再次选择 HDR，会恢复该草稿此前的节点、模型和输出设置。[交互原型](../../../docs/ui/prototype/index.html?sceneNativeReview=1&scopesNativeReview=1#edit/basic) · [正常编辑入口与走查](../../025-editing-workspace/appearance-activity.md)

## 调整的像素语义

| 调整 | HDR 中的行为 | 既有参数 |
|---|---|---|
| 曝光 | 第一次进入时，基础节点的 EV 等于旧配方的摄影曝光加上已启用 V3 光效曝光的两倍。总数超过单个节点的 ±12 EV 时分成两个串行节点。光效页直接编辑当前节点的场景曝光与强度。 | 再次进入时恢复原有 DAG，包括完整的节点身份、端口和分组。 |
| 白平衡 | 以已验证 ARW 的拍摄通道增益和相机标定生成有符号线性 AP1。基础页的白平衡区说明该阶段。 | 手动色温、色调与兼容取样设置保存在 SDR/B&W 配方中。 |
| 曲线与覆盖 | 曲线页可调整选中校正节点的场景亮度 EV 控制点。蒙版、混合及分组沿用 Graph 的已接线算子。 | 兼容显影的 RGB 曲线、色阶、局部修复和选区按原样保存。 |
| 照片模型 | 首次进入沿用可转换的 VGG7 照片降噪与 2× 超分。细节页可以增减这两类场景模型及调整降噪强度。每次先验证完整原寸程序的算力、资源和预算，成功才提交。 | 已有的场景分割阶段及覆盖标识随 DAG 往返。RAW 马赛克降噪依旧通过兼容显影执行。 |
| 配色、分级、纹理与光学 | 各自沿用原工具栏位置。区块展开后说明哪些调整依赖显示色域、镜头校正或邻域采样。 | 恢复兼容草稿时带回完整参数、几何、LUT 和蒙版。黑白切换仅改变 V3 黑白组启用位，已保存的混色参数继续生效。 |
| 高光与派生 | 100 nits 为白点。可在 0…log₂(10) EV 设定上限。HDR 经 ACES 2 转到显示线性 Rec.2020 后，对超限颜色按最大通道值等比例缩放；PQ 仍使用固定的 1000-nit 目标。SDR 派生使用独立 ACES 分支，可在 −3…+3 EV 调节曝光。 | 上限、派生曝光随图保存。旧版未设上限的配方保持先前的图像与编码指纹。 |

当前草稿和另一种引擎的完整配方、兼容预设使用记录，随同一照片的父版本与修订号在一次目录事务中写入。旧目录缺少配套字段时，保留已存的活动配方；从早期 HDR 草稿退出时可以沿其开发父版本找回兼容基线。撤销和重做可恢复当时两侧的上下文。窗口重新取得输入权限时领取新的交互 epoch；在当前编辑会话内来回切换保留原分支的 SDR 命名快照与区块展开状态。032 只冻结活动配方。[草稿持久化](../../../Sources/RAWMasterCore/LibraryStore+Editing.swift) · [首次 HDR 曝光映射](../../../Sources/RAWMasterCore/DevelopmentSceneGraphV1.swift) · [目标变换](../../../Sources/RAWMasterImaging/DevelopmentSceneOutputV1.swift)

## 原生测量

使用已授权的 4000×6000 雪景 ARW，SHA-256 为 `ba70e98cc4b7caf453aaf96f6b9da3f28a460d07aec992a2c6a49a93f90f5af2`。每次测试创建临时目录和资料库。第一次 HDR、保存后的两次重新打开、SDR/B&W 和 HDR 往返均由普通编辑控制器执行。[实拍测试](../../../Tests/RAWMasterUITests/EditingAppearanceRoundTripTests.swift)

| 检查 | 测量 |
|---|---|
| 第一遍转换 | 原有 V3 光效曝光 0.375 对应 HDR 0.75 EV；原有 SDR 饱和度 0.23 在切回后按值恢复。 |
| HDR 颜色与上限 | 节点 +2.5 EV，SDR 派生 −0.35 EV，HDR 上限 +0.5 EV。128×192 全图网格的 AP1 最大通道为 13.452231；Rec.2020 输出最大通道为 1.4142137。目标 PQ 与派生 sRGB 色度分别占 419 与 761 个格。 |
| 常驻扩展 RGB 直方图 | 每通道包含全部 24,576 样本，144 个线性白点以下档位与每 EV 28 档的四档上限区共 256 档。HDR 中高于白点的 R/G/B 样本数为 2,663 / 1,813 / 43；该 SDR 派生各通道均为 0。三条曲线与兼容显影共享绘图函数和计数尺度。 |
| SDR 与 B&W 像素 | 兼容显影各取 10,880 个可见样点，SDR 色度占 577 格；黑白占 1 格，R、G、B 三通道直方图一致。 |
| 返回焦点和过期结果 | SDR 已有测量在窗口失焦与返回时维持同一请求计数；新曝光提交后才生成新测量。并发旧曝光的返回结果由源身份、测量配方和蒙版校验拦截。HDR 使用同一全图样本计算目标、派生与诊断，节点仅改名和窗口切换可复用样本。 |
| 图表与冻结 | 原生工作台的 AX 布局检查分别测量直方图和矢量示波器，绘图区均为 96 pt，公差 1 pt。Graph 浮窗监看中间节点时，032 普通入口冻结完整图，目录依然只有原始作品版本。 |

同一实拍的 2× 原寸模型超出预览预算，原生预检给出具体原因、保留原图和配方，之后可继续调节曝光。不合格内容的负例复制同目录的真实兼容 JPEG 并命名为 ARW，验证取消与解码拒绝均保留原 0.625 EV 草稿。
