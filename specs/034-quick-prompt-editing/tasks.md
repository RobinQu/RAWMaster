# 034 · 实现与验收任务

优先顺序为 A → B → C/D → E。所有 ID 对应本规格的用户故事和成功标准。工程验收和正式发布分别记录。[产品规格](spec.md) · [实施方案](plan.md) · [原生验收](native-validation.md) · [模型验收](provider-validation.md)

## A · 体验确认与输入冻结

- [ ] QP01 产品、设计与 QA 按 quickstart 完成正式 D0。先核对底栏变形、编辑区域、内容保护、模型菜单与云端发送预览。记录 6 名摄影师试用及实际文案。HTML 已提供试走，真实应用实现开始前确认设计。
- [x] QP02 Core 冻结 Request/Scope、adopt CAS、工作区 ID、模型能力与配置、旧作业解码及 archive 引用合同。准备矩形、边缘、EXIF 8、撤销及迟到结果测试夹具。[US1, US2, US3]
- [ ] QP03 QA 固定真实照片留出集和单图对比口径。录入实际模型／许可资格、服务尺寸、部署参数、色域、输入批次及目标设备。[SC-02–05]

## B · 暗房、范围与假提供者

- [ ] QP04 编辑器实现原浮动栏的休眠／编辑／审阅状态，复用现有画布和焦点恢复机制。原生 26+ 玻璃和 15 降级、窄窗、减少动态、浅深主题与 VoiceOver 分别验。[US4, SC-01, SC-04]
- [x] QP05 成像、Core 实现矩形动作、键盘坐标及现有蒙版的快照映射。从已裁构图生成有界输入并核对冻结内容摘要，验证边缘正逆映射和保护区。[US1, US2]
- [ ] QP06 编辑器接入原创模板、双模型选择、设置往返、云端实际输入复核。先用存档 JPEG 和假提供者走一条局部、一条整张。从制作任务可回到原照片的候选，过期与严格纪实禁用采用。[US1–US4]

## C · 本机 FLUX.3 Image Klein

- [ ] QP07 模型组接入受管本机 MLX、版本化权重检查、模型空闲与取消回收。验短中文与完整场景提示的实际差别，冻结支持的离线处理方式并记录时延。覆盖机器断网和本机环境缺失。[US1, US3, US4]

## D · 云端 Seedream 5.5

- [x] QP08 接入北京端点的固定 5.5 模型，登记单图能力及返回格式。替身传输验授权与重入，真调用验尺寸、实际响应和回执。应用用例验证输入披露与核对。已发送中断进入核对状态，再次生成明确确认。[US2, US3]

## E · 写出、采用和签收

- [ ] QP09 成像和 Core 在相同冻结基底物化创作版，按原尺寸落盘局部合成并验证 TIFF16 保护区。全图标实际尺寸。原始素材、版本快照、备份及导出全部确认。[SC-03]
- [ ] QP10 编辑器完成同图对比、局部 100% 检查、回工作区、独立采用与一次 Undo。生成、收起、换片、原版变更、取消和重启的顺序由可靠的可控测试覆盖。[US1–US3, SC-05]
- [ ] QP11 按模型、范围及任务运行真实摄影留出集、Release 帧时与云端取消矩阵。记录首图可用率、题材差异、模型阶段性能及缺依赖路径，签收后对对应能力开放。[成功标准](spec.md#成功标准)
