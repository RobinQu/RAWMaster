## 准备和提交

1. **展开。** 「Prompt」放在底部浮条右端，带 sparkles 符号。点击或按 Return 后，原条以自身底部中心为锚点向左右和上方扩展。原控件立即离开焦点顺序，输入就绪时焦点进入 Prompt。当前照片、右栏面板、缩放、平移和浏览范围保持。临时收起原有对比隔层以便在当前构图选区域，退出恢复原对比。裁切、画笔或其他手势占用画布时，提示先结束手势。
2. **指定范围。** 标题旁显示「整张照片／矩形选区／已用蒙版」。点「圈选」后在照片内拖出矩形。范围只有在松手且有效时才完成。画外、零面积、目标超出当前裁切等情况保留上一次确认范围，并提示继续选取或明确选择整张。作用区用有描边的淡色覆盖，发送裁片的外沿在云端复核显示。「输入坐标」可用键盘填写左上位置、宽与高的可见画幅百分比。「使用蒙版」列出当前照片已确认、启用且与当前几何相交的蒙版。选择后缓存一份快照。
3. **写 Prompt。** Return 换行，Cmd-Return 执行与主按钮相同的校验和提交或云端复核。输入法组合、粘贴或文本选区中的 Cmd-Z 交给输入控件。常用模板点一次插入，现有文字保留。「更多」按用途提供短句。临时范围或文本编辑时，旧画布快捷键暂停。范围操作有可聚焦按钮、文本状态和对应快捷退出。
4. **选模型。** 模型菜单显示两个完整名称及「本机／云端」。就绪、需准备、离线与不可用都可定位设置。准备或配置完返回当前的草稿。即便记住上一回选择，云端每一次提交都需核对。
5. **复核云端。** 用应用现有的模态确认窗，显示照片文件名、本次模型、实际发送图的缩略图和尺寸、候选张数、完整提交文字和计费说明。局部预览是包含上下文的实际裁片，保护边缘另外描线。如果用户改变选区、模型或版本，原准备结果失效，按钮回到「核对并生成…」。确认后回到同一工具条等待。
6. **看结果。** 「生成前／候选」切换冻结基线和已合成的成片。两个视图同一定位。局部可用「100%」看接缝，整张显示结果宽高。排队、生成、整理结果按阶段播报。收起可继续看其他照片，「制作任务」与本张的 Prompt 保留入口。候选准备完维持当前焦点。过期结果标出原版本，当前作品上的应用禁用。
7. **应用或返回。** 「应用到照片」采用一个独立创作版本，浮条收回并呈现采用结果。Cmd-Z 或版本历史可以恢复原选择。先按 Escape 关闭临时菜单或结束正在画的区域，下一次收起 Prompt。收起时保留本张未提交文本。关闭窗口后可恢复已提交任务，未提交文本按编辑器会话寿命处理。「停止」与「收起」分别控制任务和界面。

## 快捷提示词

| 常用入口 | 插入输入框的起始文本 | 使用方式 |
| --- | --- | --- |
| 移除干扰 | 移除［干扰物］，按相邻光线与纹理自然补齐，保留周围对象的边缘。 | 优先圈住目标和相关阴影，填写目标名称。 |
| 替换背景 | 将背景改成［新背景］，保留主体的形状、发丝边缘和原有构图。 | 可使用现有背景蒙版。 |
| 调整光向 | 使用来自［方向］的柔光，保持人物五官、表情和服装细节。 | 建议从人物范围起步，实际光向与五官均需检查。 |
| 统一色调 | 将整体色彩统一为［色调］，保留构图、高光层次和原有明暗关系。 | 适合整张，纯参数调色也可使用智能预设。 |
| 更多 · 保护对象 | 保留五官与发丝。保留标识和原有文字。保持主要结构与透视。 | 分条插入句尾或光标位置，支持混用。 |
| 更多 · 光色与衔接 | 延续原图阴影方向。保留水面倒影。让补区纹理与邻域平顺衔接。 | 分条补充检查项，组合后仍可编辑。 |

方括号里的词是待填写的目标。模板版本随任务记录。原型的「更多」与上述列表共用原创文案，按摄影任务归类。[Dreamer / LibTV 的参考边界](research.md)

## 工具条在画面中的形变

| 状态 | 布局与动画 |
| --- | --- |
| 收起 | 沿用原浮条高度和底边位置。加入短标签「Prompt」，窄窗保留符号与可访问名称，触发区至少 32×32 pt。有待审结果时可加一个状态点并更新读屏名称。 |
| 展开 | 用照片画布安全宽度居中，宽度上限 672 pt，左右各留至少 12 pt。圆角矩形由原条连续增长。桌面上缘为标题、作用范围和关闭，中部输入，下方第一行模板、第二行圈选／复用蒙版／清除、模型、主按钮。空间不足时模板可横向滚动，范围和模型换行，主操作与关闭都可达。 |
| 审阅 | 同一块表面变成比较、检查范围、状态及采用区。进度或候选状态更替直接淡入相应内容。选区近底边时可在画布平移、做一次适配或进入 100% 检查。 |
| 过渡 | 以约 250 ms 无明显回弹的弹簧参数为起点。先从当前底边启动宽、高与曲率变化，后半段渐现编辑内容。收起走反向路径，重复点击从当前状态收敛。连续尺寸变化只作用于工具栏，照片锚点与比例保持。开启「减少动态效果」时直接更新布局，焦点规则一致。 |

在 macOS 26 及以上使用 SwiftUI 的 glassEffect(.regular, in:) 和共享的 GlassEffectContainer。保留稳定的玻璃标识与 namespace，交换内容并匹配形状。单个交互部件可响应鼠标。玻璃浮在照片之上，侧栏、照片和选区沿用既有层级。高频和明暗跨度大的照片上优先确保输入和标签清晰。主动作沿用产品强调色。.regular 用于需要阅读的输入和提示。macOS 15 使用现有 .regularMaterial，减少透明度或高对比下使用不透明底和边界。正文目标对比度 4.5:1、控件边界和焦点环 3:1。用白云、暗部、细纹理、浅色和深色分别复验。[Apple Liquid Glass](https://developer.apple.com/documentation/SwiftUI/Applying-Liquid-Glass-to-custom-views) · [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials) · [Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion) · [现有材质策略](../../Sources/RAWMaster/NavigationMaterials.swift)

HTML 用 CSS 的透明度、背景模糊和尺寸动画演示位置、切换及焦点。原生折射、系统偏好、GPU 使用与 VoiceOver 由 macOS 版本验收。[原型走查](prototype-review.md)
