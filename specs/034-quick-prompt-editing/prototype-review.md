# 快速 Prompt · 浏览器走查

2026-11-22 · macOS · Chrome 157.0.8103.80、agent-browser 0.26.0。场景在现有摄影工作台执行，复用「日落河湾」和同项目样片。模型、候选、服务回复和写入在本地模拟。模型推理和真实图像处理按原生任务复验。[从底部 Prompt 开始](../../docs/ui/prototype/index.html#edit/development) · [复验步骤](quickstart.md)

| 场景 | 结果和证据 |
| --- | --- |
| 同一个工具条展开 | 1440 × 900 深色画布，普通态 377.4 × 46 px，动画 125 ms 时量到 652.3 × 213.0 px，225 px 高的 672 px 展开态在 250 ms 到达。工具条底边始终在 y=882 px。普通翻片、裁切退出焦点序列，光标在 Prompt。Chrome 模拟减少动态时直接展开，焦点一致。[收起态](evidence/prompt-collapsed.png) · [展开与实拖选区](evidence/prompt-desktop.png) · [尺寸记录](evidence/toolbar-motion.json) |
| 范围和快捷词 | 实际鼠标拖出矩形并出现描边。键盘坐标可以设置同一种矩形。越界或零宽阻止确认。测了已启用蒙版、整张、模板占位和保护短句插入。Tab 从输入框进入第一项模板，Escape 可结束圈选及返回原入口。原对比恢复。 |
| 选两种模型 | 本机未准备时沿设置返回同一草稿，提交一项作业。云端预览显示矩形和所发送的上下文，另测整张构图。取消确认新增任务数为 0，明确确认新增 1。断网显示原因。[云端发送复核](evidence/prompt-upload-review.png) |
| 候选与撤销 | 等待、查看生成前、候选、100% 检查、显式采用和撤销都可走通。旧结果可从作品版本查看。修改原稿后，Quick Prompt 和作品版本均拒绝直接采用旧候选。验证了换片后结果归属、已出站未知状态、回查及重试返回原 Prompt。[候选比较和采用](evidence/prompt-candidate.png) |
| 试窄窗、浅色和键盘 | 1100 × 720 中收起和提交可见，浅色状态经截图核对。390 × 844 的浏览器布局保持在视口内。测试了输入法组合态的 Escape、键盘提交和关闭后焦点。[1100 × 720 浅色](evidence/prompt-compact.png) |

摄影工作台的 21 组自动浏览器场景全部通过，其中 7 组覆盖快速 Prompt。几何时间是浏览器的动画参数和抽样，不作为 macOS 首次呈现或推理计时。HTML 的既有蒙版用示意范围，候选外观用同样片的局部颜色变化。D0 摄影师走查、系统 Liquid Glass 与 VoiceOver，以及 027 坐标、TIFF16 保护区和真实两模型服务留给原生阶段。[浏览器记录](evidence/browser-check.log) · [原生任务与放行](tasks.md)
