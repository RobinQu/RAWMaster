# 快速 Prompt · 体验评审与首个原生切片

在资料库选中「日落河湾」进入编辑，或直接打开[摄影工作台暗房](../../docs/ui/prototype/index.html#edit/development)。到画布下方点「Prompt」。浏览器里的模型、上传、用量和处理结果是演练状态，所有示例图来自仓库样片。「制作任务」里的模拟中断与失败可用于走查。

| 场景 | 步骤 | 签收观察 |
| --- | --- | --- |
| 局部，本机 | 选「准备本机模型」，在设置勾选示例条款并准备。返回本张，填入「移除干扰」并补上目标。用鼠标拖矩形，或从「范围工具 → 输入坐标」输入左 22%、上 28%、宽 38%、高 24%。点击「生成候选」，对比后应用并撤销 | 点入口时原条长高逐步增加。范围描边、模型和主动作可同时看到。输出前后同一构图，撤销回原版本，只增加一笔可撤销采用 |
| 复用蒙版 | 在右栏给本张加一个蒙版，打开 Prompt，选择「范围工具 → 使用现有蒙版」。在另一张无蒙版的照片重试 | 有蒙版时复制有效范围，无蒙版时引导直接圈选。清除范围后显示「整张照片」。未完成选区期间提交禁用 |
| 云端，局部与整张 | 切到 Seedream 5.5，配置设置中的「Seedream / 中国方舟」。回到本张核对裁片和追加短句，先取消，随后明确提交。放弃候选，清除范围并再次核对整张 | 第一次取消没有新任务。第二次显示 1 张候选。整张复核显示当前已裁构图，局部显示描边与边缘上下文 |
| 任务与边界 | 在等待时收起、从浮条换片，再去制作任务核对所属文件。对已发送云请求按「停止」，检查「结果待核对」。用任务详情模拟一次失败，回编辑重填或重试。选择严格纪实，再开 Prompt | 关闭浮条只收起界面。候选留在原照片。已发送的未知结果无自动重试。严格纪实显示阻塞，原生调整仍能打开 |
| 键盘与显示 | 仅用 Tab、Shift-Tab、Return、Cmd-Return、Escape 执行。用中文输入法、浅色、深色、高对比、减少透明度和减少动态效果试跑，在 1100×720 与 1440×900 下重复 | 主动作和关闭一直可达，快捷键无意外换片。展开焦点入编辑框，退出回「Prompt」。既有对比和画布位置恢复 |

浏览器回归命令为 `python3 scripts/check-ui-prototype.py`。下阶段应将同一场景用于真实 RAW，记录窗口尺度及光栅尺寸、色彩配置、源及结果 SHA，另跑 VoiceOver、原生材质和两模型实测。按 [US1–US4](spec.md#用户故事与验收) 记录实际输入、错误编号与试用人数。[实施顺序](tasks.md) · [已完成的浏览器走查](prototype-review.md)
