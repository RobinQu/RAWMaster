## 产品目标

摄影师已经知道这张照片要改什么，例如清掉路牌、替换杂乱背景，或让整张图呈现更冷的夜色。他可以在暗房画布下方点「Prompt」，让原浮动工具条展开，圈定范围或使用整张照片，写一句要求，选择本机 FLUX.3 Image Klein 或火山方舟 Seedream 5.5，再在当前画布审阅一张候选。适合反复使用的参数方案仍从右栏「智能预设」开始。需要先商量方案的用户可以在原型中试走「Agent 对话」。下一批原生研发优先交付快速 Prompt。[030 智能编辑与三场景计划](../030-ai-retouching/spec.md)

## 用户故事与验收

| 优先级 | 摄影任务 | 独立验收 |
| --- | --- | --- |
| P1 · US1 局部清理 | 在裁过的河岸或街景照片上圈住路牌，填入「移除干扰」并写明要保留的人与倒影，选本机模型 | 给定已就绪的本机环境，当用户圈选并生成时，候选和生成前可在相同画幅下对比。应用后产生一份可导出的创作版本，选区外在同尺寸、同色域的 TIFF16 对照中逐通道差为 0。一次撤销恢复原来的版本选择 |
| P1 · US2 整张创作 | 在同一暗房对一张风景照写下全图风格要求，选 Seedream 5.5。也可为已确认的背景蒙版写下换景要求 | 未圈选时显式显示「整张照片」。确认窗展示本次上传的图、处理范围、尺寸、模型、提示词及计费状态。取消确认时调用数为 0。批准后只提交一张输入，生成一张候选。输入是圈选裁片时可看到会发送的边缘上下文 |
| P1 · US3 审阅与恢复 | 生成后关闭工具条、换片或离开暗房，稍后回到对应照片继续看结果 | 无误应用、错片或重复提交。失败回到已填写指令。云端已提交但无回执时显示「结果待核对」。旧基线产生的成片可在对应任务或版本找到，当前编辑已变化时必须回到提交时的版本才能采用 |
| P1 · US4 快速起稿 | 从模板选择移除、背景、光向或色调，再插入保留文字、五官或纹理的短句 | 所有文字在同一输入框可见可改。点模板、圈选、换模型、退出都不会生成。提示词缺失、仍有占位符、局部范围为空、模型未就绪和严格纪实都给出各自的处理路径 |

## 功能要求

| 编号 | 必须实现的行为 |
| --- | --- |
| FR-01 | 正式入口位于单张暗房画布下方的悬浮工具条。展开后原栏的翻片、缩放、裁切、对比与背景控件退出可交互视图。展开面板仅含 Prompt、范围、模板、模型、提交与当前任务或候选。退出后回到原工具、画布位置及焦点 |
| FR-02 | 初始范围是整张**当前构图**。用户可在画布拖出一个矩形、输入矩形百分比坐标，或复用当前照片已确认且启用的一个蒙版。可清除并显式恢复整张。刚进入圈选但未形成有效区域时，提交禁用。圈选草稿无需写入蒙版列表和历史 |
| FR-03 | 单个文本框支持多行输入。快捷项插入可编辑文字，保留已有草稿和插入位置。未填提示词或占位符阻止提交。用户可核对本次提交文字。本机如需模型专用展开，记录原文和最终描述，在「任务详情」可查 |
| FR-04 | 同一 Prompt 面板列出「FLUX.3 Image Klein · 本机」与「Seedream 5.5 · 云端」。首次使用默认选择本机。同一草稿记住上次选择。需要设置时可去准备模型或配置方舟，再回到同一工作与草稿。服务失败由用户决定是否换模型 |
| FR-05 | 本机就绪点击「生成候选」直接提交。云端点击「核对并生成…」先核对实际发送图、尺寸与上下文，再明确确认。局部请求上传有边缘上下文的裁片，整张请求上传当前已裁构图的渲染图。发送清单仅含本次图像数据、提示词及模型参数 |
| FR-06 | 一次提交冻结照片、版本、当次调整、几何、范围、模型版本与提示词。先展示同基线的「生成前／候选」和局部边沿，两个视图保持构图与比较位置。就绪候选须由用户点击「应用到照片」才成为当前采用版本。丢弃只处理候选与审核状态 |
| FR-07 | 应用把已归档的独立创作候选切换为当前采用版本，记录一次可撤销的版本切换。RAW 草稿、原片和之前的作品版本继续可用。局部合成保留冻结成片的原尺寸与保护区。整张输出明确显示实际宽高，按模型输出保存。再次打开、回退或导出从归档读图，模型调用数为 0 |
| FR-08 | 每张照片同一时间只有一个 Quick Prompt 生成尝试。等待时可收起工作条或换片。无真实百分比时只显示阶段。未提交可取消，本机停止后释放工作。云请求已出站、取消或断连无法确认时保留原尝试与使用量状态，恢复先核对原任务 |
| FR-09 | 严格纪实作品及其受保护的交付链路拒绝 Prompt 生成与采用。UI 显示原因，原生的曝光、白平衡、色彩和可编辑蒙版仍可继续使用。创作版本的候选审阅覆盖人物身份、原有文字及场景结构 |
| FR-10 | 工具条宽高由原浮条连续变形为展开态，底部对齐。支持浅深外观、对比增强、减少透明度、减少动态效果、窄窗及全键盘操作。输入和输入法组合过程由输入框处理。关闭、停靠与范围取消均有可宣布的状态 |

## 成功标准

| 编号 | 放行条件 |
| --- | --- |
| SC-01 | 6 名摄影师各完成一次局部和整张流程，每条流程至少 5/6 从现有暗房自主找到入口、判断发送或改动范围、对比候选并返回原编辑。未确认发送、跨片或过期采用、审阅期间的历史写入均为 0 |
| SC-02 | 两个模型各走一次局部与整张完整链路。真实照片留出集每模型每范围至少 12 张，覆盖原片横竖画幅、人像和风光及创作型街拍。QA 逐张记录首次候选可用率、面部／文字／结构损坏及边缘失败，按操作分别据实开放。严格纪实验收覆盖拒绝路径 |
| SC-03 | 局部所有通过采用的用例中，最终 Matte 为 0 的像素与同管线的冻结基线比较，TIFF16 最大通道差为 0。EXIF 8、镜像、非整数缩放、裁切边、选区边和候选尺寸不匹配均有对照。关机重开、撤销和再次导出稳定，源 SHA 一致 |
| SC-04 | 主窗口 1440×900 pt 与最小窗口 1100×720 pt 上，点击到工具条开始变形 p95 ≤100 ms（30 个暖样本），完成态目标 220–280 ms。动画和圈选本身触发 RAW 重新显影、图片上传、模型调用数均为 0。前后台模型时延、首轮与暖轮、内存另记实测 |
| SC-05 | 断网、本机未准备、云端不可用、已出站中断、立即换片、重复点击、应用前变更几何及重启后收到事件，各自得到可复现状态。一次显式云端确认至多一次生成请求，对未知结果回查产生的新请求数为 0 |

## 交付顺序

先贯通单张、单候选、矩形／可复用蒙版及整张模式。上线候选以两种模型均完成对应能力实测为目标。直接画笔和套索、参考图导入、多候选、用户自建模板和批量执行各自另排。首批智能预设仍按 030 覆盖人像、风光、纪实。生成式场景卡和 Agent 原生对话各有自己的验证与排期。[交互验收脚本](quickstart.md) · [模型比较与证据](research.md)
