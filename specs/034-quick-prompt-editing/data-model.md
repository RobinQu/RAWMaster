# 034 · 数据模型

| 实体 | 生命周期与字段 |
| --- | --- |
| PromptDraft | 编辑器会话内，按资料库、作品、编辑分支隔离。原始文字、模板 ID／修订、光标、模型选择、准备中的范围、最近焦点、当前证据／提示。相同作品切回恢复。源、裁切、镜像、角度或配方已改变时清除原范围，保留文字供重新准备 |
| PromptScope | `wholeFrame`、`rectangle` 或 `confirmedMask`。共享冻结的输出坐标身份。局部记录量化后的整数矩形、Matte 内容哈希与渲染采样版本。复用蒙版带来源快照 ID 和内容摘要。已有蒙版兼容现有 Gray8，实际贴回以冻结 Matte 为准 |
| PromptInputSnapshot | workID、baseVersionID、draftBranchID、提交时的配方修订与指纹、原始或衍生输入内容 ID、当前画幅与 ICC、用户文本与最终有效文本、模型与参数、图片文件摘要、请求图尺寸、裁片与变换、授权范围、命令 ID。保存在现有作业请求里。同一快照永远可追溯 |
| PromptAttempt | ProcessingJob 的一次尝试。attemptID、runID、准备／提交／发布阶段、出站时间、服务回执、可核对的用量状态、模型产物及其哈希。本机与服务取消按各自能力回报。再次生成用新的尝试与确认 |
| PromptCandidate | 无损候选／最终成片引用及实际宽高、位深、颜色配置、匹配的输入摘要和任务。状态为可审阅、已采用或已放弃。记录选区／合成所需材料、模型信息与原始提示词。适当清理未采用文件，保留引用关系 |
| PromptAdoption | 单份作品版本采用命令。记录父版本指纹、候选、用户采用时间、前一采用版本和回滚令牌。在当前作品的版本历史显示一条可撤销事件。后续收据可追溯创作来源 |

画布选区和任务输入都用 top-left 坐标。实际授权上传裁片由最终像素矩形、文件摘要和同意事件共同确定。一个 ID 只标识一种内容或阶段，应用普通蒙版不会修改已建立的范围快照。[合同](contracts/quick-prompt.md)
