# 快速 Prompt · 请求、回执与采用合同

本合同描述进程内类型和服务结果边界，沿用现有 AIEditingProvider、ProcessingJob 与 EditingArchive。[数据模型](../data-model.md) · [现有提供者接口](../../../Sources/RAWMasterCore/EditingModels.swift)

| 命令 | 前置条件 | 受理结果 |
| --- | --- | --- |
| Prepare | 作品、当前分支、选中的输入版本与策略匹配。提示词有效，范围已经完成，模型适配器有对应能力。 | 冻结包括画幅、Matte 范围、实际图像字节及最终提示词的请求快照。系统仅把准备好的预览和摘要交回原会话。 |
| Submit | 同一快照与当前已确认的用户选择匹配。云端存在同一图像摘要、目标、范围和参数的确认事件。 | 在发送前记录 commandID、attemptID、runID 及提交意图。重复同 ID 同内容返回原尝试，冲突拒绝。状态进入排队或处理中。 |
| Cancel / Reconcile | 任务存在且属于当前库。 | 未出站可停止。已出站但无法证明终止或收费情况时显示 outcomeUnknown。核对只读原尝试，优先恢复本机收到的结果，等待服务核对或用户处理。 |
| Stage candidate | file SHA 与响应都通过验证，输入源及合成合同匹配。 | 在相同作品原输入上物化独立候选并登记色彩、几何与影响范围。迟到结果留在原任务，不切换其他编辑器中的显示。 |
| Adopt | 该候选仍可用，基线版本与请求时修订匹配，策略允许内容变化。 | 在一个版本采用事务中记录一条历史和新的采用版本。失败保留旧选择，撤销从记录恢复。 |
| Retry | 前一次结果已明确不可用或用户从原任务手动发起新生成。 | 创建独立快照与尝试。需要云端时再次核对发送和费用。未知结果提供核对口径，禁止静默复投。 |

局部或整张的二进制材料用内容寻址归档及上限校验。不得将鉴权头、API Key、原片位置、长提示正文、图像字节写进公用日志。用户在本地作业详细信息可核对其输入与实际提交文字。现有历史记录缺少 Prompt 元数据时按旧产品行为读回。

Seedream 5.5 的新适配路径只需单张 `image`、`prompt`、版本化 `model`、经验证的尺寸和输出参数。P1 按 SDR 不透明单图核验 PNG，`b64_json` 复用现有有界传输。保留方舟的实际水印配置与返回证据，若可见标记影响照片交付则在采用前展示和拒收。局部保护依赖本机 Matte 和合成合同。最大输入、输出尺寸与收费字段按冻结 API 版本和运行回执核对。[火山方舟图片生成 API](https://console.volcengine.com/ark/region:cn-beijing/docs/image-generation-api)
