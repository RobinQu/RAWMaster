# 006 · 界面合同

侧栏：导入与初筛（仅活动批次）→ 项目（长期工作）→ 导入历史（关闭及旧版记录）。全部素材默认仅已纳入常规素材，待初筛通过明确入口进入。项目来源区可查看各次导入。

初筛：拍摄数/文件数、接入与分析状态、全部/建议排除/已排除/需复核；主按钮通过/排除/清除、检查质量、完成初筛。评分与标签放项目，复用单张/比较/RAW复核。未达标自动分组标记未启用，可手工组织，不显示假完成。

组合卡：RAW+JPEG徽标、展开按钮、单文件来源切换；不把外部JPEG和RAW内嵌预览混淆。动作默认整对，单文件例外必须展开并显示范围。筛选检查全部文件，收起不能使匹配文件或已选对象消失。

完成面板列出目标项目、纳入拍摄／文件数、排除、仅序列用途、异常、未分析项与有归档资格的原件数量及大小。被排除的必要帧显示受影响的组，提供“保留排除”和“改为仅序列用途并纳入”。整批预览确认后封存，进入项目与只读导入历史。

历史显示只读初筛报告，排除项注明“原件未随本次导入归档”。恢复到原项目时列出选择的实际文件，离线先找回并核验。从未核验的失败项引导新会话重新接入。未完成旧接入可续接，旧已完成且无初筛记录的会话显示“旧版导入，初筛状态未知”。

项目：精筛决定、评分、基础标签、比较及现有处理入口、格式化交付选项。没有显影能力时不展示虚假可用编辑操作。主题/焦点/原片可用性继承现有行为。
