# 006 · 与005实验的衔接

另一对话“规划 SDD 项目特性”拥有Sequence*、RAWMasterSequenceProbe、既有Fixtures与005质量/实验结果；本轮已向该对话发送工作边界。006拥有应用工作流、Core会话/成员/配对/交付、独立质量建议服务、新增测试和006规格。

事件适配输入应包含稳定captureID、全部原文件assetID与内容版本、原顺序、相机证据及原时间证据；唯一确认的配对才折成一个时序事件，散片仍为单事件。视觉来源明确且版本固定，不能静默把RAW预览换成JPEG以避开失败。每个事件结果都映射回全部原文件，不丢文件和位置。

配对变化使相应分析结果过期。用户解除/纠正保护不被重跑覆盖。事件级指标与逐文件完整性分别计量，新协议独立version和baseline，原有逐文件评估照旧保留。

生产检测入口需要005明确提供：版本固定的可取消服务、来源证据合同、质量通过记录、未知/失败覆盖、完整作用域原子结果。未齐全时006显示未启用，允许用户手工初筛后完成，不把任务排队或实验测试通过称为检测完成。

质量建议服务输入/输出应为Sendable值：资产ID、内容hash/大小、实际URL；输出记录相同身份、分析层级、方法版本、指标、风险/未知/故障。只读原片；提交时复核身份；缺元数据、不支持与损坏不等同摄影低质量。Core存储与Imaging实现依赖方向保持Core←Imaging。
