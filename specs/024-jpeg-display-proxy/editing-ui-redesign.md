# 编辑工作流与右侧工具栏复刻说明

## 参考证据

- Lightflow 当前发布界面的实际 DOM、辅助功能树和截图位于 `output/lightflow-research/editing-ui-current.png`、`editing-ui-wide.png`。
- 顶部工作流为 Library／Develop／Export；右侧当前编辑面板的实测宽度为 304 px。
- 调整页使用固定分区标签、当前编辑目标、组级复位和连续控件列表。
- 标量控件使用名称、轨道和可编辑数值；名称支持横向拖动，双击名称复位。实测滑杆行高约 22 px。
- REA 静态分析只用于恢复发布结构与调用关系；界面行为以实际页面观察和 RAWMaster 自动化测试分别验收。

## RAWMaster 映射

### 固定工作流

标题栏在资料库、目录、网格、单张、比较和编辑视图中保持“资料库／编辑／导出”三个入口。导出页签在导出 sheet 或草稿选择出现时保持选中。网格中选择照片后进入编辑，会先切换单张视图，再使用同一 admitted 来源。

### 调整分区

- 基础：白平衡、光效、颜色、定义。
- 影调：曲线、色阶。
- 混色：黑白、可选颜色。
- 细节：降噪、锐化、Texture、Clarity、Dehaze。
- 局部：修饰、红眼。
- 高级：已有配方与色彩分级。

分区直接展开相关控制，不再要求用户先打开一个折叠项、再进入另一个页面。当前编辑菜单保留复位照片调整与复位全部编辑。

### 标量控件

- 名称、滑杆和数值字段位于同一行，使用 11 px 标签和固定 26 px 滑杆高度。
- 名称横向拖动使用范围映射和既有滑杆量化；数值字段保留完整输入精度。
- 双击名称只复位目标字段，不复位同组其他参数；辅助功能动作走同一业务入口。
- 组级启用、自动调整、复位、撤销和重做继续使用现有命令与会话作用域。

### 视觉与状态

- 浮动命令和照片工具使用现有 Liquid Glass 策略；减少透明度和增加对比度时回退到不透明材质。
- 照片画布与长期编辑面板保持中性、不透明背景，避免玻璃材质影响颜色判断。
- 失焦后保留只读工具快照；恢复焦点后创建新交互 epoch，旧回调不能写入。
- 只有真正处于初次读取且没有可显示快照时才显示“读取照片调整信息”。

## 不复制的内容

不引入 Lightflow 的节点编辑器、预设数据库或 WASM／WebGPU 运行时；RAWMaster 继续保留原片只读、独立候选版本、显式采用和 canonical 保存／导出语义。布局复刻不改变既有配方数值或颜色契约。

## 2026-11-21 双栏与实时编辑迭代

- 左侧 232 px 工具栏提供滤镜和可点击的操作历史；历史支持初始、中间及未来状态恢复，撤销／重做继续使用同一 session 作用域。
- 此轮设计曾将当前资料库胶片固定在照片下方。后续暗房改用浮动工具条前后翻片，悬停或聚焦按钮显示邻片，沿用资料库的浏览范围与排序。[当前交互与 HTML 走查](../025-editing-workspace/prototype-review.md)
- 右侧只保留调整工具；裁切入口位于画布浮动工具条，比例、拉直和几何控制显示在画布右上方面板。
- 标题栏只保留“资料库／编辑／导出”，不再重复放置右侧导出和更多操作。
- 调整不再要求手动保存候选。`PhotoWork.liveRecipe` 与 `liveParentVersionID` 保存当前生效配方；写入经过 180 ms 合并、乐观修订和退出前 join，不生成像素或重复候选。
- 导出面板的“当前编辑”直接冻结并完整渲染实时配方。分析尚未完成时仍拒绝导出旧状态。已有不可变版本和显式采用逻辑保留给历史版本、AI 和外部编辑。
- 白平衡、色相、饱和度及明度使用原生 NSSlider 的语义渐变轨道；直方图使用对数归一化，避免少量高光像素被峰值压平。
