# 工作台搜索、网格动作与信息对比

2026-10-25 用户需求：

- 网格常显搜索，点击展开内联筛选，使用分类图标和有文字的彩色标签；单张、对比隐藏搜索和明细，保留检索结果与条件。
- 筛选不占照片信息栏。全局创建导入会话放左栏；网格右上仅项目导出和右栏开关；单张显示照片导出和外部编辑动作。
- 网格多选浮动操作栏支持 RAW+JPG 关联、拍摄序列、批量导出与对比。仅单张显示底部胶片条；对比改用侧栏候选照片。
- 对比换片保留参照，最多四张；存在至少两张匹配照片时，不因普通点击或⌘取消降为单张。
- 对比侧栏替换照片信息，提供 RGB、EXIF/文件信息、直方图；信息模式读取所选文件，直方图明确标注实际预览来源并使用统一尺度。

实现约定：单张导出只复制当前真实文件，批量导出固定当次选择（收起的组合卡保持原有整对选择语义）；明确导出范围同时约束复制和CSV/JSON清单。外部编辑创建独立可写工作副本，保存在 Application Support/RAWMaster/Editor Copies 中，再交给 Photoshop 或用户选择的应用。

视觉参考：[Apple Finder 搜索范围与附加条件](https://support.apple.com/en-gb/guide/mac-help/mh15155/26/mac/26)。标签颜色为本应用的视觉提示，不修改 Finder 标签。

范围：保留现有006/007/008及序列算法实现；本轮不改变导入、分组算法、原片字节或数据库结构。
