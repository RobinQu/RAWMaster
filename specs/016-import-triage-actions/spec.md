# 导入与初筛会话操作

## 用户流程

会话区分素材接入与人工初筛。接入中断时，“继续未完成的导入”使用同一会话及检查点。接入完成、初筛仍开放时，用户可以重新扫描分组或直接继续人工初筛。分组分析整批已完整接入的素材。扫描来源目录是另一个明确的操作。

标题区显示来源批次、当前阶段、整批文件数与初筛处置计数。主动作随实际任务切换：暂停接入、继续接入、取消分组、取消风险检查、完成整批初筛。任务取消必须等后台实际结束后才允许启动下一任务。

浏览范围与会话操作分开。选择拍摄组仅改变照片列表和所选照片操作；接入、重新分组与完成初筛始终作用于整批。辅助工具集中提供 RAW+JPEG 关联、风险检查、证据和操作记录。历史会话保留查看与恢复能力，不能在原会话重新分组。

2026-11-22 修订。封存后提供“查看导入记录”“恢复到项目”“从此来源再次导入”。再次导入创建新会话，历史恢复只登记新纳入的已核验文件。完成摘要对必要帧显示保留排除的影响及明确改判为仅序列纳入的选项，按文件预览其归档资格。重启后分别验收续接、查看、恢复和再导入四条路径。[导入处置与验收](../006-import-triage-workflow/spec.md)

## 重新分组的边界

- 自动接入回调保持原来的成功后不重复策略；用户主动重新分组走独立入口。
- 只替换从未经过人工操作、未锁定、仍待复核的自动组；人工创建或调整的组及受人工历史保护的成员保留。
- 分析完成后一次提交替换及历史记录，支持撤销。取消、失败、源文件变化或并发修改时保留旧组。
- 新结果为空时允许以一次可撤销操作移除符合条件的旧自动组；双方均空时不产生无意义组历史。
- 保留全部照片及人工初筛决定，不修改、移动或删除原文件，不把分组成功视为初筛完成。
- 完成初筛的核验、异常和人工确认规则保持，确认页明确整批来源与范围。

## 验收

验证成功后重跑、空结果、失败与取消后的重试、人工编辑及撤销保护、并发冲突、事务回滚、完成与未完成接入及历史状态。验证标题区的主次操作、整批计数、子组范围说明、禁用原因和目录入口一致性。保留拍摄组属性/成员操作和延时视频播放回归。
