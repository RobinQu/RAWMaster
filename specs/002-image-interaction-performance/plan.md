# 实现与验证计划

保留 SwiftUI 工作台外观、SQLite 数据模型和只读来源策略。先保留原始构建，再仅加入可选应用内计时，在真实窗口测量。已取得修改前 5 次网格输入：NSEvent 按下到选择 423–433 ms，选择到 NSView 更新 5–7 ms，符合双击识别等待的表现。

使用原生卡片输入处理器，在 mouseDown 立即选择，根据 clickCount 处理第二击；右键与滚动交回原有界面。手动选择与键盘显示请求分别处理，移除每次选择后的强制居中动画。对修饰键、双击、辅助功能和视口建立回归。

发布配置测试分两段顺序运行：交互处理器/视图更新；真实 RAW 解码与画布离屏绘制。保存 JSON 原始样本和统计值，检查绝对预算，并支持同机同样本前次报告的回归比较。运行脚本明确要求真实 RAW 目录。
