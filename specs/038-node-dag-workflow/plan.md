## 当前实现与验收边界

- **兼容图。** 从旧 v1–v3 照片打开只读 Graph，同时复验原编辑、撤销、重开和 SDR 导出。最新 Release 提交修复了 Finder 正常启动时两个入口变量缺失的问题。JPEG 冒烟覆盖 HDR 模式条和只读 Graph，实际可编辑图专门使用固定 SHA、已校准的 ARW。[默认入口修复](validation.md#release-默认入口修复)
- **可编辑图。** 已准入 ARW 从 037 HDR 草稿进入。原生已接曝光／强度、混合、组、连接草案、临时监看、模板和候选批量。EV 曲线、解析覆盖及 Outside 图命令另有引擎证据。完整九类调色、画布工具和模型资源尚有接线与验收缺口。[原生 Graph](validation.md#原生可编辑-graph) · [候选批量](validation.md#原生模板与可恢复批量)
- **当前验收。** 签名包已覆盖监看中保存、重开和两种固定目标交付；本轮补入两种纯画布 Graph、示波器实际回执、032 持久回执，以及图内版本化模型阶段。异源大批量、更多调整类别和各个可选模型仍按对应样本验收。[编辑器走查](../025-editing-workspace/editor-rails.md) · [037 放行](../037-color-film-hdr/plan.md) · [039 迁移](../039-rust-scene-backend/spec.md#迁移顺序)

## 场景图工程门槛先于实测

- **像素与状态。** 固定 CPU 向量的混合 F32 绝对误差 ≤ 8×10⁻⁷、alpha 相同，窗口与整幅对应像素相等。按同源 AP1 图验串行、Parallel 增量、Layer 顺序及 13 模式、Group、Outside、遮罩依赖和全源 ROI。监看、旁路及未提交连接在保存、重开、032 交付时均不替代最终根。原型用来核对动作和状态。
- **图组件。** 沿用 960×640 常驻 F32、双曝光支路、解析覆盖和混合。两轮各预热 5 次、采 30 次，计调度、分配、提交及 GPU 完成，p95 每轮 ≤20 ms。24 MP 冻结版写盘和独立回读另测。
- **原生浮窗。** 1200×640、雪景常驻、组内节点与最终图交错，每方向预热 5、采 30 次。命令至对应 SDR 浮点 drawable 完成 p50 ≤25.92 ms、p95 ≤210.23 ms。实体输入、冷读、实际合成、复杂拖动与批量另跑。[统一测量口径](../035-portable-processing-cores/roadmap.md#证据与测量口径)
- **候选事务。** 20 项提交 ≤15 秒、200 项提交／取消／重开／重试 ≤120 秒，核对 SHA、目标修订和撤销。同内容可复用校准。异源镜头、冷 I/O 与 032 真文件的批量吞吐单列，核对取消时已发布成片和每项目票据。

## 实施顺序与放行条件

| 阶段 | 接续当前实现 | 退出条件 |
| --- | --- | --- |
| T01 · 视图与命令 | 复用现有目标、阶段原型及 [039 界面原语](../039-design-system/spec.md)。 | 主图和 Graph 独立，可读取景和原焦点恢复。补 AppKit 键盘、VoiceOver、减少透明／动态、四种底色及窄窗。核对离线、取消与退出。 |
| T02 · 配方与兼容 | 复用 v4 场景图和 v1–v3 只读适配。 | 真旧版本、早期 v4、候选和撤销栈可回放。未知版本、非法端口、缺资源及错误来源被拒绝。旧 SDR 保持原像素，场景按 AP1 最终根提交。 |
| T03 · 当前原生闭环 | 与 037 同一签名包、样本与隔离资料库。 | JPEG 只读图和合格 ARW 可编辑图均从应用正常入口可达。核对缩放、焦点、撤销、换片、保存／重开及 032 冻结版本，分别读回 PQ 和 SDR。 |
| T04 · 多节点和查看 | 复用串行、Parallel、Layer、组与连接草案。按 039 核对组路径解析、实际执行回执和冻结最终根。 | 复杂图用实际指针和键盘复验，验证切片、切组、重试和迟到的 GPU 结果。Swift 参考与严格 Rust 输出同义，有且只有一个可交付最终根。 |
| T05 · 工具和批量 | Mask 绑定节点，Crop／Remove 属于照片级阶段。逐算子接通，再扩展可重绑模板与 032。 | 异源 20 张成功与 200 张部分失败的成片闭环，含取消、重启、接回、重试、撤销与后续版本冲突。用 036 口径跑冷暖 FIT、1:1 和实际监看，记录末端和任务峰值。 |
