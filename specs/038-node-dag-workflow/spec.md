# Feature Specification: Node 能力域、画布工具与悬浮工作流

**Feature Branch**: `038-node-dag-workflow`（功能标识；本轮在现有 `main` 工作区更新原型，未创建或提交分支）

**Created**: 2026-11-26

**Status**: Draft

**Input**: User description: "确保编辑面板分类属于当前 Node 的能力范围；Crop、Mask、Remove 从照片底部悬浮工具条进入，动画展开详细面板，完成后收回；Graph 改为 Liquid Glass 悬浮窗口，与主图实时交互；再次复核 LightFlow 节点清单与实现，更新原型并输出 Spec Kit 规格。"

本规格替代第一轮“Graph 替换照片”的布局。当前交付为可操作 HTML 原型与功能规格，等待用户评审；不宣称原生引擎、模型、持久化或像素已实现。采用 [Spec Kit 官方规格模板](https://raw.githubusercontent.com/github/spec-kit/main/templates/spec-template.md) 的用户故事、功能要求、实体、成功标准与假设结构；仓库没有 `.specify` 目录，本轮不安装或伪造 Spec Kit 初始化。

正常入口：[摄影工作台](../../docs/ui/prototype/index.html) → 编辑 → 节点工具条 → Graph。直接走查：[悬浮 Graph](../../docs/ui/prototype/index.html#edit/dag)。Crop、Mask、Remove 从同一张照片的底部工具条进入。[节点能力及 LightFlow 取证对照](node-capabilities.md) · [验证记录](validation.md)

## 节点工具条与最小可视面积（本轮交互修订）

从编辑右栏「当前节点」下拉进入：列表只列本照片当前组中的可编辑调色、混合和组节点；没有时给空状态与添加入口。Input、Output 和 Crop 不混入选择列表，仍作为图上固定阶段；独立「基础校正」入口通往 RAW 输入参数，Crop 仍从画布工具条进入。下半部保留「添加节点」「自动整理」「更多节点操作」。右侧常驻「忽略该节点」及 Graph 窗口开关，不再有独立菜单按钮或下方「主图 / Graph」双按钮。Graph 开关只控制浮窗，不替换照片。节点工具条是右栏上方独立的操作面板，下方编辑检查器以短间距分开，仍与当前节点联动。编辑检查器顶部的 [037 色彩模式](../037-color-film-hdr/spec.md#用户入口与状态归属)是照片草稿级设置，不承担 Graph 开关、节点管理或节点参数的作用；只让参数区域内部滚动，不把右栏拆成两个浮窗。[分区走查](../037-color-film-hdr/validation.md#右栏色彩模式与节点面板分区)。

「更多节点操作」首层仅放命名、复制插入、参数粘贴、复位、查看输出与删除；组、连接、监看、模板及整图命令折叠在高级操作里。所有节点操作沿用明确照片、路径、选择与配方修订。下拉取消或 Escape 不改节点与历史，并返回下拉按钮；Graph 点击、键盘选择、组内选择与下拉共用当前节点，检查器和忽略状态同步。单张忽略按钮只作用于一个可忽略节点，多选、固定阶段、连接或画布草案时禁用并说明原因。忽略保留参数、结构和覆盖，恢复及撤销可回到原结果。

展开浮窗的桌面最小外框为 520 × 392 CSS px，保留至少 480 × 240 的实际 Graph 画布；标题、路径、状态与操作条不占用这块面积。连接草稿额外增加 44px 高度。屏幕不足 544px 宽时外框随可用宽度收窄，画布高度仍不少于 240px（390px 视口下画布约 364px 宽）。高度容不下展开窗时只显示可关闭的标题条，说明需增高窗口，不把画布压成不可操作条带。此数值是本轮原型方案，不冒充 LightFlow 原值或原生系统窗口约束。复杂图 FIT 仅保证包含所有卡片；可继续放大和平移，不承诺任意规模全图文字始终可读。

走查：[悬浮 Graph](../../docs/ui/prototype/index.html#edit/dag) · [本轮场景与证据](validation.md#节点工具条精简与选择联动)。

## Graph 上下文菜单与临时查看

在[同一浮窗](../../docs/ui/prototype/index.html#edit/dag)右键节点、连线或空白（键盘 Shift+F10 或菜单键）。右键不进入框选或拖动。选中节点右键保留多选，右键其他节点仅选中该节点。节点只露出当前可用的查看、复位、复制或删除等动作；连线提供插入和连接编辑；空白提供添加、粘贴及视图整理；模板、组和整图操作由「更多」保留。Escape 关闭菜单并回原处。

右上角按「串行／并行／Layer」「Solo／旁路调色」「整理／适合全图／监看」分组。Solo 只对单个启用的调色节点开放：保留源与当前路径依赖，只应用指定调色节点的效果，其他调色不参与临时主图与监看。全局旁路跳过调色节点但不写入逐节点启用状态。两者互斥，和中间结果预览也互斥；在画布顶栏退出，换片、切组或关 Graph 清除。预览不改配方、历史、版本或导出；收窄与浅深色走查见[验证记录](validation.md)。

## 左栏、资料库与画布工具的入口分工

编辑左栏只保留滤镜、快照和历史。Graph 从右栏开关进入；本张模板在 Graph → 更多 → 高级图操作中应用或保存。资料库照片列表 → 底栏「更多」→「批量工作流」和「最近工作流批次与撤销」承接批量操作。至少选中两张已纳入资料库的照片：焦点照片为源（焦点不在选区时取首个选中项），其余是目标。预检明确显示源草稿和目标底稿；可改用已存工作流模板。批量不写源照片，完成或取消回到原选片。20/200 张模拟集收在预检的「原型评审样本」。

照片底部的 Mask 恢复图标和短标签；默认只显示拥有者、当前类型、组合操作、启停／叠加／反转及强度和羽化。类型板按智能选取、画笔与渐变、范围与引用分组；状态只显示相关选项，组件列表显示类型及运算，细化参数和诊断收进「细化／更多」。Remove 以四个带图标的按钮切修复、仿制、移除和 AI 填充，常驻画笔大小及羽化；只在有待生成标记时显示生成，失败后原位改为重试。草案局部撤销、取消及完成仍在底部；无修改的完成不写历史。Crop 行为和版式不变。

走查：[资料库](../../docs/ui/prototype/index.html#library/project/river) · [编辑与 Graph](../../docs/ui/prototype/index.html#edit/dag) · [紧凑工具条验证](validation.md#紧凑画布工具与照片列表入口)。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 明确编辑当前节点的能力 (Priority: P1)

摄影师在一张照片上选择基础调色、局部调色或其他节点，只看到该节点拥有的分类。单击 Graph 节点与使用右侧下拉选择同一对象；主图仍显示整条工作流最终结果。

**Why this priority**: 作用域不明确会造成串值、全图广播和错误采用，是其他图操作的前提。

**Independent Test**: 给同一张照片两个调色节点分别输入曝光 1.25 和 0.5，切换节点、分类及视图，核对各自数值和主图。

**Acceptance Scenarios**:

1. **Given** 两个不同身份的调色节点，**When** 修改其中一个的曝光并切换，**Then** 仅该节点和其下游结果改变，其他节点参数不变，返回后恢复原数值。
2. **Given** 选中 Corrector，**When** 浏览分类，**Then** 显示基础、色轮/分级、HDR 色轮、曲线、混色、色彩切片、色彩变形、细节、效果/LUT；不把 Crop、Mask、Remove、原片镜头适配、源 RAW 处理或生成任务放入调色分类。
3. **Given** 选中 Mixer、Group 或固定边界，**When** 检查右侧面板，**Then** 只显示对应混合、组管理或边界信息，不提供整套 Corrector 参数。
4. **Given** 多选节点或只选择连线，**When** 查看检查器，**Then** 数值编辑冻结，只开放针对明确集合的管理命令。
5. **Given** 尚未展开结构图的旧配方，**When** 进入编辑，**Then** 兼容显影对象明确标出“输入与基础调整”，保留原有字段；展开图后按明确的输入、调色与几何边界展示，不假称旧历史已经完成原生迁移。

### User Story 2 - 从照片工具条完成几何、覆盖与修饰 (Priority: P1)

摄影师在照片底部选择 Crop、Mask 或 Remove。原工具条动画展开为该工具的详细面板，主图上显示对应反馈；完成后提交一次并回到正常工具条，取消则恢复原配方。

**Why this priority**: 三类工具需要直接看照片和定位空间范围；不应藏在节点参数分类或要求关闭 Graph 才能使用。

**Independent Test**: 不操作任何图连线，分别做一次裁切、节点蒙版和修饰标记，独立验证完成、取消和撤销。

**Acceptance Scenarios**:

1. **Given** 当前照片已有调色，**When** 打开 Crop 并修改比例、拉直、方向或裁切范围，**Then** 预览属于照片几何阶段；完成只提交一次，取消不修改任一调色节点。
2. **Given** 当前或已进入组内的一个调色节点，**When** 打开 Mask，**Then** 面板常驻显示拥有者名称，添加、减去、相交、反转、强度和羽化只作用于此节点的覆盖，不向其他节点广播。
3. **Given** 当前选中 Mixer 或固定阶段，**When** 打开 Mask，**Then** 明确选择可用的调色拥有者；没有可用拥有者时说明原因，不默默写全图或旧节点。
4. **Given** 照片需去干扰，**When** 打开 Remove，**Then** 可选择 Heal、Clone、Remove 或 AI Inpaint，并在照片上标记；仿制先核对取样，生成类补区需要明确生成与审阅，失败可重试，未就绪不能完成。
5. **Given** 一个未完成工具草案，**When** 取消、换片或离开工作区，**Then** 草案不成为已发布配方；迟到回调不能写入新照片或其他节点。
6. **Given** 开启减少动态效果，**When** 展开或收回工具，**Then** 直接到达最终面板状态，功能和焦点顺序不依赖动画。

---

### User Story 3 - 在独立悬浮 Graph 中管理工作流 (Priority: P1)

摄影师打开非模态 Liquid Glass Graph 窗口。照片始终留在主视图中，图窗口可拖动、调整大小、收起、展开、复位位置和关闭。选择节点与调整参数实时联动右侧检查器和主图。

**Why this priority**: 降低主窗口内的布局复杂度，同时允许摄影师边看成片边操作图。

**Independent Test**: 打开、移动、缩放、收起并关闭 Graph，再重开；核对照片身份、主图倍率、图路径和参数。

**Acceptance Scenarios**:

1. **Given** 主图正在显示最终结果，**When** 打开 Graph，**Then** 不用 Graph 替换照片、不重排主窗口三栏、不重置照片倍率或平移。
2. **Given** Graph 与照片同时存在，**When** 选择节点并调整其参数，**Then** 检查器指向该节点，主图更新整图最终结果；选择本身不改预览输出或历史。
3. **Given** 窗口被移动或调整大小，**When** 收起、关闭或换片后返回，**Then** 窗口控制仍可触达，表现状态不进入像素历史，换片后图明确属于新照片。
4. **Given** 打开画布工具，**When** 编辑照片范围，**Then** Graph 暂时收起或只读以免遮挡；完成或取消后恢复原图路径、选择与视角。
5. **Given** 减少透明效果或平台不支持玻璃材质，**When** 显示窗口，**Then** 使用足够对比度的实色面板；操作不依赖背景透视。

### User Story 4 - 完成串行、并行、分层与组操作 (Priority: P1)

摄影师用常用命令建立正确工作流，再用高级连线处理特殊接法。不同 Mixer 类型和 Outside 命令有明确语义。

**Why this priority**: 第一轮单一“混合”不能完整表达参考实现的并行归并与有序图层混合。

**Independent Test**: 建立一条串行链和一条并行支路，转换或添加 Layer，调整输入，再将合法片段成组并解组。

**Acceptance Scenarios**:

1. **Given** 一个明确节点出边或所选连线，**When** 串行前/后插入或追加到图尾，**Then** 新中性节点不改变原结果；分叉不明确时保留原图并提示先选边。
2. **Given** 原链可作为基底，**When** 添加 Parallel 或 Layer 支路，**Then** 基底保留，初始新支路权重为零；类型、输入顺序和强度可在 Graph 与检查器核对。
3. **Given** Layer Mixer，**When** 添加输入、改变顺序或选择 normal、add、subtract、multiply、screen、overlay、soft-light、hard-light、lighten、darken、difference、color、luminosity，**Then** 按有序输入存储选择，不把模式套到所有调色节点。
4. **Given** 一个已有蒙版的调色节点，**When** 添加 Outside，**Then** 创建新的调色身份并反转复制的覆盖；没有可用覆盖时说明原因。Outside 是命令，不虚构另一种引擎节点。
5. **Given** 单入单出连续片段或完整菱形子图，**When** 成组、进入、退出、解组或保存模板，**Then** 外部连接与内部参数保留，不广播组内数值。
6. **Given** 一个无效连线草稿，**When** 制造自连、回路、缺输入或错误遮罩引用，**Then** 禁止应用，主图保持上一有效配方；取消恢复原图。

### User Story 5 - 复用工作流并可撤销地批量交付 (Priority: P2)

摄影师保存节点组或整图模板，选择当前或原片底稿，在所选照片上预检、创建版本，再进入既有导出工作台。

**Why this priority**: 图的复用与交付能带来实际工作流价值，但必须以正确作用域和有效单图为基础。

**Independent Test**: 组模板插入本张的指定边；在 20 张样本完成同步并撤销，在 200 张样本取消余项并检查后续修订冲突。

**Acceptance Scenarios**:

1. **Given** 组模板和明确插入位置，**When** 应用到当前草稿或当前组内，**Then** 不替换整图，内部身份与遮罩节点引用重新分配；未选边的分叉不提交。
2. **Given** 多张目标照片，**When** 预检批量，**Then** 列出冻结源、全部目标、底稿、选定字段、离线/缺素材原因及样例结果，确认前不提交。
3. **Given** 部分成功的批次，**When** 取消或重试，**Then** 已成功项保留，仅处理符合资格的余项；撤销前检查目标修订，冲突不覆盖后来编辑。
4. **Given** 正在查看中间节点输出，**When** 保存或导出，**Then** 提交已发布完整图的最终输出，与当前窗口、组路径和查看目标无关。
5. **Given** 源绑定的遮罩、补区或分析结果，**When** 跨片复用，**Then** 复用意图与参数，不把原照片像素或未经核验的素材当作新片已完成结果。

---

### User Story 6 - 用键盘和明确异常状态完成操作 (Priority: P2)

摄影师可以不用拖线完成图操作，辨认离线、未接入、忽略、缺素材和失败，取消后回到原上下文。

**Why this priority**: 非模态多表面工作区容易发生快捷键误路由和不可触达窗口。

**Independent Test**: 用 Tab、方向键和 Escape 操作画布工具、Graph 端口与连接选择器，再在窄窗及浅/深色外观复验。

**Acceptance Scenarios**:

1. **Given** 焦点在 Graph，**When** 使用全选、复制、粘贴、Delete 或适合全图，**Then** 只操作节点/图；焦点在照片或输入框时不误删节点。
2. **Given** 无效数值、未完成取样、缺素材或离线原件，**When** 尝试完成或提交，**Then** 显示具体原因并保持可取消/可修正状态，不静默改用其他来源或节点。
3. **Given** 当前节点与预览输出不同，**When** 继续选择其他节点，**Then** 明确保留“中间结果，不用于导出”标识，并可一键返回最终结果。

### User Story 7 - 看清工作流，保持暗房简洁 (Priority: P1)

摄影师打开 Graph 时先看到可读大小的节点，而不是一条缩小的流程线。常规参数留在检查器，本节点复位和临时监看从节点菜单发起；滤镜低频操作集中在左栏省略号菜单。主画布只在需要时显示贴合背景的小提示。

**Why this priority**: 读不清的默认 Graph 无法判断拓扑；重复按钮和全宽提示会占用照片与编辑空间。

**Independent Test**: 从 [摄影工作台](../../docs/ui/prototype/index.html) 选择河湾，进入编辑，打开右栏 Graph；添加支路，切换倍率按钮与「适合全图」；查看中间输出再恢复。在左栏滤镜省略号分别打开保存、导入和导出并取消。对照 [走查](validation.md#可读-graph-与暗房减项) 与 [实施计划](plan.md)。

**Acceptance Scenarios**:

1. **Given** 首次打开当前照片的 Graph，没有按新规则保存的视角，**When** 面板展开，**Then** 在画布居中取景、节点以 100% 显示；若整图超界，只调整超界轴到当前节点完整可见，允许两侧裁切。“适合全图”居中全图且可降到 100% 以下；百分比按钮恢复可读居中。
2. **Given** 已平移或手动缩放，**When** 关闭重开或改变面板尺寸，**Then** 可恢复手动视角；可读和全图模式按新画布尺寸重新取景。视角属于照片和组路径，不写照片历史，不改主图倍率及平移。
3. **Given** 当前是任一 Corrector 分类，**When** 浏览控件末尾，**Then** 没有重复的「复位本节点／查看此节点输出」；从 Graph 节点菜单仍能执行，复位纳入历史，查看不改配方。
4. **Given** 只有一个可操作工作流节点，固定输入／几何／输出不计，**When** 显示正常终稿，**Then** 不显示例行状态。多节点且 Graph 可见时可显示「最终结果」。主动查看中间节点或预览失败时不受单节点规则隐藏；保留「不用于导出／返回最终结果」或「重试预览」。状态用画布同色系、高对比小提示，不改变照片排版。
5. **Given** 在编辑左栏打开滤镜「…」，**When** 选择保存、导入或导出，**Then** 路由到各自已有流程；不存在独立「+」。导入只入预设库，不自动采用到本照片或节点，取消返回菜单触发处。

### Edge Cases

- 同名节点、组路径失效、删掉当前节点、粘贴后 ID 或 Mask 引用冲突。
- Mixer 多输入未接齐、普通节点多入边、共享支路删除、断开输出、图像或 Mask 依赖形成回路。
- 全图或多选时操作固定输入、几何、输出边界；不能删除或复制成另一个可随意改写的源。
- Mask 无拥有者、反向范围、空覆盖、全部关闭、引用自身或已删除节点；素材缺失与重建取消。
- Clone 没有取样位置，Remove/Inpaint 尚未生成、失败、取消或被严格纪实策略禁止。
- 工具展开期间切节点、换片、切版本、打开 Prompt、保存或导出；未完成数值与迟到回调。
- 关闭 Graph、主图缩放或窗口收窄不撤销已提交编辑；窗体控制不能落到屏幕外。
- 批次全离线、零目标、20/200 张、部分成功、重复重试和后来修订冲突。
- 减少动态/透明效果、玻璃不可用、浅/深色、键盘聚焦时检查器自动滚动。

## 本地模板与原生批量阶段走查

[批量阶段工作台](../../docs/ui/prototype/index.html?batchNativeReview=1) → 资料库多选至少两张 → 底栏「更多 → 批量工作流」。焦点是来源，其余最多 200 张是候选目标。可选择来源当前场景图或已存模板；此阶段同步仅支持曝光（保留其他字段），或使用整图/组选段。目标底稿可选当前场景图或原片；不兼容的旧调整不会自动迁移。预检显示所选字段、逐张底稿、准备/离线/不兼容和样例。确认前不写资料库；确认只建立独立候选，不自动采用、不改草稿。取消停止余项，重试只对同一冻结输入；后续修订冲突明确提示。撤销将仍满足修订的候选放弃，不删除原片或旧版本。结果可返回选片、重开最近批次或把明确成功的候选交给 032；不改选择或默选其他版本。模板从 Graph「更多」保存整图/组或插入本图，模板数据不带来源、监看和旧像素。[阶段证明](validation.md#原生模板与可恢复批量)。

## 场景图的数据与混合契约

真实场景图保存固定输入和最终输出，按显式图像槽和覆盖依赖验证。Corrector 的阶段顺序是：在线性 AP1 曝光后，按曝光档求曲线增益，再用节点强度 × 线性覆盖混合回输入；透明 alpha 不受调色影响。ROI 取景仍使用相同的全源坐标，不改变已画范围。Group 的权重混合其入口和内部最终结果；只在可以保留结果时允许解组。Outside 深复制并反转覆盖，不让之后编辑原节点覆盖影响副本。模板只迁移意图及重映射身份，不携带原片像素或捐赠者输出设置。

- **Parallel**：`base + Σ(weight × (branch − base))`，数学上不依赖输入次序。**Layer**：有序输入，按 `mix(current, blend(current, layer), weight)` 更新；新增权重 0 时都精确保留基底。入端有名且定位实际生产者，不能根据当前选择猜边。
- 13 种 Layer 均定义在同源直通 AP1 上、按原 alpha 重新预乘。Normal、加/减/乘、最亮/最暗/差值使用带符号扩展域；Color 使用支路色差但保留底图 AP1 亮度，Luminosity 反之。Screen、Overlay、Soft/Hard Light 在 `[0,1]` 的线性锚段用其标准分段公式，并加回两端带符号残差；`1` 是场景锚，不是 100 nits 或 HDR 峰值。此定义不声称与显示参考混合或第三方渲染逐像素相同。数值、alpha 或端口不符时拒绝输出，不静默转换为 SDR。
- 在目录中该路线与旧配方互斥；查看组路径、节点输出和旁路不是配方字段。它们不允许生成替代交付根。上述契约描述引擎目标，不指示尚未放行的原生海量操作已经开放。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 分离照片身份、当前节点、节点多选集合、组路径、预览输出、连接草稿、画布工具会话与 Graph 窗口表现状态。
- **FR-002**: 系统 MUST 根据当前节点能力提供分类；Corrector 的九类域及完整字段族以 [能力对照](node-capabilities.md) 为范围依据，不以标签相似认定源 RAW、模型或画布工具属于 Corrector。
- **FR-003**: 系统 MUST 在同一行提供合并节点列表与常用图动作的下拉、当前节点忽略按钮及 Graph 浮窗开关，不重复提供主图/Graph 双按钮；工具条和检查器标出名称、类型、范围及忽略/未接入/缺素材原因。Graph 指针和键盘选择 MUST 同步下拉、参数和忽略状态；多选不广播数值，单节点忽略禁用。
- **FR-004**: 参数命令 MUST 绑定发起时的照片、节点与修订；过期、无效或不同作用域的回调不能写入当前对象。
- **FR-005**: 系统 MUST 将 Crop、Mask、Remove 入口放在照片底部工具条，以展开/完成/取消状态完成工具事务；同时最多一个画布草案或 Prompt 会话。
- **FR-006**: Crop MUST 作用于照片几何阶段，提供比例、拉直、方向、翻转、裁切范围与复位，不成为每条调色支路的任意局部裁切。
- **FR-007**: Mask MUST 明确绑定 Corrector 拥有者，支持语义/人物部位、物体、画笔、线性/径向、颜色/亮度/饱和度/色相/深度范围和节点引用；组合支持添加、减去、相交、反转、强度与细化。
- **FR-008**: Mask 引用 MUST 作为独立依赖验证，禁止缺失引用、自引用和循环；复制/模板重新分配内部引用身份。
- **FR-009**: Remove MUST 属于有序照片修饰阶段，区别 Heal/Clone 的取样与 Remove/Inpaint 的补区候选；未就绪、失败或禁止内容替换时不能正式采用。
- **FR-010**: 完成画布草案 MUST 至多产生一笔有效历史，取消/无变化/失败不得新增像素历史；完成后回到正常工具条和原节点上下文。
- **FR-011**: Graph MUST 是与主图共存的非模态悬浮窗口；照片不能被替换，窗口开合不改变主图变换、来源或导出根。
- **FR-012**: Graph MUST 提供移动、调整大小、收起、展开、复位位置、关闭与重开；展开时桌面实际画布至少 480×240、最小外框 520×392，窄窗适配宽度并保留 240px 画布高度。连接草稿另留动作区，高度不足只显示可关闭标题条并说明原因；玻璃材质有不透明和减少动态替代。
- **FR-013**: 窗口操作、图布局、平移、缩放、选择及临时输出查看 MUST 不进入像素历史；拓扑、参数、忽略与有效工具采用进入照片历史。
- **FR-014**: 系统 MUST 区分 Corrector、Parallel、Layer 和 Group；固定输入/输出及照片阶段不冒充普通调色节点。
- **FR-015**: 串行插入 MUST 使用明确边；Parallel/Layer 的新输入初始不改变既有结果，输入顺序、权重与 Layer 模式保持独立且可检查。
- **FR-016**: 系统 MUST 提供串行前/后/末尾、Outside、复制并插入、参数粘贴、忽略/复位、删除、分组/解组、组路径、模板与等价键盘命令。
- **FR-017**: 删除 MUST 只做可确定的重接；删除 Mixer 明确保留基底及受影响支路，共享或不明确连接不得擅自删除。
- **FR-018**: 连接 MUST 支持端口操作和可访问选择器；无效草稿不能替换已发布图，取消恢复原拓扑。
- **FR-019**: 主图 MUST 默认显示完整最终结果，临时节点输出有明确标识和返回入口；选择节点不能偷偷切换交付输出。
- **FR-020**: 批量入口与最近结果 MUST 位于资料库选片菜单，不在编辑左栏或单张模板对话框。系统 MUST 冻结源与目标底稿、逐项预检并核对修订，不写入源照片；取消只停止未提交项；重试与撤销不得覆盖后来的版本。
- **FR-021**: 保存和导出 MUST 读取有效已发布图与不可变版本，沿用现有导出工作台；未完成工具/连接和必要素材缺失须说明阻塞原因。
- **FR-022**: 智能预设、Prompt、Agent、版本、保存和导出 MUST 明示照片级作用域，不成为节点参数分类或在未采用时改写节点。
- **FR-023**: 系统 MUST 保留键盘与逻辑焦点，Escape 按输入/局部选择、草案、临时预览与窗口层级处理；Graph 快捷键不能仅因窗口存在就接管主图或文本框。
- **FR-024**: 原型 MUST 使用授权样片与可辨认模拟状态，不对 RAW、精确混合、模型、缓存、性能、真实文件写入或原生可访问性作未核验结论。
- **FR-025**: Graph MUST 将首次默认和旧视角迁移设为可读居中（100%，节点标题基准 12 CSS px），长图优先保持当前节点可见。全图居中是显式操作；手动缩放和平移只改变当前照片及组路径的查看状态。
- **FR-026**: Corrector 检查器 MUST 不重复节点菜单的复位和中间监看命令；滤镜栏 MUST 仅从上下文菜单提供保存当前设置、导入 Lightroom／Camera Raw 预设与导出原生预设，并保留各自的作用域和权限。
- **FR-027**: 主画布 MUST 使用紧凑状态提示，底色与照片画布背景同系且文字对比至少 4.5:1。健康的单节点终稿不占位；中间预览和错误状态必须显式标记，不能被单节点或 Graph 关闭规则隐藏。

### Key Entities *(include if feature involves data)*

- **Photo Workflow**: 一张照片的一份配方，关联固定输入、照片修饰/几何、调色图与最终输出；与版本历史、任务队列不同。
- **Node**: 稳定身份、种类、名称、启停/强度、参数域及拥有的覆盖；Group 关联子图，Mixer 关联有序输入。
- **Edge / Dependency**: 明确图像来源和输入槽；Mask 引用是另外的依赖，均须校验。
- **Coverage**: 一个节点拥有的复合范围、组合运算、细化参数与素材状态；跨片复用保存意图而不是任意复制旧像素。
- **Canvas Tool Session**: 发起照片、拥有者/阶段、原配方、草案、修订、完成资格与返回上下文。
- **Graph Presentation**: 窗口位置/大小/收起状态、图视角、路径、选择和监看；不成为第二份权威配方。
- **Workflow Template / Batch**: 冻结模板、目标底稿、逐项前后版本、执行状态与撤销资格。
- **Version / Candidate**: 可审阅不可变结果；正式采用与生成/预览分离。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在覆盖九类参数、同名节点、切节点/换片、无效输入和迟到回调的 20 次作用域操作中，写入错误节点或照片为 0，多选广播为 0。
- **SC-002**: 每个画布工具各做 5 次完成与取消；有效完成每次至多一笔历史，取消/无变化新增历史为 0，其他节点参数变化为 0。
- **SC-003**: Graph 开合、移动、调整大小、收起、组进出、平移/缩放各做 5 次，照片身份、主图变换和输出根误改为 0；主图始终可见。
- **SC-004**: 在桌面、窄窗、浅/深色、减少动态/透明条件下，所有主要操作有可触达入口，文档横向溢出及窗体控制落屏外为 0。
- **SC-005**: 能力清单中的四种普通图对象、九类 Corrector 参数域、13 个 Layer 模式、Mask 范围族和四类修饰都有明确的操作或准入说明；不支持项静默遗漏为 0。
- **SC-006**: 自连、回路、缺输入、错误 Mask 依赖、未完成候选和修订冲突的验收集中，无效正式提交与覆盖后来编辑为 0。
- **SC-007**: 20 张样本完整批量与 200 张部分成功/取消/重试/冲突场景均可逐项解释；当前选择或中间监看导致错误导出版本为 0。
- **SC-008**: 原型评审记录与原生验收分别标明证据类型；把模拟当作模型、像素或性能签收的声明为 0。用户未确认前不推进本规格的原生默认行为。
- **SC-009**: 桌面／窄窗、浅／深色四种组合中，100% 可读模式的当前卡可见；全图模式中卡片外接框中心与视口中心相差不超过 1 CSS px，且全部实际卡片可见。切换与重开产生的额外照片历史为 0。
- **SC-010**: 九个 Corrector 分类重复命令为 0；滤镜栏常驻保存／导入／导出按钮为 0，三个菜单入口均可打开对应流程。单节点健康终稿提示为 0，中间预览及失败提示静默遗漏为 0。

## Assumptions

- 当前研发范围包含工作台原型、节点复核、原生实现、数据迁移测试和验收，不包括提交、发布或部署。原生默认行为须在对应验收项通过后开放。
- Liquid Glass 在 HTML 中表达为材质与非模态窗体交互，不冒称已经创建 macOS 原生窗口。
- 首次载入本版悬浮布局将旧版 Graph 视角迁至可读居中，不迁移旧的自动缩小比例；保留窗框与卡片位置。之后保留主动选择的图视角。该适配不改变主图倍率、平移、来源或配方。
- 当前 CSS/样片反馈只用于交互评审；参数子域、范围形状、候选和延迟可以模拟，准确算子、模型与资产恢复须独立验收。
- LightFlow 对照限于固定发布资产与明确工厂/注册表，REA 语义图为 partial，WASM 内部实现及运行时完整节点集合未知。
- 旧配方可先保留兼容显影语义；原生迁移必须另行证明历史、像素顺序、来源和跨片素材不变。
- Node 强度与 Mixer 权重、Mask 不透明度、照片修饰强度是不同字段；统一入口不改变数据所有权。
- [能力对照](node-capabilities.md) 保存参考依据；[验证记录](validation.md) 保存实际通过、失败、截图与未签收项，而非把本规格目标写成已完成事实。
