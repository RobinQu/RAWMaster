# 043 · 任务清单

2026-11-28 · **M0 外部对标继续采集，M1-01、M2 双端及原生传输已通过。** M2 的 6 MP、96 节点与 60 MP 图阶段性能门已通过。每项按对应原生路径和实际执行回执签收。[规格](spec.md) · [计划](plan.md) · [验收基线](validation.md)

## M0 · 回执修复与基线

- [x] **M0-01** 对齐 Swift/Rust 的 V1 `SceneExecution`，接受并持久化可选的 `photographicEngine`、`dagBackend`，回归旧回执及严格字段校验。
- [x] **M0-02** 用非中性摄影调整和有实际派发的 DAG 冻结场景，分别走 032 的 PQ AVIF 和 SDR JPEG，核对准备、发布、文件摘要与回执重开。Rust 目录测试验证旧票据与进程中断续跑。[原生回执](evidence/m0-032-photographic-receipt.json)
- [x] **M0-03** 记录来源校验/读取、FlashRaw 解码、mosaic 上传、摄影/模型、DAG 准备与执行、DRT/blit、编码/发布和等待，区分 CPU 墙钟、可取得的 GPU 时间和未观测量。
- [x] **M0-04** 60 MP 三路暖态各 30 次，已记录墙钟、计数、分项预算与进程/设备采样。6 MP 两个原生 Metal 执行器各完成 5 次预热与 30 次计量。038 FIT/监看与 036 1:1 已复跑。[M0 原生基线](validation.md#m0--回执修复与基线)
- [x] **M0-05** 定稿版本化 [ReceiptV2](plan.md#43-receiptv2)，区分执行器、图形 API、阶段峰值、计时来源和回退。定义旧 V1、恢复票据与 V2 写入切换条件。
- [x] **M0-06** 固定实拍和校准摘要、构建与运行库、设备/系统构建及测量区间，提供复现脚本。按原生分项判定编译、图执行、同步和编码的优先级。[M0 验收](validation.md#m0--回执修复与基线)
- [ ] **M0-07** 建立 LightFlow 和 Camera Raw 同机逐控件基线，保留预热、原始样本和像素见证。逐项以两者较快 p50 与 p95 加容差验收。LightFlow 六项可见响应通过。37 项精确读回按 6 次预热、30 次计量，默认实验组过 36 项，试用同态局部颗粒精确重放后过 37 项。首次定稿点算子上下文复用经交叉复测后启用，首次定稿的尾延迟仍超线。原寸预算窗在 RAW 基图池关闭时达到 LightFlow 容差，配置开池的组 p95 达标。60 MP JPEG 同设置复测通过 LightFlow 门槛，九档校准尚未进入等保真双门。Camera Raw 与三方 1:1 继续取证。[外部对标](validation.md#外部产品对标)

## M1 · 去重

- [x] **M1-01** 每个目标复用一个 renderer、冻结 SceneProgram 和输出阶段。输入、ROI、预算按瓦片绑定，旧运行库沿用逐瓦片 Rust。60 MP 三路核对 `rendererBuildCount`、`programCompileCount`、`libraryCompileCount`、成片与派发数。[实测回执](evidence/m1-60mp-frozen-tile-preparation.json)
- [ ] **M1-02** 验证同一冻结输入可共享逐瓦片显影和 DAG，再分目标 DRT。只在输出、编码和总预算通过的路由启用，复验单目标失败、取消和 032 恢复。
- [ ] **M1-03** 合并图与 DRT 的同队列工作，核对与解码和平台段的完成信号及资源生命期。瓦片 DRT 直写已启用，60 MP 每个目标少 35 次 blit，逐份成片及瓦片后取消重试已通过。[实机对照](evidence/m1-direct-drt-assembly.json)
- [ ] **M1-04** 按设备和规范化结构缓存编译产物，分别验证改参、跨照片、拓扑变更和源资源失效。
- [ ] **M1-05** 对照分块/整幅、单/双目标、60 MP 成片像素。签收暖态端到端 p95 ≤M0 同路由基线的 105%，同意图的瓦片和 DAG 派发计数至多等于基线，重复准备下降。

## M2 · 首条 WGSL 场景 DAG 与融合

- [ ] **M2-01** 定义 Rust `EngineGraph`、类型化端口、几何/ROI、执行计划和版本化算子注册表，绑定 CPU 参考、WGSL、能力、成本、像素与缓存契约。
- [x] **M2-02** 从 038 持久图接入首条 AP1 F32 曝光、EV 曲线、coverage 和有序 Layer，保留监看与最终根。摄影前缀和现用 ACES 2 以适配段运行。[原生验收](evidence/m2-native-metal-textures.json)
- [ ] **M2-03** 实现 WGSL 点段融合、已验证的裁剪、按设备限制切段及资源生存期复用。保持已签收的 F32 语义。结构化 pipeline 缓存与参数缓冲独立。
- [x] **M2-04** 首条链使用同源固定 AP1 夹具和冻结图，在 macOS wgpu/Metal 与 Linux wgpu/Vulkan 实体 GPU 验证了 F32、ROI、恒等和零回退。记录驱动、两端回执及独立复算结果。[双端证据](evidence/m2-ap1-cross-device-receipt.json)
- [x] **M2-05** 在 macOS 24/60 MP 原生 FIT、原寸窗口、顶层和组内监看与 032 冻结交付验证同设备纹理、同步和峰值。两种实拍尺寸均已呈现 AppKit drawable。032 覆盖 24 MP SDR 和 60 MP PQ、SDR。读取有效性标志前等待实际 wgpu 提交，验收拒绝、取消、超时清理和复用。[实机回执](evidence/m2-native-metal-textures.json) · [完成点复测](evidence/m2-native-metal-completion.json)
- [ ] **M2-06** 接入其余场景节点和有等价证据的 V3 点段，作 CPU/039 与融合/未融合像素对照。径向 coverage、交集、有序 Parallel、13 种 Layer blend、Add/Subtract/Adjust coverage 已在准入数值域内通过双端实机组件及 macOS 原生全幅与 ROI 对照。[六节点](evidence/m2-six-node-operators.json) · [混合与覆盖](evidence/m2-layer-blend-coverage.json)
- [x] **M2-07** 等待实际提交时，6 MP 暖态图通过 p95 门，96 节点通过吞吐和中间工作集门。60 MP 三路各累计 60 个暖样本，四个图阶段达到相对 M1 的 15% 提速门。24 MP FIT 与两种尺寸的组内监看达到 038 既有门槛。043 的节点监看继续向 p95 ≤20 ms 优化。[完成点复测](evidence/m2-native-metal-completion.json) · [有界等待验收](evidence/m2-native-metal-bounded-wait.json)
