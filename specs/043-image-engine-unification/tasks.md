# 043 · 任务清单

2026-11-28 · **M0 进行中。** 每项按对应原生路径和实际执行回执签收。[规格](spec.md) · [计划](plan.md) · [验收基线](validation.md)

## M0 · 回执修复与基线

- [x] **M0-01** 对齐 Swift/Rust 的 V1 `SceneExecution`，接受并持久化可选的 `photographicEngine`、`dagBackend`，回归旧回执及严格字段校验。
- [x] **M0-02** 用非中性摄影调整和有实际派发的 DAG 冻结场景，分别走 032 的 PQ AVIF 和 SDR JPEG，核对准备、发布、文件摘要与回执重开。Rust 目录测试验证旧票据与进程中断续跑。[原生回执](evidence/m0-032-photographic-receipt.json)
- [x] **M0-03** 记录来源校验/读取、FlashRaw 解码、mosaic 上传、摄影/模型、DAG 准备与执行、DRT/blit、编码/发布和等待，区分 CPU 墙钟、可取得的 GPU 时间和未观测量。
- [x] **M0-04** 60 MP 三路暖态各 30 次，已记录墙钟、计数、分项预算与进程/设备采样。6 MP 两个原生 Metal 执行器各完成 5 次预热与 30 次计量。038 FIT/监看与 036 1:1 已复跑。[M0 原生基线](validation.md#m0--回执修复与基线)
- [x] **M0-05** 定稿版本化 [ReceiptV2](plan.md#43-receiptv2)，区分执行器、图形 API、阶段峰值、计时来源和回退。定义旧 V1、恢复票据与 V2 写入切换条件。
- [x] **M0-06** 固定实拍和校准摘要、构建与运行库、设备/系统构建及测量区间，提供复现脚本。按原生分项判定编译、图执行、同步和编码的优先级。[M0 验收](validation.md#m0--回执修复与基线)
- [ ] **M0-07** 建立 LightFlow 和 Camera Raw 同机逐控件基线，保留预热、原始样本和像素见证。逐项以两者较快 p50 与 p95 加容差验收。分别跟踪可见响应、精确读回、1:1 与出片的覆盖。[外部对标](validation.md#外部产品对标)

## M1 · 去重

- [ ] **M1-01** 复用设备 pipeline、SceneProgram 和输出阶段，输入、ROI、预算按瓦片绑定。记录 `rendererBuildCount`、`programCompileCount`、`libraryCompileCount`。
- [ ] **M1-02** 验证同一冻结输入可共享逐瓦片显影和 DAG，再分目标 DRT。只在输出、编码和总预算通过的路由启用，复验单目标失败、取消和 032 恢复。
- [ ] **M1-03** 合并图、DRT、blit 的同队列工作，核对与解码和平台段的完成信号及资源生命期。
- [ ] **M1-04** 按设备和规范化结构缓存编译产物，分别验证改参、跨照片、拓扑变更和源资源失效。
- [ ] **M1-05** 对照分块/整幅、单/双目标、60 MP 成片像素。签收暖态端到端 p95 ≤M0 同路由基线的 105%，同意图的瓦片和 DAG 派发计数至多等于基线，重复准备下降。

## M2 · 首条 WGSL 场景 DAG 与融合

- [ ] **M2-01** 定义 Rust `EngineGraph`、类型化端口、几何/ROI、执行计划和版本化算子注册表，绑定 CPU 参考、WGSL、能力、成本、像素与缓存契约。
- [ ] **M2-02** 从 038 持久图接入首条 AP1 F32 曝光、EV 曲线、coverage 和有序 Layer，保留监看与最终根。摄影前缀和现用 ACES 2 以适配段运行。
- [ ] **M2-03** 实现 WGSL 点段融合、已验证的裁剪、按设备限制切段及资源生存期复用。保持已签收的 F32 语义。结构化 pipeline 缓存与参数缓冲独立。
- [ ] **M2-04** 首条链使用同源固定 AP1 夹具和冻结图，在 macOS wgpu/Metal 与 Linux wgpu/Vulkan 实体 GPU 验证 F32、ROI、恒等和零回退，留存设备/驱动和两端回执。[双端矩阵](validation.md#m2--首条-wgsl-场景-dag-与融合)
- [ ] **M2-05** 在 macOS 24/60 MP 原生预览、监看和 032 冻结交付验证同设备纹理、同步和峰值，计量全幅拷贝和等待。
- [ ] **M2-06** 接入其余场景节点、13 种 blend 和有等价证据的 V3 点段，作 CPU/039 与融合/未融合像素对照。
- [ ] **M2-07** 签收 6 MP 暖态图 p95 ≥1.3× 提速，固定 96 节点吞吐 ≥2×、峰值中间工作集 ≤50%，60 MP DAG p50 较 M1 至少降 15%，维持 038 既有门槛。

## M3 · 资源、模型与原寸窗口

- [ ] **M3-01** 按生存期复用 wgpu 纹理/缓冲池。工作集、缓存、coverage、模型、输出、编码分别准入并核算总峰值。
- [ ] **M3-02** 按每个模型的尺度和 halo 准入，验证全图坐标的分块 coverage、接缝、取消及预算失败。
- [ ] **M3-03** 采用设备/ROI/预算计划进行 1:1 取景，替换固定像素数门槛，在 5K/6K 对照整幅对应区域。
- [ ] **M3-04** 交互合并到一个在途帧和一个最新待处理帧，交付在预算内重叠阶段。覆盖换片、切组、迟到、命令和资源失败。
- [ ] **M3-05** 签收 60 MP 总峰值下降，5K/6K 1:1 可用，受支持模型运行成功，其余组合有具体能力或预算诊断。

## M4 · 空间与输出算子

- [ ] **M4-01** 使用 036 固定瓦片和默认 inline 的同窗口数据，评估 `texture → clarity` 的 WGSL halo、可分离滤波和 band 合成，留下窗口/整幅/导出证据。
- [ ] **M4-02** 先量化全图成本，再验证 `dehaze`/`brilliance` 的确定性分块统计与应用。
- [ ] **M4-03** 按注册表迁移九类调色、几何/蒙版/修饰，保持显式几何和独立 coverage，核对模型遮罩准入。
- [ ] **M4-04** 迁移版本化 ACES 2 输出、LUT/胶片/OCIO 的域、参考白、峰值，每个目标从母版成像一次。
- [ ] **M4-05** 验证 50 配方矩阵 p95 至多为 M0 同路由的三分之二，逐算子像素及产品路径通过。
- [ ] **M4-06** 旧 v1–v3 成片回放及 035 封存矩阵通过后启用可等价替换的路由。
