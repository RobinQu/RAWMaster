## 状态、操作与写入

| 当前状态 | 触发与用户看到的反馈 | 退出、恢复与副作用 |
| --- | --- | --- |
| 浏览目录或场景 | 左栏悬停／方向键可在有就绪渲染的条目上临时试看，主图标「临时预览」；右栏只移动卡片焦点，列明「全图」「需要选人」「已有范围」 | 左栏离开行、Escape、开始比较或另做编辑立即还原已采用画面。右栏点击／Return 打开卡。两处浏览均为零新历史、零模型调用、零上传 |
| 全局卡草稿 | 记录源照片、进入时的修订与配方；主图显示「未应用」。黑白卡先明示将转为黑白，可展开受影响字段；暮色卡暴露高光暖色与阴影冷色 | 按住原片看原始曝光与构图内的源图，松开恢复；「采用前／当前草稿」比较只隔离这次变更。有意义的变更才启用「应用到照片」。切换场景不隐式采用 |
| 等待选区 | 「准备选区」才启动本机分析，进度旁有「取消」与手工路径。已有确认范围可直接复用。多人时以编号、轮廓和候选列表一一对应，允许点画布、选列表或画笔 | 无目标显示「未找到人物／天空」，提供「画笔」「线性渐变」和「跳过」。未装模型时直接呈现手工入口。取消、换片、过期回调均不得将旧叠加显示在新片 |
| 修边 | 区域列表选中本层。画布外侧显示添加／减去／相交、叠加开关、100% 和边缘羽化；画圈或拖渐变时有光标半径、边界和模式文字。支持灰度 Matte，叠加可换色 | 「完成修边」带回同一草稿；「取消修边」回到进入修边前的范围。画笔笔划可逐步撤销。独立从蒙版打开时沿用蒙版本身的确认和历史 |
| 微调与采用 | 滑杆以进入卡的基线重算；连续手势合并。本张命名范围和参数同屏可见。按主操作后列出已采用的卡名及目标 | 同一照片修订一次有效采用只写一条，双击去重。撤销返回进入卡前的图和范围；已采用状态可「查看历史」或「保存为我的预设」。草稿期间历史、库文件和导出仍指向已采用态 |
| 切换、放弃与过期 | 未手修的临时预览可离开。对已有手修笔划或改过参数的右栏草稿，换卡／换片时在原面板给「继续编辑」「放弃草稿」；主动按取消可直接退回。进入裁切／版本变化先撤下过期预览 | 迟到结果必须匹配照片和修订。修订被其他操作改变时显示「照片已更新」，可回当前版重新预览。原图对照结束回到此前状态；未采用草稿退出不产生历史 |

## 三类拍摄任务

**人像。** 「逆光人物提亮」详情先显示「选择人物」，双人时用人物 1／2 与画布对应；发丝串到邻人则转「减去」。确认范围后调曝光，先比较背景，再在 100% 检查发丝，最后采用。「明暗黑白人像」详情在全局显示「橙色明度（含衣物）」和「明暗反差」。用户可在上画面比较皮肤与服装；进入黑白状态有文字标记。

**风光。** 「天空压高光」的首批首屏有「使用已有范围」「线性渐变」「画笔」。从上往下拖渐变、在山脊减去、关闭彩色叠加后再判断云层，避免叠加颜色干扰修图。无天空可跳过；原始通道已剪切时明确可恢复的边界。「暮色冷暖」两个控件分别回中性，可保留阴影原色。低饱和雾景和单色源给使用条件；用户可直接查看原图。R2 的自动天空准备在同一位置增加选项。

**纪实。** 进入时显示当前照片的严格纪实状态及可查看的调整来源。单张「中性还原」区分曝光、是否校白；「克制黑白」把暗部人物与标语设为检查点。已含克隆或生成处理的来源提供干净祖先供用户另起版本；取消则回到原片当前版本。切换人像卡、左栏已存外观、批处理都执行同一照片策略。

**同组参考配平。** 至少选两张；组内参考张单独固定、只读，其余是待处理目标。先选参考和字段，再看「参考／当前目标」并排图。清单显示文件名、ΔEV、白平衡是否参与和状态。默认勾选可采用目标，换光、来源不满足或估算失败的行未勾选并说明原因。摄影师可逐张调整、主动接受例外或跳过；主按钮始终带实际选中数。部分完成时显示成功／待复核／失败／未处理数；停止不撤销已采用张，恢复只处理仍选中且修订匹配的未完成张。重新选参考使旧估算失效，重复采用不重复写入。普通撤销只作用于当前照片，通过逐张回执可定位已处理照片。

| 新增能力与批次 | 摄影师看到什么 | 谁决定写入 |
| --- | --- | --- |
| 031 · 保存、迁移与强度 | 「保存为我的预设」弹出字段清单，名称、组、源绑定项分开；强度只在支持连续混合的条目显示。XMP／ZIP／本机目录由「导入」发起，预检后分行列出可用、缺少基底和仅部分映射的字段。打开 Profiles 时单列相机与色彩条件 | 保存只更新预设库；缺依赖项可保留浏览。部分采用需确认字段清单；未支持的强度保留独立控件或解释原因，换片终止上次强度会话 |
| 027 / R2 · 自动类别 | 在原有手工入口附近增加「自动天空」「水面」等已验证项。显示准备中、已就绪、无目标和模型未安装。多人或部位用编号／名称选择，允许转画笔和灰度查看 | 用户确认结果后才复用冻结范围；切换模型版本时保留既有版本成片。自动选择不改变已有手工笔划 |
| 030 / R3 · 局部清理候选 | 独立的「生成候选」展示实际发送裁片、保护区、本机或北京 Seedream 5.5、等待与费用状态。结果在原图／100%／差异／接缝之间切换；画布仍可看其他照片。请求结果未知时保留回执 | 采用与拒绝独立；手动选云端才发送，拒绝和过期结果不写入。严格纪实不提供改写动作。该状态不占首批场景卡位。[候选技术与恢复](plan.md) |

## 视觉、响应式与辅助功能

- **暗房与版式。** 以现有 macOS 编辑工作区为边界。左右栏各 304 pt，外边距 12 pt，右侧工具轨 48 pt，余下约 255 pt 提供竖排内容。Fit 的左右避让沿用 328 pt，顶部 24 pt、底部 88 pt。画布受用户背景偏好控制，保留原有比较与缩放工具。右栏卡片整行进入，细节单列，主操作固定底边；组照对照占中央画布。原生目录不生成滤镜预览小图；批量目标和已有胶片带可显示照片本身。[工作区尺寸](../../Sources/RAWMaster/EditingWorkspace.swift) · [右侧导航](../../Sources/RAWMaster/PhotosDevelopmentInspector.swift)
- **基准与最小窗口。** 以 1440×900 pt 审主要界面，再在已有最小 1100×720 pt 审同一操作。窄窗将组照的左右并排换成同一视口「参考／目标」选择器，保留同步缩放；右侧步骤可纵向滚动，目标与采用按钮不挤出可视区域。大号字体改成标题与数值上下两行，长文件名中间省略、读屏报全名。[应用窗口下限](../../Sources/RAWMaster/RAWMasterApp.swift)
- **字级与控件。** 延续 macOS 系统字体。面板标题 15 pt semibold，正文和动作 13 pt，辅助状态 12 pt；数值用等宽数字。间距采用 4/8/12/16 pt。工具轨命中区至少 32×32 pt，细滑杆另有可编辑数值和键盘步进。常规工具保持低对比中性色，焦点环、选中行和唯一主动作使用现有 AppPalette.accent。异常用 warning、图标与明确文案。蒙版叠加色属于选区显示，允许改色或切换黑白 Matte，细边加轮廓。[主题语义色](../../Sources/RAWMaster/Appearance.swift)
- **焦点与按键。** Tab 依次访问入口、场景、卡列表、选区／参数与底部操作组，Shift-Tab 反向；左右／上下键只在当前控件内选择。左栏目录 Return 采用当前可直接应用的行；语义范围未就绪时进入准备。右栏列表 Return 打开详情，在「应用到照片」按钮获焦后 Return 才提交。Space 切换获焦的批量选择框；不占用画布外的全局快捷键。Escape 先关闭菜单或结束当前修边、再退出卡片。Command-Z 沿当前编辑上下文撤销。保留「按住原片」并提供可切换的比较按钮。
- **读屏与视觉状态。** VoiceOver 报「场景、卡名、范围、应用状态」，批量行报「文件、参考／目标、曝光差、复核原因、是否勾选」。有序号的目标选择器和画布对应；可用键盘调整渐变位置／方向、选择已有目标；画笔精细手修仍可用指针。焦点环与选中、表示颜色的圆点都配文字或图形。提高对比度时保留边框，减少动态效果时直接换帧；推理进度按阶段播报，不逐帧抢焦点。设计目标为常规文字 4.5:1、交互边界 3:1，需用真实主题和叠加样片验证。

## UX-D0 · 开发启动前的走查

产品与设计准备可切换状态的原型，6 名摄影师交叉顺序完成下列脚本，覆盖经常使用蒙版与不熟悉蒙版的参与者。主持人只宣读摄影目标。QA 记录首次落点、求助、误采用、能否说清范围／参考及失败后的返回位置。下述均为验收目标，当前尚无参与者成绩。

| 任务与样本 | 通过条件 | 回到的研发任务 |
| --- | --- | --- |
| A · 左栏比较两个自己的风格，只保存曲线，撤销一次；在缺少基底的导入项上找原因 | 至少 5/6 独立辨别临时与采用状态，保存字段可复述。悬停／保存造成误采用 0 次 | 031 T004–T008、T010 |
| B · 逆光双人照只提亮发言人，再看单人黑白卡对衣服的影响 | 至少 5/6 完成选人、修边、采用与撤销；能指出背景保护与黑白的全局范围。出现采用错人即记录阻塞并重测 | 030 T005–T007、T017、T021 |
| C · 无模型山湖片压天空，换一张暮色片只减弱冷影；再给一张无天或已剪切的反例 | 至少 5/6 找到渐变／画笔，检查山脊并完成采用和撤销；能分别找到高光与阴影控件，知道何时跳过 | 030 T006、T017、T022 |
| D · 12 张组照锁定参考，仅调曝光，排除换灯张；给一张已含克隆的祖先，检查严格模式 | 至少 5/6 正确指出参考和待复核原因。误改参考、默认采用换光、把内容改写带入严格输出均为 0 | 030 T008/T009/T017 |
| E · 键盘、VoiceOver、增加对比度、减少动态效果、最小窗；取消分析后立即换片 | 编辑器与 QA 逐条走焦点与朗读脚本，主操作、返回和状态均可达。另列真实系统的待验证项；旧片叠加落在新图上为阻塞 | 027 接入、030 T006/T017、031 T008 |

每个场景记录完成人数及分母。误写照片、误选对象／参考、无法离开或无法手工完成风光，须修改设计并重走相应脚本。产品与设计确认文案和路径，成像确认字段与保护范围，QA 附问题单和复测结果，再由负责人决定启动对应新增功能编码。真实窗口的响应时间、蒙版节时、盲评可交付率与全尺寸导出另按 [030 成功标准](spec.md)和 [031 验证](../031-preset-browser/validation.md)计量。
