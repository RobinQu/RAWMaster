# 按摄影场景选择智能预设

2026-11-22 · 产品规划 · 编辑工作区右侧「智能预设」

摄影师先选拍摄场景，再选想解决的问题。例如，一张台上双人合影可以选「人像 → 逆光人物提亮」，直接在画布点中发言人，减去误选的投影幕，拖动曝光看效果。一组活动照可以选「纪实 → 同组参考配平」，指定参考张，在胶片带逐张复核换光照片。两个流程都从现有照片和明确的操作开始。

本目录只计自适应调整，五个场景共规划 **15 张卡**。去干扰、人物换光和风光参考／风格包有独立的出图、保护与审阅流程，见[生成式产品规格](generative-editing.md)。首批 R1 交付人像 2 张、风光 2 张、纪实 3 张，其中「同组参考配平」服务组照交付。七张均能离线操作。R2 新增水面、肤色和两张街拍卡，并为首批天空卡增加经验证的自动范围。另四张按皮肤纹理、山脊、直线和窗框样片专项试用。首批发布以七张卡逐项通过验收，且三类场景均可完成实际编辑为条件。[社区作品、插件与选型依据](../../docs/research/photography-community-preset-styles.md) · [编码前交互与视觉设计](ux-design.md) · [精修需求与指标](spec.md) · [联合研发顺序](../../docs/planning/24-mask-preset-retouch-roadmap.md)

## 摄影师在卡片里做什么

1. **选场景和目的。** 场景由用户指定。已有直方图、已选人物、已就绪的天空蒙版、选中照片数可调整同一场景内的顺序。例如选中多张时优先显示「同组参考配平」。建议旁说明依据，用户仍可浏览该场景的全部已开放卡。
2. **看范围与保护项。** 卡片显示将修改的字段、目标及检查位置。全局卡可直接临时预览。局部卡有现成范围就显示叠加，首次分析由「准备选区」发起。主体合并时允许手工划出一个人，无天空或无人时显示跳过，模型缺失时可选画笔或渐变。浏览和悬停的推理与上传数为 0。
3. **比较并微调。** 提供前后对照、100% 检查和与当前操作相关的滑杆。局部卡可直接进入原蒙版面板加减和羽化。拖动强度从当前应用前基线重算，沿用已确认范围。几何卡用网格和裁切预览。
4. **明确采用。** 一个有变更的单张预设写一条可展开、可撤销的历史。批量卡列出每张预计调整、待复核和跳过原因，用户勾选后逐张写入。生成候选另有「生成候选」和「应用到照片」两个动作。用户保存为左栏「我的预设」时，只复用允许跨片的参数、目标和保护规则。[预设保存与强度契约](../031-preset-browser/spec.md)

## 七张首批卡怎样起调

下表给出设计评审用的起调配方；数值按普通彩色 RAW 的中性基线示例，正式默认值由留出的实拍样本与手动作业对拍决定。所有连续偏移相对进入预设前的版本计算并限制在字段合法域，未列字段沿用。已调过的黑白或分级设置要展示拟改字段及前后值。局部高光、阴影和黑白混色的原生域为 −1…1，色轮饱和度为 0…100。[局部字段范围](../../Sources/RAWMasterCore/DevelopmentMaskModelsV3.swift) · [黑白混色](../../Sources/RAWMasterCore/DevelopmentAdjustmentsV3.swift) · [分级色轮](../../Sources/RAWMasterCore/DevelopmentColorModels.swift)

| 卡／研究样本 | 起调与给用户的控制 | 试用时必须看见的差异 |
| --- | --- | --- |
| 逆光人物提亮 · P1 | 选人或画笔确认后，局部曝光 +0.35 EV、阴影 +0.10；可分别调整曝光、阴影与边缘。保留背景光和现有白平衡 | 人脸能读出，发丝外侧和舞台屏幕维持原样；刻意剪影可跳过 |
| 明暗黑白人像 · P2 | 显式进入黑白，使用原生黑白混色。在中性基线试橙通道 +0.06、全局对比 +0.08；中性颗粒为 0。面板写明「橙色明度（含衣物）」和「明暗反差」 | 眼神和脸的体积可读，橙衣不过亮；不同肤色、妆容与单色源分别检查。单色源仅开放有实际作用的明暗控制 |
| 天空压高光 · L1 | 由已确认范围或渐变＋画笔起步，范围内高光 −0.22、曝光沿用。拖动高光、修边和检查剪切独立操作 | 明亮云层可恢复部分有变化，未选前景在相同渲染节点差值为 0；山脊无亮边、全剪切时不承诺找回细节 |
| 暮色冷暖 · L2 | 中性基线以高光 42°、饱和度 8 和阴影 218°、饱和度 4 试看。用户分别调「高光暖色」「阴影冷色」。已有分级需列出拟替换的两轮，保留中间调、白平衡和几何 | 岩石的受光面、背光面与水中倒影仍来自同一束光。阴天、雪地或单色源可看原片、退出；单色源解释色调卡的适用条件 |
| 中性还原 · D1 | 用已有亮度统计估计全局曝光偏移，初稿限 ±0.35 EV；初始沿用拍摄者当前白平衡。显式勾选才建议白平衡，彩色灯下可只改亮度 | 现场灯、肤色和标语可辨。无法估计时可手调或跳过；已合适的照片允许零改动、零历史 |
| 克制黑白 · D2 | 显式选黑白，初版中性混色、无新增颗粒，曲线保留黑白端点；开放「暗部层次」控制。中性基线试阴影 +0.05 | 对照旁观者及暗处标牌。严格纪实时检查祖先、列出变更，摄影师确认仍能读到事件信息 |
| 同组参考配平 · D1／交付工作流 | 固定参考张，默认只勾曝光。按张估计并列出 ΔEV；可选白平衡。初版将绝对曝光建议大于 0.70 EV 或灯光组不一致的照片列为「待复核」，默认未选。参考张锁定 | 试用需校准该阈值。12 张含换光、缺参考或失败的序列，可排除、逐张改、停止后续办；逐张结果带调整与撤销记录 |

选黑白是明示的离散动作，卡内用「明暗反差」或「暗部层次」调连续量；对照基线或取消能完整恢复彩色。连续强度为 0 时显示进入前的整张基线，100 为确认过的当前卡效果；只对已通过强度验证的字段开放总强度，其余保留独立控件。摄影师自行调过的原有颗粒不随卡片清零。

## 五个场景的预设目录

### 人像

| 卡片与阶段 | 拍摄问题与范围 | 输出、保护与验收 |
| --- | --- | --- |
| **逆光人物提亮** · R1 | 窗前或舞台人物偏暗。选择整个人，或用画笔把范围缩到脸部。多人时由用户点选或手工分开 | 命名蒙版＋曝光、阴影。显示背景叠加，100% 检查发丝、衣领、投影幕。整片可离线回放。人物轮廓无法分清时停在修边 |
| **明暗黑白人像** · R1 | 用黑白突出眼神与受光面。全图转换，用户对照眼窝和肤色原有的明度层次 | 黑白混色＋中间调反差，默认不加颗粒。可调皮肤常见色域的明度，显示红橙衣物也会受影响。比较深浅肤色、近黑头发和眼中高光；不会自动磨皮或裁切 |
| **肤色去偏** · R2 分项试用 | 混合光让脸侧泛绿或偏洋红。用户圈定受影响皮肤，可扣除眼唇、腮红、发色与衣物 | 局部色温、色调与必要的饱和度，保留现场光和当事人肤色。用户可用手工范围，自动部位须在不同肤色、妆容和侧脸 RAW 上另行通过 |
| **自然肤质** · 专项试用 | 大面积皮肤出现不均匀过渡，用户希望保留毛孔。选择皮肤并明确排除痣、眉毛和嘴唇 | 比较原生轻纹理调整与低频处理，分开控制强度。100% 核对毛孔、妆面和明暗体积。只有范围和盲评都通过的实现才能出现在卡片里 |

### 风光

| 卡片与阶段 | 拍摄问题与范围 | 输出、保护与验收 |
| --- | --- | --- |
| **天空压高光** · R1 | 平衡亮天与较暗的地景。复用本张已确认选区，或拖出线性渐变、用画笔减去山脊树梢；支持后可另选自动天空 | 一层命名范围和局部高光。检查剪切指示、山脊光晕及蒙版外前景；没有天空可跳过，完全剪切的云没有可恢复纹理。未安装模型可走完整手工路径 |
| **暮色冷暖** · R1 | 夕阳照亮山脊或建筑，背光面已有较冷色调。用户决定是否加强已有冷暖关系 | 暖高光与低饱和冷阴影分开控制，两轮明度默认沿用原值。复核雪、雾、镜面倒影与中性建筑；原片缺少此类光色时可原样退出 |
| **水面明暗** · R2 优先 | 湖面或江面比岸边过亮或过暗。单独选择水面，按需要排除船体、岸线和倒影 | 一层局部曝光或高光。保留水纹与反射关系，100% 检查船沿、碎浪。与天空卡共用一次场景分析，分别采用 |
| **远山层次** · 条件试用 | 雾气使远景层次弱，用户希望维持近景。先用手工渐变或已确认的远山范围 | 局部去雾和对比，检查山脊及近景反差。小样本的自动山体平均 IoU 为 0.343，自动选择留待独立 RAW 验证。天空和水面分别为 0.822 和 0.956。[标注结果](mask-validation.md) |

### 纪实

| 卡片与阶段 | 拍摄问题与范围 | 输出、保护与验收 |
| --- | --- | --- |
| **中性还原** · R1 | 单张现场照欠曝或色偏。首稿只提议曝光，沿用当前白平衡；需要校色时可显式勾选白平衡 | 展开拟修改的字段，保留标语、人员与物体。严格纪实检查当前版本的编辑来源。已经含克隆或生成像素时，提示选择干净祖先 |
| **克制黑白** · R1 | 复杂颜色抢走事件主体的注意力。用户主动选择黑白交付 | 固定版本的黑白混色与明暗曲线，可调整对比。检查暗部人物与标牌可读性，保留内容处理记录。左栏保存的同款外观仍走同一配方 |
| **同组参考配平** · R1 | 活动连拍在同一灯位上曝光漂移。用户选一张已修参考片、目标照片及「曝光／白平衡」 | 逐图给出参数差量和对照。换光张进入待复核列表，用户可排除或单独调整。首版可只用全局参数。12 张实拍序列的主动操作时长目标较手工缩短 ≥30% |

### 街拍／旅行

| 卡片与阶段 | 拍摄问题与范围 | 输出、保护与验收 |
| --- | --- | --- |
| **人物融入环境** · R2 复用 | 巷口或街边人物处在阴影里，摄影师仍希望读出街景。选人后对照周围店面、招牌或同行者 | 复用「逆光人物提亮」的局部工具，以环境作比较，单独调人物阴影。换人或换照片需重选，检查路人及招牌边缘 |
| **夜街灯牌控光** · R2 复用 | 夜景霓虹和招牌刺眼，暗部仍要有层次。用户圈定亮部，可与亮度范围相交 | 调局部高光，保留字形、灯光颜色及夜景氛围。无可恢复细节时提示，无法划清灯牌与人脸时转画笔。严格纪实策略随照片继承 |

### 建筑／城市

| 卡片与阶段 | 拍摄问题与范围 | 输出、保护与验收 |
| --- | --- | --- |
| **立面垂直校正** · 专项试用 | 仰拍导致竖线汇聚。用户借网格选参照，调垂直透视和水平，再确认裁切 | 复用原生几何参数。保留机位与透视意图，明示导出将裁掉的边缘。核对窗框直线、层数、文字形状和最终有效像素。复杂曲面可手调或跳过 |
| **窗景与室内光比** · 专项试用 | 室内与窗外曝光差大。分别选窗区和暗部，减去窗棂、玻璃反射和标志 | 两层可独立开关的高光与阴影，保留材料纹理和窗外原有细节。检查窗框光晕、文字以及裁切后遮罩的对齐，按卡单项开放。[现有几何模型](../../Sources/RAWMasterCore/DevelopmentGeometryV3.swift) |

风光与旅行还可从画布进入同一个 **「纹理区局部清理」**。它是 R3 的独立候选操作。用户涂目标、确认保护区、查看实际裁片、本地或北京 Seedream 5.5 的执行信息，再审阅接缝。严格纪实下该动作不可用。任一生成失败，前面已采用的原生调光仍可继续编辑。[生成留出集与恢复条件](spec.md)
