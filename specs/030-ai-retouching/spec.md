# 030 · 摄影场景中的 AI 精修

2026-11-22 · 产品规格草案 · 桌面端编辑工作区

首批让三类摄影师都能交片。拍人时，可修正逆光人物的选区，或用黑白明暗突出眼神。拍风光时，可压住云层高光、保留地景，或分别控制黄昏的暖光和冷影。交付纪实照片时，可沿用现场光、选择黑白，或用参考张逐张平衡一组照片，并能解释做过哪些处理。跨场景去干扰、人物换光与风光重绘各自进入候选验证。是否开放一项操作，取决于它能否比现有画笔或滑杆更快地交付同等可信的照片。

右侧「智能预设」在现有画布上选场景、目标、强度并确认采用。左侧继续管理可复用外观、快照与历史。首批七张卡须同时覆盖人像、风光和纪实；自动天空选区另行验收，首批已有离线手工范围。编码前先走查交互、视觉稿和异常路径。[社区风格样本](../../docs/research/photography-community-preset-styles.md) · [体验设计与评审稿](ux-design.md) · [按场景的预设目录](scene-presets.md) · [规划背景](../../docs/planning/23-scene-guided-ai-retouching.md) · [实施方案](plan.md) · [双模型对照](research.md) · [交付任务](tasks.md)

七张首发卡归入「自适应调整」。重建被遮挡背景、改变人物光向、匹配风光场景做风格迁移分别作为独立研发项。修复面板与场景卡共享选区及采用机制。具体光型、五种风光匹配、交互样稿和技术放行条件见[生成式精修增订](generative-editing.md)。

## 用户故事与独立验收

| 故事与优先级 | 用户操作与价值 | 可独立验收的结果 |
| --- | --- | --- |
| US1 · P1，选中并修好一个人 | 在逆光合影里选择「逆光人物提亮」，确认左侧人物范围，叠加查看发丝和衣领，减去误选的邻人再调曝光。节省描边及来回试调的时间 | 给定两人合照，当用户确认左侧人物的手工或实例蒙版时，画布标明该人，右侧出现命名蒙版与曝光量。缩放、修改、撤销、重开和断网导出都能复现选区。无法区分两人时停在选人步骤 |
| US2 · P1，交付同一事件的一组照片 | 选一张已修好的照片作参考，对目标序列执行「同组参考配平」，勾选曝光或白平衡。摄影师只需处理换光等例外照片 | 给定 12 张混合光线照片，预览逐张给出调整、保护项和跳过原因。逐张估算曝光和白平衡。没有人物的照片也可参与全局配平。接受的照片各有可撤销记录，严格纪实的内容增删调用数为 0 |
| US3 · P1，控制风景的亮天与暮色 | 在山湖 RAW 上拖出渐变、减去山脊后压天空高光；另一张日落片上分别调整高光暖色与阴影冷色 | 在断网且未安装可选模型的设备上完成两张风光卡。只采用天空时地景不随局部算子改变；暮色卡展开两个色轮。无天空可跳过，完全剪切有提示。R2 水面卡可独立叠加 |
| US4 · P2，审阅局部清理候选 | 在旅行照片上涂抹水面标牌，明确保护邻船与乘客。选择生成后可继续编辑其他照片 | 用户用原图、补区、接缝与 100% 视图分别检查，明确采用才写入。调羽化复用已归档候选。迟到或失败的请求独立留在该照片的任务记录 |
| US5 · P1，找到合适的预设 | 摄影师首批从人像、风光、纪实选场景，查看卡片、作用范围和保护项。街拍／旅行、建筑／城市随卡片验证加入更多场景 | 首发可直接完成两种人像、两种风光、两种纪实单片处理和一种纪实组照交付。当前照片不适用的卡说明原因并提供适合的手工工具。收藏或已有选区可复用，切换场景不自动分析、上传或采用 |
| US6 · P1，逐项去干扰 | 用户在旅行照保住同伴，标记路人及其影子稍后处理；处理一组传感器污点时逐张重新检测 | 未执行的标记重开后可见，误选可排除，确认补区后再采用。严格纪实拒绝替换。透射／反射与人像瑕疵按专项放行 |
| US7 · P1 验证，给同一人换光 | 选择右侧柔光箱或从另一张照片取光，比较脸颊、鼻影、发丝和制服文字 | 两种输入独立验收。错光或串入参考人物时能放弃，源片和已归档候选仍可重开 |
| US8 · P1 验证，按风景选风格 | 用户从五类场景一键选风格并确认允许重绘的区域，例如湖泊保船、夜景保招牌 | 同源比较原生调色与参考／已装风格包。能指明光效来源，缺少同底模风格包时说明原因，明确采用才产生创作版本的操作 |

## 本期自适应预设

| 场景 | 摄影师要解决的问题 | 交付次序 |
| --- | --- | --- |
| 人像 | 逆光脸部或人物太暗，混合光造成肤色偏差，肤质需要保留毛孔 | R1 做「逆光人物提亮」「明暗黑白人像」。R2 试用「肤色去偏」，「自然肤质」另验皮肤范围与纹理 |
| 风光 | 压住天空高光、保留暮色冷暖，或单独控制水面及远景 | R1 做「天空压高光」「暮色冷暖」。R2 扩展可选自动天空与「水面明暗」。「远山层次」先用手工范围试用 |
| 纪实 | 还原现场光线，交付黑白，或使同一灯位的组照一致 | R1 提供「中性还原」「克制黑白」「同组参考配平」，逐张展示参数和换光例外 |
| 街拍／旅行 | 同时读出阴影里的人和街景，夜间保留灯牌文字 | R2 复用人物蒙版和亮度范围，开放「人物融入环境」「夜街灯牌控光」 |
| 建筑／城市 | 确认立面垂直和裁切，平衡窗内外光比 | 「立面垂直校正」「窗景与室内光比」按直线、文字与原尺寸导出逐卡试用 |

每张卡的使用条件、产出、保护与失败路径见[场景预设产品规划](scene-presets.md)。风光／旅行的「纹理区局部清理」单独走候选审阅和 R3 的任务留出集。固定胶片外观由左栏预设库管理。[031 预设浏览与保存](../031-preset-browser/spec.md)

## 功能要求

- **FR-01 范围。** 「蒙版」增加主体、背景、点/框选物体、人物及部位、风景类别入口。按设备已准备的能力呈现。选区可叠加查看、添加、减去、相交、反相和羽化。弱结果可用画笔或现有渐变修正，保留已有调整。
- **FR-02 预览。** 卡片显示目标、范围、保护项和可编辑参数。全局参数可直接试看，局部卡由用户明确准备选区。已有快照可直接叠加，强度拖动复用范围。无目标、多人、模型缺失分别提供跳过、点选、手工修边的处理。
- **FR-03 纪实。** 严格模式允许批准的曝光、白平衡、色调、裁切等操作。工具层拒绝传统内容替换、生成移除、增景和生成重打光。带内容改写的来源须从干净祖先另起，处理记录能追溯到来源。
- **FR-04 批量。** 保存语义目标、参数意图和参考张。跨照片只传这些信息，逐张计算范围。单张失败、跳过、取消或迟到均可辨认，允许从已完成的位置继续。
- **FR-05 生成。** 本地 ComfyUI/MLX 为可选运行时。新云端方案只路由北京方舟 Seedream 5.5。每项生成列出提供方、发送范围、图像尺寸、候选张数、费用状态和等待方式。切到云端须用户选择，云端故障可继续原生编辑。
- **FR-06 采用与回放。** 悬停、选区分析、候选预览只更新当前视图。点击「应用到照片」后校验修订并记录采用。强度、羽化、撤销、断网重开和导出复用已确认资产。
- **FR-07 检查画面。** 原图对照、100% 局部、差异和 Matte 四种检查共用画布。人像定位到脸与发丝，清理定位到补区边缘。输出保留原尺寸、方向和色彩配置，生成内容有处理记录。
- **FR-08 选卡。** 场景由用户指定，卡片依据当前可用工具、已准备范围和用户选择显示适用原因。建议使用已取得的信息。照片继承严格纪实策略，切换分类、保存或重新套用预设仍检查来源。
- **FR-09 编码前体验验收。** 首批入口、三场景七卡、现有蒙版和左栏预设复用同一份[交互与视觉契约](ux-design.md)。D0 记录原型任务、误操作、修订和决定后再开始对应的新增功能开发。

- **FR-10 去干扰。** 029 的标记／候选列表共用于各场景，含逐项目标、保留对象与排序。有序补丁仅写入有效 Matte。玻璃反光保留双层预览，永久面部标记默认保留。批量区别按图检测与同机位标记复用。
- **FR-11 重打光。** 灯位有画面坐标、方向、光质和保护对象。参考图有「只取用光」用途，明确提交前逐一显示真实发送内容。硬保护、光向或身份不合格时可丢弃；已归档候选调强度不重新生成。
- **FR-12 风光迁移。** 五类场景各有匹配依据、允许改变的图域与结构保护。每个已装风格包按底模、adapter 哈希、许可和图生图结果分项登记。参考图、普通调色、已加载权重各显示真实来源。

## 成功标准

以下是产品试用目标。先冻结样本与评分表，再由摄影师与现有手动工作流做交叉顺序对照。每项单独统计，记录失败、弃用、重试和人工修正时间。

| 编号 | 验收办法与目标 |
| --- | --- |
| SC-01 · 蒙版节时 | 至少 6 名摄影师，每人做相同难度的人像与风光任务。取从选图到首次接受并在 100% 检查后的用时中位数，较手动流程缩短 ≥30%，盲审可交付率不下降 |
| SC-02 · 交互 | 支持机型上取连续 30 次操作。缓存命中后的点选反馈 p95 ≤250 ms，已确认蒙版的受支持滑杆暖呈现 p95 ≤50 ms。首次分析另计且可取消，记录冷启动、内存与失败 |
| SC-03 · 同组交付 | 每位测试者处理 12 张混合光序列。相比逐张手工，主动操作时长中位数缩短 ≥30%。严格模式中被拦截的内容改写进入执行器 0 次，跨照片复用上一张位图 0 次 |
| SC-04 · 局部清理 | 每个拟开放的任务族先冻结 ≥30 张留出图，两位独立审阅者同时接受第一张候选的比例 ≥80%。未通过者计入分母。任一硬保护区像素变化、身份或文字失真即拒收。两张对照样本不能用于宣布达标 |
| SC-05 · 可恢复 | 对接受、放弃、修边、取消、崩溃恢复、断网重开与导出分别验收。源文件哈希、同版本同色彩条件下的回放像素和写入次数可核对，断网回放的模型调用为 0 |
| SC-07 · 直接用卡 | 与 SC-01/03 使用同一批 6 名摄影师。分别给定逆光双人片、带树梢的山湖片、12 张换光活动照，每个场景至少 5/6 人无需提示找到对应卡、说清范围或参考张并完成预览、采用与撤销。风光须覆盖未安装可选模型的路径。另用彩色近景人像、黄昏风景和彩色／黑白现场片验证其余卡片及保护项。浏览造成的新增历史、推理、上传均为 0。记录找不到卡或看错影响范围的步骤 |
| SC-08 · 去干扰 | 逐族 ≥30 张，双人共同接受首选 ≥80%；污点另报告精确率、召回与负例误替换。检测、标记、请求、写入分别计数 |
| SC-09 · 人像光照 | 每种模式 ≥30 对，光向盲判正确 ≥90%，两人均接受自然度及身份的首候选 ≥80%。任一硬保护变化或参考人物串入即拒收 |
| SC-10 · 风光迁移 | 每个风格 ≥30 张，目标风格辨识及双人共同接受首候选分别 ≥80%；地标、文字、船客等硬保护零变化。与同底模无 LoRA、原生配方和仅参考路线对照 |

生产准入仍须蒙版快照、原尺寸有序补丁、真实 RAW 的代理／全尺寸对拍与逐族盲审。实测已覆盖本机灯位／双图、北京 5.5 的单图与双图输入，以及两套 SDXL 社区风格权重。失败样例作为后续验收固定回归图。[验证结论](research.md) · [新增 PoC 与样片](../../docs/research/generative-retouching-field-review.md) · [Spec Kit 规格结构](https://github.com/github/spec-kit/blob/main/templates/spec-template.md)
