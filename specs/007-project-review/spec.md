# 007 · 项目搜索、独立审阅与批量标签

2026-10-24 首版范围为 N01/N02/N03。2026-11-22 修订增加资料库阶段二的结构化查询与保存规则，阶段三增加智能检索。首版实测记录与新增目标分别验收。[检索与检查器规格](../033-library-lifecycle/search.md)

## US1 组合搜索与筛选（P0）

- SR01：项目与本地全部已纳入素材提供文件名搜索，组合拍摄日期、已有机型、星级、标签、入选决定、文件可用性及已审状态。不同条件AND，标签组内可选全部/任一。空条件等同当前完整范围。
- SR02：范围可明确选择当前项目或单库全部项目；待初筛和历史未纳入资产不进入结果、词表或动作。初筛/历史继续使用原专用筛选，不受项目条件暗中影响。
- SR03：文件名/标签匹配的大小写和字符规范化规则明确。日期使用当前界面显示语义、起始日含当天/结束日含当天；缺时间或机型的文件不能假装匹配相应条件，不改EXIF或推断未知时区。
- SR04：每个文件独立满足整套条件，不允许RAW满足一条件、JPEG满足另一条件却拼出假匹配。只一成员匹配时显示该文件且默认操作不扩大到隐藏伴随；操作范围与结果张数/文件数可见。
- SR05：切换或清除条件后协调焦点/选择，空结果保留检索和清除入口。批量动作不作用于已被条件移出的不可见资产。决定/标签更新导致结果变化时也维持明确范围。交付默认按当前匹配结果冻结allowedAssetIDs，格式选择也不暗中补入结果外伴随，清单/组上下文遵守同一范围。
- SR06：保存按拍摄顺序/自然文件顺序或明确排序的浏览状态；人工组保持原成员顺序，不被查询重排关系。查询只读，不触发RAW解码或改变初筛/精筛决定。

## 搜索体验修订（用户追加，2026-10-24）

- SR07：搜索是浏览内的即时只读操作，不用sheet收集条件后“应用”。正常无条件浏览不常驻额外搜索/计数区域；工具栏入口或⌘F按需打开搜索，条件修改即时更新既有结果缓存及有效选择。
- SR08 · 高级条件以非模态控件逐步展开，可边看图片边调整。结构化过滤沿用文件、处置和日期时区语义。后续的画面匹配在同一可见范围内按相关度排序。
- SR09：收起编辑器不清空查询；有条件时始终可辨认当前范围、有效筛选与匹配计数，每项可独立移除并可清除全部。恢复项目查询不抢键盘焦点，空结果保留编辑/清除入口。
- SR10：搜索/筛选控件（包括日期、选择器、标签和菜单）获得交互焦点时，P/X/U/0–5及方向键不误操作照片；返回图片浏览后原快捷键继续可用。⌘F在初筛/历史或业务sheet中不激活项目搜索，Esc不默默清除条件。
- SR11：日期/星级等组合字段必须原子校验；暂态非法输入只在当前编辑区反馈，不将非法query持久化或静默当作无结果。项目切换、清除或单条件移除后，旧局部草稿不得回写新查询。
- SR12 · 沿用原生浅／深色及图片优先的层级，小窗给画布保留空间，筛选与信息检查器避免同时挤占两列。
- SR13 · 阶段二支持文件夹、集合、项目及资料库范围。可选择文本、属性和元数据列，组合镜头、曝光参数、格式、版权、GPS 有无、编辑／导出及人工清晰度等条件，查看分项计数。保存为智能集合时持久化规则，原值或成员变化后重新求值。
- SR14 · 阶段三允许把人物、半径／多边形围栏与画面文字描述叠加于结构化条件。显示本地索引覆盖和未完成状态。业务操作冻结可见且有资格的结果文件，不从伴随或识别推断额外操作对象。

## US2 每项目独立审阅（P0）

- RV01：每文件的“已审/未审”独立于访问、初筛、入选和评分。浏览、放大、选择本身不标已审；明确精筛决定/评分可记已审，并可显式标回未审。取消评分/撤销决定不自动声称没有看过。旧评分不推断旧已审。
- RV02：进度显示整个项目的已审/总数，另列当前结果；分母包含全部已纳入素材（含仅序列用途并另列），RAW+JPEG两成员都已审才算整次拍摄已审，部分已审可核对。新增成员默认未审，解除/新增配对按当前成员重算，不丢旧记录。
- RV03：每项目保存检索条件、排序、浏览模式、当前照片及有效比较选择；切项目先保存旧状态，再加载目标状态。正常退出/重启可恢复，不能由全局最后位置覆盖另一个项目。
- RV04：恢复只引用本项目已纳入且仍符合条件的文件；文件/标签/关联/范围变化时剔除过期选择，无结果时显示空状态，不越界定位。初筛、历史和全库浏览不覆写项目状态。
- RV05：已审标记立即持久化，浏览布局可短延迟保存但切换/正常退出必须刷新；持久状态仅含布局/查询，不写回旧评分、标签、组或文件位置。

## US3 批量标签（P0）

- TG01：支持追加、移除、替换，默认追加；多选展示共有标签与混合标签，不拿焦点照片的标签覆盖所有文件。
- TG02：追加/移除保留每文件独有的其他标签；替换明确展示会移除哪些标签和实际文件数量。无变化的追加/移除不产生标签写入或可撤销空操作，可保留内部幂等收据；空替换是明确清空并需要有效预览。
- TG03：提供已有标签列表/补全建议，限定已纳入范围。输入去首尾空白并规范Unicode，去重和大小写规则固定，不在后台自动重写旧标签。
- TG04：预览绑定真实动作文件集合与当前标签版本；提交原子、幂等，标签或成员变更时拒绝过期结果。更改检索/选择不能用旧预览默默作用到另一批。
- TG05：标签操作有持久记录，可在重启后恢复；连续LIFO恢复不误拒，有后续未撤销写入时报告冲突，不能用值相同绕过ABA。与既有选择/组/粗筛撤销按实际动作顺序协调。项目历史只展示完整目标集合均属于该范围的命令，全库可展示跨项目命令并明确项目/完整文件数；恢复不能裁剪成部分命令或跨到未说明项目。
- TG06：收起组合遵守已确认整对操作，展开单文件按明确范围；查询只匹配一个成员时不扩大到不匹配伴随。初筛和只读历史不提供精筛标签写入。

## 共用约束

- GC01：继续本地离线、原片只读、schema升级前一致备份。既有项目/资产/评分/标签/组/操作与006纳入关系不变。旧数据新增审阅字段默认未知/未审，不伪造历史。
- GC02 · 基础过滤离线使用 SQLite 索引和稳定分页，筛选与计数不扫描原始 RAW 目录。前三阶段按[现有照片基线](../033-library-lifecycle/validation.md)测库级搜索、首屏和持续导入期间的时延。长期[目录容量验收](../033-library-lifecycle/spec.md#100-tb-目录验收)另行安排。文本、空间和语义索引各自维护进度。
- GC03：Core新类型/Store扩展与App文件由本对话维护；Sequence*、Probe、fixtures、005质量门及metadata-sequences工作树由原对话维护，不互相覆盖。
- GC04 · 2026-10 的开发与安装记录适用于当时交付的 N01–03。资料库后续的智能集合、存储及备份按[生命周期阶段](../033-library-lifecycle/spec.md)验收。

## 必测场景

1. 多个项目混有评分、标签、缺元数据、离线及未纳入素材时，组合条件与预先清单一致；清除条件回到全范围。
2. RAW/JPEG标签/评分不同，只一个文件满足全部条件时，只出现与操作匹配成员；恢复全条件后选择可见。
3. A项目有query/焦点/比较状态、B有另一套，切换及重启分别恢复；全部项目和初筛不覆盖A/B。
4. 旧五星照片仍可未审；仅浏览不增进度，明确已审/未审或精筛动作正确更新，组合部分状态正确。
5. 两文件标签[a,b]/[b,c]批量加d后分别保留a/c；移除b只移b，替换预览明确后再覆盖；无内容写回原片。
6. 标签并发变更/成员或选择过期、幂等重试、跨重启撤销和ABA不静默覆盖；筛选导致结果改变后无隐藏批量动作。
7. 旧schema4升级备份、业务关系与原片不变；普通回归/发布构建/既有性能门/隔离窗口结果分别记录。
8. 保存“四星以上”的智能集合，改星后核对成员增减。叠加人物、围栏和画面描述时，硬条件、语义排序、缺坐标及尚未索引的照片可分别核对。
