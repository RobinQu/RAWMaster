# 007 · 交互（2026-10-24 搜索体验修订）

## 图片优先的浏览与搜索

默认浏览没有额外搜索条。工具栏放大镜或⌘F展开约280–320pt搜索框，替换装饰性的品牌内容，直接搜索文件名；放大镜在展开时高亮，再次点击收起且保留条件，重复⌘F重聚焦并选中。输入立即更新图片，搜索框不挤进预览上方。Esc退出编辑、收起输入，保留查询。

现有浏览标题保持两行（约66–72pt）：第一行项目名、排序和视图切换，第二行范围/匹配数、项目已审进度和可移除条件chips。没有条件就没有chips。条件多时水平滚动，单颗截断但Help显示完整内容；清除全部在滚动区外固定可达。收起控件后仍知道当前被筛选，空结果也能清除。照片信息/部分组合/仅序列计数用Help保留，避免重复的大块计数。

工具栏筛选图标打开280–320pt右侧面板，与照片信息复用同一槽位；界面不同时增加两列，打开/关闭不改原信息栏显隐偏好。点照片信息按钮显式切回信息；关闭筛选恢复原状态。

面板顶栏“筛选”、清除、关闭，下方滚动分区：精筛（决定、已审、星级）、标签与机型、拍摄日期、可用性。当前项目/全部项目范围直接切换，组内固定本组。控件更改立即生效，没有全局“应用/取消”。标签Enter/逗号完成一个token或点击现有标签即加入条件，标签关系保留全部/任一。日期保留原时区和含起止日语义，非法日期/星级组合只在当前编辑区提示并保留最后有效结果。

过滤器绑定model有效query，只有正在编辑的局部无效文本可暂存；切项目、清除或删除chip后重同步，不能把旧项目草稿带入新项目。恢复条件不抢焦点。搜索/筛选控件拥有交互焦点时，P/X/U/0–5及方向键不操作照片；点击图片返回原快捷键。⌘F在初筛、历史和业务sheet不可用；Esc在相应控件内只收起、不暗中清空。

## 既有审阅、标签与双格式

项目显示整个项目的已审/总数；当前结果和范围分开计数。浏览不标已审；显式决定/评分或已审动作记录，可标回未审；撤销决定保留审阅记录。每项目独立恢复query、排序、焦点/模式与有效compare2–4成员。

批量标签默认追加，提供移除/明确替换；显示拍摄/文件范围、共有与混合标签。替换/批量写入继续核对逐文件预览，历史恢复继续检查后续写入冲突。本次只读搜索去确认步骤，不取消写入前有效预览。

双格式保持整对/单成员显式范围，只有匹配成员能进入动作和交付；搜索不改变原文件关系或组顺序。初筛/历史不使用项目搜索，保留其专用工作流。
