色调 Auto、单字段 Auto 和 Auto WB 每次从两套预设起始配方之一重新分析同一张原片，检查实际源身份、请求标识、响应绑定和已更改的目标字段。点取工具交替使用归一化源坐标 (0.29, 0.31) 和 (0.73, 0.69)。HSL 和点曲线定向工具包含首次非零拖动及具体通道值验证。RAW 白平衡的原生色温、色调估计经过 Core Image 的 CIRAWFilter。

RGB 与 Lab 通过原版检查器的指针事件更新读数并产生所选格式的文本。九点采样包含替换第一条持久化标记，以及映射和读取全部九个位置。参数曲线依据当前显示像素的亮度确定区域，返回经过验证的更新曲线。以上各项在数值就绪时结束。

矢量示波器取样 128 × 85，正常饱和度与增强饱和度两份分布分别有 369 和 501 个非空色度箱。SwiftUI Canvas 绘制真实分布后，在靠近中心的色度轨迹上校准出 96 个 RGB 差异明显的像素。肤色虚线使用同一份分布，在经过校准的虚线上读取 40 个开关亮度差至少 24 级的像素。两项都要求至少 90% 的像素符合其目标状态，本次的 12 帧均达到 100%。[完整像素、坐标和两态判据](rawmaster-inspection.json) · [肤色线整幅摘要的早期记录](history/rawmaster-skin-whole-raster.json)

临时剪切预览固定照片曝光设置，只改变高光区的 Option 状态，计时包含返回 2400 × 1600 预览并观察 96 × 64 RGB 像素。第八个点色样每次从相同的七个现有取样出发，换一个位置并验证前七个保留。引擎可复用没有色彩调整的工作图，时间从 363.446 ms 降至 6.115 ms，十二个色样结果逐次一致。启用色相、饱和度、明度或偏差调整的配方仍按其真实图像内容建立缓存键。[优化前的构建、像素与采样时间](history/rawmaster-point-swatches-before.json) · [优化后的逐次结果](rawmaster-inspection.json)

复跑使用真实原片、固定的 FlashRaw 动态库和新的输出文件。可用 RAWMASTER_INSPECTION_ONLY 选择逗号分隔的操作 ID。

```sh
RAWMASTER_FLASHRAW_LIBRARY="$PWD/output/tools/flashraw-target/release/libflashraw_capi.dylib" \
RAWMASTER_INSPECTION_RAW="$PWD/output/performance/acr-benchmark.ARW" \
RAWMASTER_INSPECTION_REPORT="$PWD/output/performance/inspection-new.json" \
RAWMASTER_INSPECTION_SAMPLES=10 swift test -c release --filter PhotoInspectionPerformanceTests
```

## 复用分析工作图后的逐项对照

服务为符合预算的 FlashRaw 工作图保留一个经过验证的源纹理及其 Core Image 上下文。色调统计按取样配方和区域最多保留四组。当前全套实测重建工作图 5 次、复用 77 次，标量缓存命中 17 次，结束时保留 3 组统计和约 459 MiB 源纹理。色调自动命令还移除了多余的 CIRAWFilter 降噪默认值读取。当前版本与优化前对照了 108 个输出摘要，均逐项一致。

## 编辑器操作与镜头配置

这些操作在同一张已打开的 RAW 上运行。直方图、曲线和参数行使用生产检查器的命令与真实编辑会话。曲线方向键通过原生 AppKit 控件的 keyDown 入口发送。计时始于控件参数输入，止于编辑会话发布新值。镜头默认值还从隔离偏好库重新打开验证。初始设置放在每个计时窗口之前，后续整幅照片渲染单独计量。镜头匹配读取的是原片 EXIF 中的 Sony FE 14mm F1.8 GM。
