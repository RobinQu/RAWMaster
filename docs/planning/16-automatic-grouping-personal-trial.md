# 新导入自动分组：个人试用与标注复核

2026-10-24。用户已明确要求将自动导入相关功能合入 main，以便人工测试。本次接入指完整导入后自动生成序列组；不增加目录监视。此前“质量达标前不接入自动导入”的限制，在这次个人试用范围内由该指令替代，开发数据结果不因此变为独立质量验收通过。

## 试用范围

- 原地接入与复制导入完成后，在后台读取实际导入文件的元数据和预览，运行元数据事件关联与暂停桥接规则。
- RAW/JPEG 事件关联采用明确的待检查假设；不宣称已经验证同一曝光或任意同型号相机的设备身份。
- 自动组名标记“待复核”，保留全部文件、全部成员和选片决定。现有人工组、锁定或历史编辑涉及的成员优先保护。
- 一次成功的自动分组对应一个组历史命令，可通过已有组历史恢复功能撤销。撤销后普通恢复导入不会把该批自动组重新建回。
- 分组失败或取消不会回滚已经完成的导入；缺少读取组件、文件过期或证据不足会明确保留为失败/未分组，不能变成静默丢片。
- 旧资料库批量重分组、排除废片、预训练视觉模型、服务端与同步均不属于本次增量。

## 实现与证据边界

Core 负责完整会话快照、跨连接租约、现有 metadata 表中的运行记录、严格结果校验、原子组命令和撤销。Imaging 通过可选导入后回调提供真实素材的分析，不直接写选片或分组数据。数据库结构版本不为本次增量改变。

运行时提取器与历史审计提取器使用不同来源标识。固定 ExifTool 13.59 随试用包提供；JSONQ 传递解析器解码后的字符串，保留 `001` 等子秒文本，不能称为 RAW 标签原始字节。资料库私钥用于设备候选信息的 HMAC；不把明文设备序列号写入报告或日志。

运行时检查点预算不等于可强制中断原生ImageIO读取，留存缓冲预算也不等于整个应用的RSS硬上限。

现有 Sony 开发数据的009实验为 TP800 / FP0 / FN0 / TN7、5/5整组；负样本有限，所有样本均已用于开发。DJI 严格事件关联仍存在漏分，假设关联改善不等于配对精度已获证实；0188归属继续未知。旧标签、v1/v2数据、历史基线和质量门保留。

## 人工标注报告

`docs/diagnostics/sequence-codex-visual-review-v1.json` 保存实际 Codex 图像查看记录和对应 JPEG 哈希。复核区分可见的画面事实、算法归因与需要用户判断的拍摄意图。相同主体/场景不能证明一次连续快门，也不能否定人工定义的片段边界。

`python3 scripts/build-sequence-review-report.py` 生成离线 HTML、最长边384的JPEG缩图、完整文件与历史错误清单。标注工具只编辑独立草稿，支持同组/分开/未知、组范围/类型、撤销及JSON导入导出；每份修订绑定索引、旧标签与全部文件哈希，不自动改写 truth 或生成新基线。使用方式见 `docs/diagnostics/sequence-review-report.md`。

本次实际生成含6案例/1265文件/396个不重复历史错误边界，包括另行指定的005首次冻结实验。22条实际视觉复核记录覆盖全部17个Sony CV误切位置、旧误并边、连拍与间隔启动、DJI始中末表示对，并浏览全部188个DNG派生JPEG总览。不能据此宣称所有JPG表示均逐对核验，也不能保证用户意图标注客观无误。
