# 空间 CV 分组实验

2026-10-24。用户已授权按混合路线实施第一个空间 CV 实验，先在现有 JPEG 集上比较质量和代价，再决定是否实验预训练视觉模型。质量未达标前，不接入自动导入、资料库堆叠或历史数据写入。

## 问题与对照

保留 dev4 为默认算法，对照两个显式开启的实验变体：仅复核连拍暂停桥接；在此基础上增加受限的局部直方图断组救援。相机来源、时间、曝光、长期锚点和间隔拍摄节奏约束继续保留。实验不能借助文件名、样本编号或人工标签决定分组。

第一版使用纯 CPU 的确定性位移与分块结构证据，不下载模型，不引入新的图像库。复用已转正的最长 160 像素预览，另取最长 96 像素、保持比例的亮度及梯度平面。先估计有界整体平移，再检查固定九块局部窗口的对应关系、残差、纹理和可靠性。比较方向固定为时间序列左帧到右帧；不以位置相同、背景相似或单块匹配成功证明属于同一逻辑组。

局部救援只考虑原普通门和既有救援均拒绝、且仅直方图超过局部门的候选；原亮度、指纹、时间和锚点限制保留。暂停桥接先通过旧门，再要求左右各三帧的九对比较中至少六对提供空间支持，且每行、每列都有支持。证据不足不算支持。间隔拍摄的共享桥接调用必须明确绕过本实验复核，防止无意改写间隔规则。

固定配方、版本、参数及源码身份必须在读取实验样本前封存。任何看过结果后的修改都属于下一轮开发，不能回写这一轮结果。

首轮冻结的空间配方：

| 项目 | 固定值 / 处理 |
| --- | --- |
| 输入 | 最长 96 像素、保持比例，不放大小预览；有效区域以外不参与计算 |
| 整体位移 | 24 像素平面上 ±3 格粗搜，再在 96 像素平面 ±3 像素细搜；最终不超过 ±12 像素 |
| 全局可靠性 | 有效重叠至少 75%，亮度标准差至少 0.025，相关值至少 0.80，与不同粗匹配峰的差至少 0.03 |
| 局部窗口 | 固定 3×3 中心的完整 16×16 有效窗口，在整体位移附近 ±3 像素搜索 |
| 局部支持 | 相关值至少 0.80、梯度余弦至少 0.70、残差长度不超过 3 像素 |
| 整对支持 | 至少 6 个有纹理窗口，其中至少 80% 支持，分布在至少 3 个非轴线象限；中心有纹理时也必须支持 |
| 工作上限 | 每对最多 539 个搜索候选，串行处理；特征、缓存、临时空间纳入额外内存预算 |

无纹理、重复图案导致的多峰歧义、过小有效区域和比例不兼容分别报告证据不足。每个局部窗口都使用完整有效面积，不能以少量重叠像素得到高相关值后宣称支持。此版仅估计平移，不拟合任意旋转、缩放或单应关系。

## 测量与回归

六组共 1,265 个 JPEG、原顺序、来源声明、人工真值和 dev4 行为基线保持不变。先运行三变体的 18 项质量测量，结果封存后才加载标签，复用已有严格计量器。基线漂移或文件完整性错误属于执行失败；实验质量变差仍保留并报告。

每组比较已知正负相邻边的 TP/FN/FP/TN、完整组恢复、类型覆盖、额外与遗漏成员，并列出所有变化边。未标上下文不能当作负例；DJI 的 0188 继续未知，DNG/JPG 仍按独立资产处理。本实验不顺便实现拍摄事件配对。

性能使用同一 release 二进制、串行新进程和交替的基线/候选顺序。每组、每候选各一轮预热和十轮测量，保留原始样本。分别记录读取、额外特征提取、空间匹配、检测、整组分析及进程峰值内存；子阶段耗时不能重复相加。新进程不等于冷文件缓存，十轮的 P95 仅描述样本尾部。另验证取消、内存预算、有限 trace 和默认路径不变。

这些是已经见过的开发样本，不能声称是独立留出。自动导入仍需满足原质量门及新的独立样本验证；合成测试通过或误并下降都不能单独关闭质量门。

## 如何决定下一步

先判断空间证据是否同时改善误并和漏分，是否破坏原先完整恢复的组，以及资源代价是否可接受。若只是拒绝大量合法暂停，或无法区分主体变化与相机移动，报告这一反证。再以明确的困难样本、独立验证划分、模型许可和本机资源预算评估预训练局部视觉特征；本轮不自动进入模型接入。

算法背景和候选路线见[算法分析](12-sequence-grouping-algorithms.md)。均值中心化相关与运动假设参考 OpenCV 的[模板匹配定义](https://docs.opencv.org/4.x/df/dfb/group__imgproc__object.html)和[光流说明](https://docs.opencv.org/4.x/d4/dee/tutorial_optical_flow.html)；本实现不依赖 OpenCV，也不把这些假设当作分组正确性证明。

## 首轮结果：质量不达标，保留实验分支

全部 18 个质量单元及 264 个性能单元完成，另有 1 个配置描述启动单元。固定源码、参数和二进制没有在采样中修改；默认结果保持原 golden。三个变体各自的有 trace 质量结果、无 trace 预热和重复测量结果 SHA256 均一致。

| 开发样本 | dev4 TP / FP / FN | 仅桥接复核 TP / FP / FN | 混合 TP / FP / FN | 完整组变化 |
| --- | --- | --- | --- | --- |
| 123 张连拍 | 122 / 0 / 0 | 119 / 0 / 3 | 119 / 0 / 3 | 完整 → 被切开 |
| 38 输入、14 张正组 | 13 / 0 / 0 | 13 / 0 / 0 | 13 / 0 / 0 | 保持完整 |
| 72 输入、48 张正组 | 47 / 0 / 0 | 43 / 0 / 4 | 43 / 0 / 4 | 完整 → 被切开 |
| 439 输入、427 张间隔组 | 426 / 0 / 0 | 426 / 0 / 0 | 426 / 0 / 0 | 保持完整 |
| 217 输入、193 张连拍组 | 191 / 1 / 1 | 182 / 0 / 10 | 182 / 0 / 10 | 仍不完整 |
| DJI 376 文件、374 个正组成员 | 0 / 0 / 373 | 0 / 0 / 373 | 0 / 0 / 373 | 未恢复，0188 仍未知 |

TP/FN 按已标正组内相邻边计算，FP 只按明确标注的相邻负边计算。七条已知负边中，误并从 1 降到 0；五个 Sony 完整真值组的内部误切从 1 增至 17，精确恢复从 4/5 降至 2/5。两种 CV 方案的最终分组完全相同，局部救援没有带来恢复。总 FN 为 374 → 390，其中 DJI 的 373 条始终未恢复。未知或未标上下文没有被当作负例。

193 张组内 DSC00411/DSC00412 的实验匹配得到全局相关 0.9801、位移 (1, −2)、有效重叠 95.87%，但局部只支持 5/9，中心窗口不支持、仅覆盖两个象限，因此救援仍被拒绝。已知负边 DSC00560/DSC00561 的桥接九对均未得到支持，确实被挡住。该实验能拒绝一处错误，却也拒绝了已标注合法组内的边；具体运动或构图原因尚未独立验证，不能据此放宽门限后声称成功。

有 trace 的空间比较中，仅桥接方案有 162 对：7 对支持、30 对全局相关不足、41 对峰值歧义、84 对中心窗口不支持；混合方案另多 1 对中心窗口不支持。这里是实际触发比较的计数，不是全部相邻帧的准确率。间隔组沿用既有每帧 trace 上限并明确记录不完整；该组的严格分组结果和完整性能计数仍有效，但不把截断 trace 当完整因果解释。

六组 P50 合计为 2.326 → 2.526 秒，混合方案约增加 8.6%；这是各组统计值相加，不是一次资料库导入的端到端耗时。217 输入的实际空间匹配 P50 约 0.521 毫秒/对。间隔组和 DJI 即使没有触发空间比较，也承担了预先提取空间特征的代价。

测量阶段分析结束时的进程 RSS 高水位最大值约 37.50 → 41.12 MiB；引擎托管预留估计约 2.70 → 8.82 MiB，仍在原 64 MiB 托管预算内。RSS 不是托管估计，也不含随后完整元数据审计及报告写入阶段的高水位。时间边界包括前后两遍 JPEG 哈希、读取与检测，不含标签评价、额外审计及输出。没有新 RAW、低内存机型、GUI 性能或系统冷缓存验收。

### 决策

**不启用这版 CV 强制复核，不接入自动导入，暂不将预训练模型加入产品依赖。** 现有结果支持下一轮独立研究局部视觉特征与主体/背景相对运动的价值，但不支持直接替换为全图 embedding 相似度。合法连拍中的姿态变化和用户希望切组的构图变化，不能用“中心必须静止”这类硬规则统一处理。

下一轮若做预训练模型对照，应先冻结模型、许可、预处理与资源预算，把局部对应、主体变化和上下文作为候选证据，仍由来源/时间/锚点及整组一致性约束控制分区。只有七条已知负边，不能据当前相邻帧随机拆分训练一个边界分类器后宣称泛化；需要按独立拍摄任务补充完整组与组外边界，再比较是否值得引入。当前不下载模型、不训练分类器，也不修改本轮参数或人工真值。
