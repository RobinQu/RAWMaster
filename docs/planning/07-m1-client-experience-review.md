# M1 客户端 MVP：用户体验与技术要求确认

日期：2026-10-21；版本：0.1；状态：五项关键选择已确认，界面与操作细节待审。

2026-10-23 状态说明：本页保留 M1 设计输入与确认过程；实际实现/验收以 specs/001–003 为准。以下“默认深色”只描述初版提案，已被用户新增的三档主题要求取代。下一批外观、原片恢复与分组体验见 [09](09-next-batch-review.md) 和 [004 规格](../../specs/004-client-next-batch/spec.md)；本页早期“尚缺样本/尚未实现”等不能用于判断当前状态。

本文件细化 F001/F002。M1 的目标是：在本机完成一批真实拍摄的接入、人工比较、选片、恢复与精选原片交付。M2 再增加 RAW 质量分析和自动分组；后续自动排除按 F003 的独立增量交付。本文件不代表开始编码。

## 1. 本次已明确的五项选择

| ID | 用户确认 | 对 M1 的影响 |
|---|---|---|

## 2. 建议的主界面：一个选片工作台

以下布局与交互为待确认建议，不属于上表已经获批的五项选择。

```text
┌──────────────────────────────────────────────────────────────┐
│ 项目 / 当前导入        过滤：未决定、保留、排除     比较  导出 │
├────────────┬─────────────────────────────────┬───────────────┤
│ 项目/导入  │ 网格 / 单张大图 / 2–4 张比较     │ 信息面板      │
│            │                                 │ 拍摄参数      │
│ 全部素材   │ 当前图片与判断所需细节          │ 决定/星级     │
│ 未决定     │                                 │ 组用途        │
│ 已保留     ├─────────────────────────────────┤ 文件位置      │
│ 已排除     │ 当前组胶片条 / 拍摄顺序          │ 可用性        │
│ 手动拍摄组 │                                 │               │
├────────────┴─────────────────────────────────┴───────────────┤
│ 扫描 / 复制 / 校验进度分列；异常可展开；前台不被进度框阻塞    │
└──────────────────────────────────────────────────────────────┘
```

默认深色中性背景，图片占主要空间，信息栏可收起。首次打开只显示“新建项目 / 接入素材”和最近项目；不要求登录，不要求连接服务器。首版不展示空的显影、AI 或服务器操作页面。

项目是一次拍摄/工作范围；导入会话记录一次接入过程，两者可分别恢复。M1 可切换多个本地项目，但同时跨资料库检索仍按 F005 的主线交付。

## 3. 一次完整操作

### A. 接入素材

1. 选择存储卡/目录、现有或新项目。拖入目录也进入同一个接入面板。
2. 明确选择接入方式：存储卡建议“复制导入”，已在工作 SSD 的原片建议“原地接入”；不自动执行移动或源删除。
3. 复制模式选择目标文件夹；建议默认保留源文件名和相对子目录。同名不同内容分别保留，不静默覆盖。原地模式明确“引用原位置，未新增安全副本”。
4. 拍摄用途可选“混合/待分类、普通、连拍、延时、HDR、星空/校准等”；用途不确定时不自动淘汰。
5. 扫描、预览和复制逐步推进；首批出现后即进入工作台。未扫描完整前不显示确定的全批总量，可显示“已发现”数量。

原地接入也要逐步读取身份与完整内容校验；在校验完成前使用会话内临时身份，不单凭路径、文件名或部分 hash 宣称完全重复。相同内容复用不丢失来源归属。

### B. 浏览与比较

- 网格用于定位，双击进入单张，选择 2–4 张进入比较；底部胶片条保留当前组上下文。
- 先显示内嵌预览，用户放大时优先解码当前 RAW。细节尚未就绪时显示来源和加载状态，不能把放大的低清预览标成 RAW 原始细节。
- 建议提供适合窗口、1:1 与自由缩放；比较时可锁定缩放/平移，也可解除锁定处理主体位置变化。1:1 的像素映射应在显示契约中定义，不能混淆点与像素。
- RAW 细节是固定基础渲染，用于人工判断，可能与相机 JPEG 颜色不同；不承诺 Adobe 外观一致，不提供显影滑块，也不标成自动质量复核通过。
- 支持选中范围建立、拆分或合并手动拍摄组。M1 不依赖自动分组；先建立序列用途和成员顺序，自动识别在 M2 增加。

### C. 做决定

- 建议采用 `P` 保留、`X` 排除、`U` 清除决定，`0–5` 星级，方向键前后；`G` 网格、`E` 单张、`C` 比较、`Z` 适合窗口/1:1、`Tab` 收起面板、`⌘Z` 撤销。文字输入聚焦时不触发选片快捷键，菜单提供等价操作。
- 决定自动保存；默认不自动跳下一张，可设置开启自动前进。批量决定前明确选择数量和作用范围，避免把当前过滤结果误当全部素材。
- 排除只是可恢复的决定。过滤为隐藏排除项时，当前图片先保留焦点，用户主动导航后再离开；提供“已排除”入口和撤销，避免刚操作就失去上下文。
- 对序列分别保存“独立照片是否入选”和“参与本序列”。独立排除不移出序列；显式调整序列成员时才展示间隔/覆盖变化，未支持的专项判断标为未评估。
- M1 界面以入选和评分为主；长期归档策略不逐张强迫填写，保留未决定状态等待后续归档功能。

### D. 交付选片结果

1. “导出”明确两项范围：独立精选原片、显式选择的完整序列；不能因只选代表帧而暗示序列已经完整导出。
2. 选择新目标目录，展示待复制数量、预估体积、缺失文件和同名冲突；来源盘缺失时列明跳过/等待项，不输出虚假全部成功。
3. 建议复制原始字节并校验，保留 RAW+JPEG 等已识别关联文件，可由用户明确选择是否一起带走；不在导出中重编码 RAW。
4. 建议同时输出 UTF-8 CSV（便于查看）及 JSON（保留结构）：资产身份、原路径、目标映射、决定、星级、组/成员顺序、原片可用性与复制结果。CSV 与 JSON 的正式字段和格式版本在契约中确定。
5. 清单覆盖会话内已登记素材，注明扫描覆盖范围；精选复制按选定范围执行。取消或失败保留进度与结果清单，再次导出不能覆盖不同内容。

精选原片复制属于本地交付，不等同服务端归档或独立备份。M1 不承诺 Lightroom 直接识别全部决定；XMP 写回及 Adobe 字段映射随迁移/交换契约另定。

### E. 退出与恢复

关闭应用后不继续后台导入；先持久保存状态，再停止/暂停安全边界内的任务。重新打开恢复项目、选择决定和最后浏览位置，列出可继续任务。磁盘满、源掉线、权限变化仅暂停受影响部分；原地引用掉线显示离线占位，重连后核验文件身份再恢复。

|---|---|---|---|

| T05 | 文件与资源 | 接入源只读；复制/导出校验；图片解码不阻塞交互；缓存有限额并优先当前图片 | 既有原则与工程要求；具体缓存/并发/内存预算在 plan 与测量中冻结 |
| T06 | 交付与安装 | 先本机自用，不将账号、云端或公共分发设为前置条件 | 用户已确认；签名/公证、依赖打包与分发策略在发布前处理 |

技术依据：[SQLite 官方用途说明](https://www.sqlite.org/whentouse.html)支持桌面应用本地持久化场景；[LibRaw 项目说明](https://www.libraw.org/about)列出 RAW 数据、元数据与内嵌预览读取能力。具体选用方式为本项目工程判断，尚未通过相机模式、性能与恢复验证。SwiftUI/AppKit 分工是候选设计，尚未完成接口或性能验证。

## 5. M1 验收与尚缺输入

M1 验收必须覆盖两种接入方式、边接入边选片、真实 RAW 细节显示、手动序列保护、批量决定/撤销、退出重开、拔盘/磁盘满恢复、精选复制及清单对账。人工细节查看不依赖 M2 自动分析能力。

现有性能目标仍为待验证目标：首批预览 p95 ≤ 2 秒、缓存翻片响应 p95 ≤ 100 ms、本地 RAW 首次细节 p95 ≤ 2 秒；按具体机型/模式、存储位置和缓存状态分列。在测试前冻结样本与口径，失败时明确报告；不能在未测量时承诺已达标。

尚缺：可读 RAW 样本目录及模式、真实工作盘和精选导出目的地、批次数量/容量。缓存初始位置/空间预算可先提案，不默认将仓库卷剩余空间作为 RAW 工作盘配额。服务器详细配置与 Lightroom 资料按后续里程碑补，不阻塞本地 UX 细化。

界面布局、默认快捷键/自动前进、组浏览细节和 CSV/JSON 交付格式仍待用户审阅；不因 C01–C05 获批而把这些细节一并标为确认。

数据库与未来同步的专项研究见 [08-local-database-and-sync-evaluation.md](08-local-database-and-sync-evaluation.md)。M1 不实现服务端同步，但需要为多设备身份、变更记录和冲突保留预留明确契约；不把数据库文件兼容视为 SDK/备份/同步无成本替换。
